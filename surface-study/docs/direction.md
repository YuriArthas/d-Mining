# 松风矿谷 / Pinewind Quarry

独立的 Three.js + WebGPU 地表场景，布局保留矿架主景、商店和宠物院、前景溪桥。无角色、存档、采矿或经济接线。

当前美术方向：在用户认可的 Roblox / 方块融合版上，进一步向 Roblox 倾斜。建筑改为连续大坡屋顶、粗檐口与切角门窗；树冠是少量完整、饱满的削角体，松树用三层连续锥面。河岸使用连续地形斜坡，道路边缘清楚，降低草地与图集的碎纹对比。保留清绿、橙色、青蓝和深色结构边，以及少量附着在模型表面的像素点缀。岩石以偏侧肩部、缺角和大斜面组成，远山保留宽斜面，避免规则台阶和同心叠层。

全屏像素后处理方案已被用户否定并移除。新建筑与自然资产由 Blender 脚本制作，保存 .blend、GLB、256px 图集及 SHA-256；地形、水面用世界 UV 像素贴图。近处最近邻、远处 mip 层，清晰正常分辨率输出。没有使用 Dream Loop，没有减面冒充新资产。

先发布公开独立入口，再查看全景和近景、修正并复核。当前仅检查电脑端。

场地中心 y=0；主要活动区域 x=-30..30,z=-25..30。镜头从南面（+z）朝北看。
- 矿井：椭圆开口中心 (0,-11)，半轴 (8,7)，周围保留环形步道；主提升架横跨开口，最高约17m。
- 商店：(-17,-1)，门朝+z，暖橙屋顶、明显挑檐。
- 宠物温室：(17,3)，门朝+z，青绿屋顶、蛋形展示物、圆窗。
- 工坊：(-20,-17)，规模小于前两栋建筑。
- 弯曲溪流从东北 (32,-30) 向西南 (-24,36) 穿过前景；中央桥位 (2,24)，桥面沿z轴，跨度约10m、宽5m。
- 路径：从 (0,34) 过桥到 (0,13)，分往矿井和两栋建筑。避免直角网格道路和等距排列。
- 后景：北侧及两侧起伏岩壁，林木成簇；远山和空气透视。

新造型使用适合其轮廓的分段几何、倒角、外轮廓和结构细节。通过材质分组批处理静态几何，阴影静态更新，保留全场景驻留；不靠远处卸载掩盖资源成本。
