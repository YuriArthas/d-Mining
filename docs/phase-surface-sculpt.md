# S1.5：表层曲面造型与材质细化

用户指出 S1.4 仍然只是方块堆叠，不符合希望看到的现代 Roblox 模拟器场景。本轮进一步调整造型，保持既有入口、服务与出生平台布局。

## 造型与材质

- 矿口使用曲线挤出的弧形横梁、带倒角的立柱、嵌板、金属束带和立体宝石徽章，替换矩形横梁与扁平镐子标识。
- 售卖亭使用圆边柜台、曲面顶棚、带波浪边的檐口、托盘矿石和有厚度的金币标识。矿车增加内槽、轮毂、包边和成组切面矿石。
- 树木使用渐细树干、分叉与不对称树冠；树冠为带径向起伏的曲面网格，并有沿高度变化的顶点色。石头使用确定性的多环削切轮廓；远景岩壁另有更直立的剖面和匹配草顶。
- 纯逻辑场景描述仍放在 `world/surfaceArt.ts`；原生网格构建集中在 `presentation/surfaceGeometry.ts`。不引入外部模型或贴图依赖。
- 不规则岩石/岩壁与草顶的轮廓来自纯数据 `world/rockProfile.ts`：渲染三角化，物理独立构建凸包，继续使用原来的近处加载/远处卸载机制，避免装饰网格明显超出旧盒体碰撞。
- 普通、岩石、树叶、金属和发光构件分别合并；相同材质内仍批量绘制。区别主要通过轮廓、粗糙度与金属度建立，而不是为每个道具增加独立材质。
- 新增 `SurfaceEnvironment`，初始化时生成一次 128 尺寸的环境反射图，以低强度补充金属与圆角高光；没有逐帧环境捕获。进入地下恢复原环境设置，退出时释放。
- 沿用 1024² 缓存太阳阴影与角色接触阴影，没有增加动态灯或后处理。表层日光与补光重新平衡。

## 实机参考与边界

- 对照 [Mining Simulator 2 教学视频](https://www.youtube.com/watch?v=RrH1Jm7Qnrc) 的实机故事板，观察设施、树木、岩壁之间的轮廓与配色差异；它是低分辨率参考，不能据此判断原作精确材质参数。来源与取图地址保存在 `artifacts/sculpt-reference-source.json`，参考图为 `sculpt-ms2-gameplay-grid.jpg`。
- 没有把宣传图当成实机参考，也没有把参考截图导入游戏。
- 主角、动作、镐子、背包和 UI 美术不在本轮展开；8×8 入口、售卖圆圈位置、平台/坡道共用尺寸和地下主题保持原有语义。
- 本轮是否达到用户期望的美术质量，仍以实际画面反馈为准。软件浏览器的截图和规模统计不等于真机 60 FPS 验收。
