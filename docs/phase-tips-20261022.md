# 新手引导改为一次性提示（2026-10-22）

用户反馈：“现在新手引导太烦了，应该就简单的几件事。现在变成了强制完成一堆任务。应该非常非常的节制，每次有新功能需要提示，只提示一次。”工作区 `/root/.t3/worktrees/d-Mining/surface-roblox`，基于 `b327ea9`。

## 删掉了什么

原来是一条要按顺序做完的任务链：去矿坑 → 挖第一块 → 出售 → 攒钱升级镐子 → 挖到 20 米 → 攒钱升级背包 → “长期目标：累计采矿 100 块” → 买蛋 → 装备宠物，全部做完才弹“基础教学完成！”。每一步都在左侧占一张目标卡，带“跳过引导”按钮、箭头和按钮高亮，帮助里还有“跳过/继续引导”。

这些全部删除：目标卡、任务链、采矿 100 块、完成庆祝、跳过/继续按钮，以及已经没有入口的“前往蛋台/商店”路线指引（这两处现在都是一键传送）。

## 现在只有四条提示

每条在玩家第一次用得上时出现一次，之后永远不再出现：

| 提示 | 什么时候出现 | 怎么显示 | 什么时候结束 |
| --- | --- | --- | --- |
| 挖矿 | 新玩家一进游戏 | 地表上一个“去矿坑挖矿”的箭头；到了矿坑，点亮一块方块“长按这里挖矿” | 挖到第一块 |
| 出售 | 第一次装满背包 | 深度下方一行“背包满了，点「出售」卖掉”，出售按钮闪 | 卖掉、点掉这行字，或 12 秒后 |
| 镐子 | 第一次攒够下一把镐子的钱 | 一行“金币够了，去「商店」升级镐子”，商店按钮闪 | 打开商店、升级、点掉，或 12 秒后 |
| 宠物 | 第一次买得起宠物蛋 | 一行“点「宠物」开蛋，挖得更快”，宠物按钮闪 | 打开宠物、获得宠物、点掉，或 12 秒后 |

- 同一时间最多一条；一条结束后至少安静 6 秒才可能出现下一条，不会连成清单。
- 玩家已经做过的事不提示：比如先自己升级了镐子，镐子提示就直接算作看过。
- 提示不拦任何操作，也不需要“跳过”。
- 背包满时原有的“背包已满”通知在出售提示显示期间不再重复出现。
- 左侧原目标卡的位置只留一条“下一层：老矿井 0 / 400 米”的进度，不再写说明和任务。

## 存档

- 继续存在 `onboarding` 字段里，新增 `seen`（已看过的提示）。
- 测试入口 `mining-test` 的旧版本和这里共用测试存档，它仍要求旧字段，所以 `status`、`minedOnce`、`soldOnce`、`equippedOnce`、`longTaskIntroduced`、`minedCount` 照常保存；四条提示都看过后 `status` 记为 `completed`。旧版本里点过“跳过引导”或已完成的存档，在这里一条提示都不出。
- 早于这次改动的存档按已经做过的事推算：挖过矿、卖过矿、镐子 2 级以上、有过宠物，对应提示直接算看过。
- 正式入口 `/games/mining/` 使用单独的存档命名空间，不受影响，也没有覆盖。

## 代码

- `src/game/logic/Onboarding.ts`：一次性提示记录（`seen` + 兼容旧版本的字段）。
- `src/game/application/Tips.ts`：每条提示的出现时机、“已学会”的判断、显示时长和安静间隔；下一层目标的计算也挪到这里。
- `GameSession`：每次刷新状态时更新提示；`dismissTip` 在点掉提示或用到对应按钮时调用。玩家自己做到而结束的提示可以从已保存的事实推算，跟着下一次存档保存；只有超时结束的提示立即存档。
- 界面：`src/game/ui/TipsUi.tsx`（地表箭头、点亮方块、提示行、下一层进度）和 `tips.css`；删除 `OnboardingUi.tsx`、`onboarding.css`、`OnboardingGuide.ts`。

## 验证

- TypeScript 与 Vite 构建通过。全量测试 488 项：484 通过，4 项失败与改动前相同（contact-bake、quarry 资源清单、quarry 庭院碰撞、旧道路）。旧引导链的 21 项测试随功能删除，换成 `tools/tests/onboarding.test.mjs` 的 7 项：新玩家只有挖矿一条提示且挖到就结束、出售提示只在第一次装满时出现并能超时结束、镐子和宠物提示各一次且中间有安静时间、做过的事不提示、事实只由真实采集和出售记录、旧存档与旧版本字段兼容、下一层目标计算。
- 先发布到公开试玩入口（`artifacts/tips-release.json`），再跑手机检查 `tools/check-tips-mobile.cjs`（Android UA、触控、横屏 844×390、DPR 2、SwiftShader），6 项通过、错误 0：新档只有指向矿坑的一条提示、没有目标卡和跳过按钮；到矿坑后长按点亮的方块挖下第一块，提示消失且刷新后不再出现；第一次装满背包出现一行出售提示并让出售按钮闪，卖掉后结束；钱够时镐子提示出现一次，打开商店后结束；安静几秒后宠物提示出现一次，打开宠物后结束；刷新后一条提示都不再出现，四条都记为看过。HUD 手机检查 `tools/check-ui-hud-v2-mobile.cjs` 复跑 7 项通过、错误 0。
- 删除只测试旧引导链的检查脚本：`check-onboarding.cjs`、`check-guide-arrows.cjs`、`check-guide-route.cjs`、`check-pinewind-mobile-guide-public.cjs`。另外几份更早的检查脚本（如 `check-pinewind-*-public.cjs`、`check-world-journey.cjs`）里还会点“跳过引导”，它们在之前的界面改版后已经找不到原来的界面元素，属于历史记录，这次没有改。
- 这是手机浏览器模拟，不是真机；真实新玩家是否一看就懂，仍要真人试玩确认。
