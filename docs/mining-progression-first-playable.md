# Mining 成长首版：数值与验证记录

2026-10-11。已发布 [公开测试入口](https://w-sunjun-public.dev.clock-p.com/games/mining-test/index.html)，正式 Mining 未覆盖。目标仍是普通玩家到第八层约八小时、后三段各两小时。下面的时长是共享配置计算器的估计，**不是八小时真人通关记录**。

## 已实现的玩家规则

新档零金币，地下站点不再预开放。进入休整房间才解锁传送和对应蛋，不发金币。只有高级矿要求镐子等级；岩石、煤铜等普通矿没有等级锁。每层房间脚下为本层浅岩，距本层房间 280 米后转为低价值致密岩石，直到下一房间顶部（约 380 米）。成熟装备预计约三分钟挖完这 50 格深岩；提早挖始终允许。

镐子每五级理论攻速翻倍，实际最多每秒 16 次，溢出转力量。宠物加成仍加法求和，三只装备；普通宠基础每代乘三，高价蛋普通宠再乘二，没有保底。前四层各一蛋，后六层各两蛋，共 16 台。蛋的名称价格常驻、概率直接展示。大数字显示 K/M/B/T，结算不缩写。

新存档命名为 `mining:test:progression-v1`（正式路径另槽），旧库未删除。地形版本 9。第九、第十层仅保持内容和数值兼容，不声称时长已设计完成。

## 试算结果与限制

运行 `npm run balance` 得到六种策略逐购买事件和分段 JSON；`BALANCE_SEED=2 npm run balance` 改抽蛋种子。`tools/balance/simulate.mjs` 直接读取游戏的 HP、价格、概率、背包及镐子公式，按 `ceil(HP/力量)/攻速` 累加，不对最终时长乘系数。

运行 `node tools/balance/report.mjs` 可复现下表并生成逐事件记录。抽蛋种子 1～9，固定地图种子 0，共 27 次：

| 策略 | 到第八层 P10 / P50 / P90（分钟） | 分段中位（分钟） |
| --- | --- | --- |
| 普通 | 476 / 481 / 483 | 19 / 17 / 24 / 61 / 119 / 120 / 120 |
| 精算 | 225 / 231 / 239 | 16 / 14 / 15 / 37 / 44 / 71 / 34 |
| 随性 | 871 / 873 / 877 | 32 / 27 / 38 / 108 / 231 / 216 / 221 |

逐段中位数相加不等于总时长中位数。普通策略按推荐镐级下潜；精算比较六个已暴露候选矿的收益，深段预估不足十分钟即可提早下潜；随性购买更多蛋、操作和回卖更慢。普通/精算每块瞄准假设 0.4 秒，随性 0.8 秒；售卖基础假设 18/38 秒，加离房间深度的路程项，开蛋首次 35 秒、随后 5 秒。上述参数都是待实测输入。

模型使用抽象浅层采矿面，不模拟实际走位、地形连通、渲染与 worker 调度；遇锁矿按绕挖邻接岩石处理，竖井按 190 格计，地表现有入口约少三格。精算看得到的候选矿和售卖路线是简化假设，不能据此证明真实最优策略。当前只有抽蛋多种子，尚未扫描地图种子。初次购买间隔、主矿击数分布与真实回卖路线仍需公开试玩回填。

种子 1 对照中，无宠策略在 72 小时上限内只抵达第六层，纯直挖及拒绝升级亦未到第八层。这说明模型里成长投资有价值，不表示所有捷径已穷举，也不证明无宠体验合理。

**已发现的调参问题：** 普通策略九次中最长购买空窗约 18 分钟，精算约 30 分钟（含提前下潜），随性约 33 分钟，均不能宣称“最长十分钟”已达标。继续保持后期两小时，试玩后调整层内费用分配、高价蛋时点与矿种解锁密度。第 2→3 段粗算约 17 分钟，高于 15 分钟目标；先保留首版作实际手感测试。

## 验证记录

- 自动化测试 350/350 通过，TypeScript/Vite 构建通过，`git diff --check` 通过。
- 发布脚本校验公开文件哈希、测试入口在游戏列表中，且正式 Mining 文件未改变。
- 浏览器脚本 `tools/check-progression.cjs` 使用公开入口、独立测试存档。远程命中、传送和资助存档属于受控交互验证，不是自然游玩时长证据。截图及逐项结果写入 `artifacts/progression/`。
- 公开脚本通过十项检查：新档状态、实际命中与售卖、锁蛋提示与五项概率、入房解锁且不送金币、刷新恢复地形与进度、银矿 Lv.7 拒绝/Lv.8 接受、实际开蛋装备、升级扣款，以及 Lv.21 的 16 次/秒、220 力量、110 溢出。资助存档只用于后半段 UI 验证。页面异常记录为空。
- 已查看地表、锁蛋及升级截图，桌面面板内容可读。T3 预览因主机 AppArmor 无法启动，使用独立 Playwright 检查公开地址；软件渲染的加载耗时和帧率不作为产品性能结论。
- `tools/check-attack-speed.cjs` 现转调本轮公开脚本，移除了依赖旧版 200 金币和旧价格的流程；攻速时序另有现有逻辑测试覆盖。

G0/G1/G2 与 G4 首版实现已交付；G3/G5 的真人长时试玩、自然下潜手感与两小时节奏验收仍开放。下一次校准应从新档记录首卖、首升、首宠、前三次到房间时间，再抽查第 5→6 和第 7→8 段。此处没有把自动化截图或粗算等同于人工体验验收。
