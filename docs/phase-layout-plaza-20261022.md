# 地表布局：松风广场 v3（2026-10-22）

画风保持松风矿谷现状，只重排第一世界地表的布局，全部沿用现有 Blender 资产和地形生成流程，没有新做模型。工作区 `/root/.t3/worktrees/d-Mining/surface-roblox`，基于 `77a3629`。

## 改了什么

- **广场**：矿口前改成直径 30 m 的圆形沙地广场，过桥就到。站在中间转一圈：北面矿井和排行榜，西面出售和商店，东面蛋台和宠物屋，南面桥。
- **出售 + 商店**：商店从矿架后面（原来出生点看不到）挪到出售旁边，两栋都在广场西侧、朝向广场中心内收；圈都在广场边上。两块 3D 大字招牌浮在各自的圈上方，朝向桥头，从出生点看错开高度不重叠。
- **传送门**：从西边一排（其中两座在河里）改成围着出生点的半圆，面朝出生点；南边走去传送，北边过桥去干活。返回地表正好落在传送门环中间。
- **蛋台**：保留三层台位置，台面从灰色石台改成木质台身加草皮台面；三层高度拉开到 0.4 / 2.6 / 4.8 m，相邻两层错开半个间距，常驻的名称价格不再叠成一片。按进度排：前排是第一世界前期的蛋（最便宜的在离广场最近的北端），中排第一世界后期，顶排第二、三世界。每种蛋有自己的颜色（原来只有三种配色）。宠物屋上方加了「PETS」大字。
- **扭蛋机**挪到广场东北角排行榜旁边，不再挡住从走道看蛋台的视线；桥头两侧加灯。
- **镜头**：默认俯角 0.22 → 0.34，少拍天空。

## 数据与代码结构

- 新增 `src/game/content/pinewind/hubLayout.ts`：第一世界地表布局的唯一数据源（服务点、传送门槽位、蛋台与台阶、宠物屋、招牌、道具、广场/道路/铺地/植被避让）。
- `withPinewindSurface` 改为同时提供第一世界地表的交互区：售卖圈、商店圈、传送门、蛋台站位都来自 `hubLayout`；规则、存档、房间和第二、三世界不变。旧的 quarry 布局常量保持原样，只服务于旧内容和它们的测试。
- 服务区可带 `lookAt`，即时传送后面朝建筑。夜间补光改为跟随新的广场、传送门和服务点。
- 美术流程不变（`export-pinewind-layout` → Blender `build_architecture.py` → `export-pinewind-scene` → `pack-pinewind`）：`layout.json` 改由 `hubLayout` 导出，增加 `grounds` / `props` / `terrace`；地形生成器从中读取广场、道路、铺地和植被避让；建筑脚本按蛋颜色生成蛋贴图（图集新增草皮 + 每种蛋 2 格），台面换材质。流程可复现（重建与现有资产逐字节一致，只有 UV 的 6e-8 浮点尾差）。架构 14,052 三角面、地形包 100,492 三角面。

## 验证

- TypeScript + Vite 构建通过。全量测试 485 项：481 通过，4 项失败与改动前相同（contact-bake、quarry 资源清单、quarry 庭院碰撞、旧道路）。
- 新的布局测试（`tools/tests/pinewind-surface.test.mjs`）：交互区来自布局；出售/商店不压矿架、互不重叠、朝向广场；蛋台每层抬高 ≥2 m、相邻层错开；真实 Rapier 角色碰撞下不跳跃走通：出生点过桥、广场到出售圈和商店圈、出生点到 6 座传送门、广场到第一颗蛋、北侧台阶走到最高层；即时传送面朝建筑。
- 先发布到公开试玩入口再检查（`artifacts/plaza-v3-release.json`）。手机检查 `tools/check-plaza-v3-mobile.cjs`（Android UA、触控、横屏、DPR 2、SwiftShader）6 组通过、错误 0：新玩家首屏；出售传送落在西侧新圈并自动卖出；商店传送落在旁边并开店；获取宠物 → 前往落在前排原野蛋台、提示可打开蛋台；用摇杆从出生点往西走进老矿井传送门并传送到地下 400 m；返回地表落在传送门环中心。另外复跑统一面板检查 8/8、HUD 检查 6/6（HUD 第一次运行截图超时一次，单独重跑通过）。
- 这是手机浏览器模拟，不是真机或真实 GPU。
