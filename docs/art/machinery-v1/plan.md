# 第九层：古代机械 / 3200m

后方三枚大小不同的十二齿齿轮形成传动组，两侧活塞柱高11.5m，独立底座承托。侧墙是成组发电机、电容柱与散热格栅，前侧有带指示灯的控制台；左侧售卖、右侧升级。

青灰金属、暗钢、暖黄铜与少量青绿指示灯。齿轮和机械件本轮为静态装饰，不增加运动碰撞或每帧逻辑。新网格在Blender生成，共享64×64图集；局部光照与可见指示灯分开配置。生成：`blender -b --python tools/blender/build-chamber.py -- machinery`。

公开验证通过：地表踩踏进入、正确深度落地、售卖、存在商店时自动弹窗、返回与再次传送。已查看公开到达截图；浏览器与shader错误列表为空。证据：`artifacts/machinery-v1/public-check.json`、`arrival.png`。本层222实例、4968三角面、18批次、64×64图集，无实时阴影。
