# 第七层：熔岩矿洞 / 2400m

后方11m宽熔炉、双烟道和拱形炉口；炉栅前后层次清楚，大面积亮色集中在炉口。两侧熔槽在X=±17，保留独立高边碰撞；中间环矿口通道没有熔岩装饰侵入。前侧有淬火桶、售卖与升级工作台。

暖灰玄武岩、红铜、橙色熔体，不使用透明流体，不叠加实时光源。静态局部光照参数与灯具独立。顶部/地板都留垂直入口。模型、碰撞、灯位、设施配置均分开；生成命令：`blender -b --python tools/blender/build-chamber.py -- volcanic`。

公开验证通过：地表踩踏进入、正确深度落地、售卖、存在商店时自动弹窗、返回与再次传送。已查看公开到达截图；浏览器与shader错误列表为空。证据：`artifacts/volcanic-v1/public-check.json`、`arrival.png`。本层218实例、4176三角面、18批次、64×64图集，无实时阴影。
