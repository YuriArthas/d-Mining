# 第十层：地心秘境 / 3600m

后方三层祭坛承托核心晶体，三重不同角度的天球环围绕核心；主环半径5.8m，中心Y=7m、Z=-15.3。两侧环形方尖碑和小型遗物台呼应地标。主招牌降低到Y=3.4m，让环与核心轮廓完整露出。左侧售卖、右侧升级。

深蓝紫石构、浅色祭坛、暖金实体环和少量发光晶体。64段环形轮廓配平滑法线，避免明显折线。无透明叠层、动态环碰撞或新增实时阴影，局部光照独立配置。所有造型由Blender新建，图集64×64；生成：`blender -b --python tools/blender/build-chamber.py -- core`。

公开验证通过：地表踩踏进入、正确深度落地、售卖、存在商店时自动弹窗、返回与再次传送。已查看公开到达截图；浏览器与shader错误列表为空。证据：`artifacts/core-v1/public-check.json`、`arrival.png`。本层204实例、13346三角面、19批次、64×64图集，无实时阴影。
