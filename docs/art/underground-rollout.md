# 地下层逐层制作

每层先完成独立配置、新网格与小图集，构建并发布 Mining 测试版，再检查公开画面、踩踏传送、落地、售卖、可用商店、返回和再次传送。所有图集64×64，局部光照64×64，无新增实时阴影；不按角色距离卸载普通场景。正式版不覆盖。

中央矿口为8×8格（16×16m），房间40×40×20m。到达点(0,0,12)，售卖(-12,0,12)，有升级功能的层为(12,0,12)。后方地标主要位于Z=-13..-19，侧边陈设X约±17，不侵占垂直矿口。

| 层 | 深度 | 本轮独立造型 | 升级 |
|---|---:|---|---|
| 04 水晶洞穴 | 1200m | 紫晶地标、切面晶簇、勘探仪、样品架 | 无 |
| 05 地下遗迹 | 1600m | 阶台、石柱拱门、青铜浮雕、考古营地 | 有 |
| 06 冰封矿洞 | 2000m | 高低冰壁、垂挂冰锥、雪台、补给雪橇 | 无 |
| 07 熔岩矿洞 | 2400m | 熔炉、双烟道、炉栅、侧边熔槽、淬火桶 | 有 |
| 08 巨型化石 | 2800m | 完整肋笼骨架、分节脊椎、化石岩台、标本盘 | 无 |
| 09 古代机械 | 3200m | 三齿轮传动组、活塞柱、发电机、控制台 | 有 |
| 10 地心秘境 | 3600m | 三重天球环、核心晶体、祭坛、环形方尖碑 | 有 |

所有布局都作为独立的 `content/rooms/<id>.layout.json` 保存，功能/照明/标识由同名 scene JSON 指定，运行时不添加楼层专属分支。Blender共享导出流程，不导入旧模型；规则石构、齿轮、菌伞、晶体及重建骨骼采用可控制尺寸和法线的自制网格。此次化石为简化重建肋笼和脊椎，没有尝试复杂有机头骨。

构建水晶层：`blender -b --python tools/blender/build-crystal.py`。
其余层：`blender -b --python tools/blender/build-chamber.py -- <id>`。
源模型：`assets-source/<id>-v1/source.blend`；资源统计/哈希：各层 `asset-record.json`。

公开检查：`node tools/check-authored-room.cjs <id>`。脚本只访问公开测试入口，按真实地表踩踏触发进入，输出 `artifacts/<id>-v1/public-check.json` 和 `arrival.png`。软件渲染浏览器的帧率不用于设备性能结论。
