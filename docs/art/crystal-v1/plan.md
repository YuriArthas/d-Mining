# 第四层：紫晶勘探站 / 1200m

独立场景 `crystal-station-v1`，替换第四层旧主题生成器。维持仅售卖、不设升级商店的原玩法。

- 40×40×20m房间；中央X/Z=-8..8的16m矿口。地板、顶部各用四块几何避让，不把视觉天花板跨在落井路径上。
- 出生(0,0,12)，售卖(-12,0,12)。出生前方双向通道通往左侧鉴定收购台和右侧勘探区。
- 巨型紫晶主景在后方Z=-16，最高晶柱11m、根部Y=1.45m；两侧岩台X=±17.5，错落放置蓝紫晶簇。
- 银灰框架位于Z=-13.8、高9.4m，包围后方晶簇；实体招牌位于Y=7m，完整容纳层名、层号和深度。
- 右侧分拣台中心(12.5,2,10)，仪器、样品架、周转箱形成勘探主题。全部是装饰，不添加假商店触发。
- 矿口边缘X=±8.7低栏与晶芯路标；场景照明和发光装饰分离，无新增实时阴影。

全新 Blender 切面晶体、倒角石块、十二边台座和仪器环，使用64×64自制图集。设计使用实体晶体与小面积发光嵌条，避免全屏透明叠加和玻璃塑料感。场景数据、碰撞、灯位各自声明，不互相推断。

生成：`blender -b --python tools/blender/build-crystal.py`。源文件、脚本、图集与哈希见 `asset-record.json`。编辑入口为 `crystal.scene.json`、`crystal.layout.json`；打包工具 `room_export.py` 只共享导出流程，不引入其他层的美术网格。
