# 第二层：老矿井重建

第二层按地表为第一层计，稳定 ID `old_mine`，深度 400m。旧 timber 布景分支已移除，新场景使用 `scene: timber-station-v2`。中央仍可挖矿，售卖规则不变，本层不增加升级店。

## 布局

坐标单位为米，Y 相对本层地面，北侧为 -Z。范围 X/Z=-20..20，高20。Blender 新组件全部从零生成，不引用表层或旧地下资产。

| 区域 | 中心/范围 | 用途 |
| --- | --- | --- |
| 挖矿口 | X/Z=-8..8 | 原 8×8 方块，地板和上方结构避让 |
| 到达点 | (0,11) | 前侧步行通道，远离栏杆/售卖触发 |
| 收购柜台 | (-12.2,8.1)，6.7×2.9 | 左侧；触发圈仍在 (-12,12)，半径1.7 |
| 后墙提升机 | (0,-15.6)，宽12、高12 | 独立后方地标，吊笼不侵入中央矿口 |
| 装卸轨道 | X=13.8，Z=-17..16 | 右侧轨道、矿车、缓冲挡木 |

| 工作台 | (-14.5,-5) | 左侧维修区 |
| 两侧支架 | X=±17.8，Z=-14/-4/6/16 | 成对支架、石墩、铁箍、阶梯撑木、壁灯 |

示意图：`concept.png`，使用 imagegen skill CLI 的 `gpt-image-2.5` 生成。完整提示词：`concept-prompt.txt`。定量平面图：`layout.svg`。概念图中的下挖深度只作视觉参考，实际采矿格子仍由体素系统控制。

## 结构边界

- `content/layers.ts` 决定深度、主题、矿物、room规格和场景ID。
- `content/rooms/oldMine.ts` 为资产注册表；Blender产物中的材质、实例、灯位和独立碰撞描述均为纯数据。
- `world/authoredRoomPlan.ts` 派生尺寸、落位与固定入口；售卖圈半径不随房间缩放。
- `presentation/AuthoredRoomView.ts` 只处理通用组件实例化、纹理与静态照明；没有 layerId、挖矿、售卖或传送逻辑。
- 其余八个地下层仍为旧主题生成器。本轮只是为第二层迁出独立入口，不能宣称各层美术已全部重构。

灯具发光独立于实际照明；本版使用仅作用于本房间材质的64×64静态灯光/接触暗部场，不追加实时点光源或阴影。普通场景常驻，碰撞继续使用既有近远滞回机制。

## 验收入口

当前版本通过 `content/initialAccess.ts` 在正式版与测试版统一预解锁 `old_mine`，不伪造到达深度，不解锁后续层。进入任一入口后，可踩地表的“老矿井 400m”模型旁传送。之前仅按测试路径解锁会导致正式发布后入口再次锁住，已移除该路径判断。

生成脚本：`tools/blender/build-old-mine.py`；源文件、面数和SHA见 `asset-record.json`。资源释放、非均匀缩放、固定矿口、预解锁与正常探索相互独立，均有自动检查。

## 本轮检查结果

274 项自动测试通过；墙面碰撞修正和灯架补齐后，6 项房间/入口/预解锁专项检查再次通过。公开桌面检查验证：地表老矿井展位踩踏自动传送、400m 正常落地、新组件身份、柜台触发、返回地表，浏览器错误为零。初版墙砖凸出超出碰撞壳，曾挡住相机，已调整墙体碰撞包络并在公开版复查。记录及截图位于 `artifacts/old-mine-v2/`。上述首轮检查时正式 Mining 尚未覆盖；现已正式发布，第二层开放规则与测试版一致，后续层仍按探索深度解锁。

本轮没有实际手机 GPU 性能验收；头部帧率截图来自软件渲染检查环境，不能作为设备性能结论。

2026-10-06 发布访问修正：移除按 URL 区分的第二层预解锁；12 项相关检查通过。公开测试版和正式版均验证了地表踩踏传送到 400m、通过“返回地表”按钮返回、再次踩踏传送成功，运行错误为零。证据：`artifacts/portal-release-fix/preview.json`、`production.json`。

## 第二轮精修（2026-10-06）

保留规则方块木构，新增两侧高位检修廊（X=±17.2、Y=7.5，Z=-11..5）、低位木质到达区（X=-6.3..6.3，Z≈9.3..14.4）及矿口厚木沿。后方提升机名称落到实体牌匾，读图高度由13.5m降到8.1m，避免出生视角只见被截掉的文字。

柜台采用青绿色帆布与奶油色条纹，增加矿样架、矿石托盘和账本；右侧增设装卸货物，维修区增设砧座及样品。岩壁增加块状矿脉和水平岩层，保持冷色岩壁、暖色木构与灯具的分工。地板图集改为较大的铺地块，木纹降低细碎条纹。

新增平直结构和小装饰采用12三角面的共享 panel 单元，主梁原有倒角仍保留；总计1297个实例、47232三角面、4个共享网格，64×64图集不变。矿口围栏增加四盏低位作业灯，照暖木沿与到达区。灯具与照明仍分离，使用场景局部静态光照场，不追加实时灯光/阴影。碰撞覆盖木质到达区和高位廊台，中央8×8矿口与售卖通道保持畅通。

本轮验证：13项相关自动检查和生产构建通过；最终产物已发布到 Mining 测试版并完成公开资源哈希校验，正式版未改变。公开桌面检查覆盖地表踩踏传送、400m 落地、售卖区触发、返回地表及再次传送，浏览器与 shader 错误列表为空；已查看最终到达视角截图。证据位于 `artifacts/old-mine-polish/preview.json` 和 `arrival.png`。检查环境为软件渲染，截图 FPS 不代表真实设备性能。浏览器断言和报告写入完成后，收尾进程退出码为143。
