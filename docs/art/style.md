# 林地矿营 — Tripo 全新场景

旧矿场、旧树及其减面版本全部作废，禁止作为新组件的输入或运行时依赖。

当前主设施采用 [A 经典采矿模拟器方案](quarry-v2/facility-comparison.md)：饱和蓝/橙功能分色、象牙白粗框、暖黄色立柱，以及宝石/镐子/金币大徽标。避免用普通木屋加一个绿色屋顶来表达 Roblox。

所有新建筑提示词必须明确指定 modern Roblox / Mining Simulator 2 的明亮、简洁、厚实的模拟器游戏风格。不要用中世纪遗迹、魔兽世界式重石墙、写实风化噪点代替 Roblox 风格。矿棚必须有完整屋顶，正面敞开，保证矿区和第三人称视线可读。

造型采用大块面、饱满轮廓和清晰色块。树冠由少量完整厚实的绿叶团块构成，粗短树干，无碎叶、细枝和透明叶片。草坡采用宽缓轮廓与浅色岩土侧面，建筑只有少量厚木梁、完整屋顶和明确的服务窗口。避免真实感碎石、密集瓦片、旧场景的灰色石墙堆叠。

所有可见环境组件由新 Tripo `text_to_model` 或以 Image 2.5 参考图引导的 `image_to_model` 任务生成。装配仅调整位置、朝向和尺寸；地面通过材质裁掉 16×16 米矿口，碰撞独立。UI、交互圆圈、体素矿块和天空光照属于游戏系统，不要求生成网格。

面数由 Tripo 的 `face_limit` 控制，禁止重新引入 Blender Decimate 或本地程序建模替代成品。传输处理仅做贴图规格转换、GPU 纹理压缩和无拓扑简化的 Meshopt 打包；原始和打包后面数必须一致。

布局与组件表见 [quarry-v2/layout-plan.md](quarry-v2/layout-plan.md)。每个生成任务、提示词、原始 GLB、打包哈希保存在 `assets-source/quarry-v2/<name>/`。测试发布只覆盖公开 Mining 测试版。
