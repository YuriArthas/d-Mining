# 第五层：地下遗迹 / 1600m

40×40×20m。后方Z=-16布置四级砂岩阶台、两根圆柱和拱门，中央青铜浮雕形成考古地标。侧边X=±16.7柱廊，地面放石质残件；前左收购、前右升级。八块地板/顶部几何保留16×16m垂直矿口；环矿口步道和触发区不被陈设占用。

砂岩、暖铜和少量青绿遗物，暖色静态光照。没有引用旧遗迹模型。配置和源码路径遵循 `../underground-rollout.md`，生成命令：`blender -b --python tools/blender/build-chamber.py -- ruins`。

公开验证通过：地表踩踏进入、正确深度落地、售卖、存在商店时自动弹窗、返回与再次传送。已查看公开到达截图；浏览器与shader错误列表为空。证据：`artifacts/ruins-v1/public-check.json`、`arrival.png`。本层214实例、4768三角面、15批次、64×64图集，无实时阴影。
