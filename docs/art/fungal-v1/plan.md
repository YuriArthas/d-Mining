# 第三层：荧光蘑菇驿站

第三层 `fungal`，800m；独立场景 `fungal-station-v1`。本轮替换该层旧生成器美术，不改变矿种、经济和挖矿逻辑。原有第二层保持不变。先发布测试入口，初始解锁前两个地下层。

## 布局（米，房间局部坐标，Y向上）

- 房间40×40×20；中央垂直矿口X/Z=-8..8，完整保留，不用蘑菇或桥遮挡。
- 到达点(0,0,12)，朝向后方主景；前区铺石步道连接左右服务点。
- 售卖(-12,0,12)、升级(12,0,12)，半径1.8；各自菌伞柜台在触发点后方2.4m，所有柜台摆件、标识、灯位随功能锚点一起移动。
- 左右通道位于矿口边缘8.7与岩台内缘15.05之间；两侧低栏高1.6m，前后各留中央入口。
- 两侧苔藓岩台中心X=±17.3，高1.3m/2.9m；放错层菌丛，避免阻塞主通道。
- 后方主菌伞中心(-1.8,-16)，根部高1.7m，菌柄9.1m，伞半径5.2m，冠顶约14.5m；另配两株不同高度副伞。招牌在前侧Z=-13.1、Y=7.4。

## 视觉

蓝紫分层洞壁、青绿菌褶、米白菌柄、灰绿苔藓，柜台使用暖木色。用完整大菌伞形成前中后景轮廓，不堆细枝叶、花瓣或粒子。规则石层呼应Minecraft，菌伞使用平滑法线和稀疏大斑点，保持Roblox清晰、玩具化的大形体。

灯具/发光菌褶是装饰网格；房间照明为64×64局部光照场，与模型分开配置，不增加实时灯/阴影。四块地板固定避开世界矿口，铺路块有对应碰撞，避免只画薄片。普通场景不按角色距离卸载。

## 制作与编辑

- 新网格与新图集由 `tools/blender/build-fungal.py` 在Blender生成；无旧美术资产输入。菌伞为规则旋转体，适合精确建模，此轮未使用Tripo。
- 摆放、独立碰撞与灯位：`src/game/content/rooms/fungal.layout.json`。
- 设施、标识、材质/照明参数：`fungal.scene.json`。
- Blender源文件：`assets-source/fungal-v1/source.blend`；构建后哈希与三角面统计：`asset-record.json`。
- 初版590实例、6种共享网格、53,508三角面；单图集64×64 RGBA。实例按网格/材质合批。

布局图见 `layout.svg`；这是按坐标绘制的平面示意，不是效果承诺图。公开版本画面与交互另行核验。
