# Roblox 设施风格比较与整套替换

目标：用户认可有顶矿棚比之前好，但仍不够 Roblox；先画多张示意图自行比较，再统一矿棚、商店、售卖处。这里只调整这套主设施及其前场，不重做已认可的围墙和道具。

四个方向均由 imagegen 技能的 API/CLI 路径调用 `gpt-image-2.5-sunburst`。保持同样的三建筑构图来比较，不以背景和光效掩盖建筑差异。

|方案|看到的特点|判断|
|---|---|---|
|A 经典采矿模拟器|饱和蓝矿棚与商店、橙售卖处、象牙白粗边、黄色柱子，宝石/镐子/金币三个大徽标|采用。设施身份和主次最明确，匹配 Mining Simulator 2 方向，也保留方正结构。|
|B 圆润玩具模拟器|奶白圆角柱脚、金色包边，三栋均蓝色，交叉镐与金币|玩具感强，但商店和售卖配色重复，偏礼品店套装。|
|C 施工 Tycoon|深蓝屋顶、亮黄柱子、警示斜纹与青色灯条|矿业辨识度强，但深色工业件与警示纹会压过田园场景。|
|D 童话矿镇|绿/蓝/红弯檐、暖木与灰石柱脚、屋脊上翘|仍接近上一版童话木屋，不能充分回应“还不够 Roblox”。|

比较图：`output/imagegen/facility-comparison/comparison.jpg`；四张原图同目录。原始提示词：`docs/art/quarry-v2/references/facility-comparison.jsonl`。

选定 A 后用 Image 2.5 edit 分别提取三座建筑，保持轮廓、配色与徽标；明确去掉概念图矿棚下面画出的坑壁、水晶和地板。独立参考在 `output/imagegen/simulator-facilities/`，三份提示词在 `docs/art/quarry-v2/references/simulator-*.txt`。图像参考进入三个全新 Tripo 任务，面数上限矿棚10,000、商店6,000、售卖6,000；不做本地建模或减面。

布局：中央有顶矿棚26×26×14m，完整8×8格矿区；蓝色升级店在(-21,6)，朝向矿区前场；橙色售卖处在(20,4)，金圈仍在(15,11)。蓝圈在(-18,15)，复用已有商店进入/离开状态与升级UI。屏幕上的升级按钮保留。挪开商店占地范围里的树、石头、草和告示牌；没有把新建筑叠在旧补给棚上。

所有新建筑贴图沿用512颜色/256法线/128材质，GPU压缩。围墙仍为256/128/64。旧绿顶矿棚、旧收购棚和旧补给棚退出运行时，源记录保留。

矿棚全体素区下方6m净空通过，上方1,024个采样点有完整屋顶；最低上方结构约6.32m。柱、栏杆、屋顶和徽标碰撞独立配置并与实际网格核对，360组相机位置/角度无穿模。添加地表商店时修复了直接从后序地下商店转移到前序地表商店会被exit事件覆盖的问题，统一从所有区域当前状态确定active shop。

已发布到公开 Mining 测试版，正式 Mining 未覆盖。电脑端检查出生全景、售卖区、升级界面和矿棚内部；挖矿/自动出售、地表蓝圈进入打开升级界面且离开关闭、高角度相机、场景常驻、地下回家与退出到列表均通过。页面和 WebGL 错误为零。165 项测试通过。报告与四张公开截图在 `artifacts/roblox-facilities/`。
