# V15：清澈浅水与真实平面镜像

用户要求接近镜面、清澈且略有波纹。方格草土岸和浅水通行保留。两片同高度水面共用`PondReflection`，基于Three Reflector的镜像相机和斜近裁切面捕获实际场景，包括建筑、树、角色及天空；反射时排除两片水面，避免递归。

仅在水面进入正常视锥且相机位于水面上方时更新，每次主画面最多一次捕获。第二片水面复用同一张图。普通场景未按角色距离卸载或裁剪。反射使用现有阴影，不额外刷新阴影贴图；草簇主画面统计排除反射通道，renderer总绘制统计保留反射工作。

共享RGBA16F颜色与深度缓冲，分辨率随画布等比缩放，上限1024×640，MSAA关闭。按颜色8字节、深度4字节估算上限7.5MiB；1280×720电脑检查实际1024×576，约6.75MiB。退出时释放目标、辅助材质和几何，不分配每塘一张目标。下载资源无需新增图片。

水色变淡，以统一0.13吸收系数和水IOR 1.333的Schlick菲涅耳项组合底色与镜像。透明混合保留实际塘底：俯视更通透，掠视反射更明显。倒影以原有细微法线斜率轻微扰动，约亚像素至一像素；不移动水面几何、不使用大块亮斑或岸边亮圈。未增加屏幕空间折射或游泳逻辑。

新增测试覆盖镜像相机高度、两塘共享一次捕获、防递归、尺寸上限、目标释放，以及反射异常时主画面目标/视口/裁剪/可见性/渲染状态恢复。全套194项测试通过，构建通过。先发布Mining测试版，再执行`tools/check-planar-ponds.cjs`，证据目录`artifacts/planar-ponds-v15/`。
