# V6：出生区改成石砖道路和低路沿

撤掉原出生区38×32m椭圆浅色铺面，恢复道路以外的草地。保留矿坑、出生点、左右功能区、售卖和升级位置。

|通路|尺寸与位置|
|---|---|
|中央主路|宽6m，中心x=0，z=12..51.3|
|左右连接|宽4m，中心z=30，x=-24..25|
|后方服务路|宽4m，中心z=49.3，x=-14..14|
|传送浏览路|宽4m，中心x=-22，z=14..50；1.6m支路连接各模型|
|蛋台前通路|宽6m，中心x=22，z=14..46；两端通向原楼梯|
|低路沿|高0.12m、宽0.28m，最长约1.05m一个模块；小倒角和窄拼缝|

道路使用暖灰褐色石砖，砖尺寸1.2×0.75m、错缝铺设；世界坐标shader绘制接缝、浅边缘和有限色差，继续使用V5的128×128图集，不新增路面贴图。金属度0、粗糙度1，环境反射强度0。主路到矿口衔接原施工泥土。

路沿从共享道路矩形的并集外边界生成，十字路口没有横挡。矿棚入口、蛋台、传送模型端和售卖/升级门前保留开口。路面着色、草地排除和路沿使用同一套矩形配置。草的总数量仍为780簇，圆形广场取消后重新分布在可用草地。

路沿由Blender自制：单模块44三角面，无贴图；367个实例，共16,148三角面，一个实例批次。物理独立合并为49条低矮边段，沿用普通场景附近碰撞管理；渲染资源全程驻留。角色可直接跨越，不需要跳跃。

## 验证

187项测试通过，包含实际Rapier角色双向跨越路沿、主路交叉口、售卖门前和蛋台楼梯通行。道路外边界断言保证交叉口不会生成内部路沿。原“通道无碰撞”断言现允许已单独验证可跨越的低路沿，其余障碍仍检查。

TypeScript与生产构建通过。先发布Mining测试版并校验公开产物哈希，正式Mining未覆盖。电脑公开检查由`tools/check-raised-roads.cjs`执行，截图与状态保存在`artifacts/raised-roads-v6/`。软件GPU运行结果不作为真实设备帧率或用户美术验收。
