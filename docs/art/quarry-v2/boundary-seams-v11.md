# V11：外围梯田接缝深度冲突

原外围模块宽8.6m，按8m间距排列；底部填充块宽8.5m。相邻可见土墙和顶面存在约0.5–0.6m重叠，近乎共面的三角面随镜头变化争夺深度，形成接缝闪烁。

每层模块按实际相邻关系，在中心间的中线分配接缝所有权。只有共享的一侧裁切，外露的正面、背面和倒角保持原样；直墙、转角、下部填充块都使用相同规则。未缩小整块模型，未改变相机远景或用深度偏移掩盖重叠。

`BoundaryStitcher`在加载时将裁切平面转换到网格局部空间，裁切三角形并插值原UV和法线。几何按原网格与切面缓存共享，重复块不各自保留一份网格；不在帧循环中处理。主画面、阴影、射线查询使用同一份裁切结果。碰撞仍独立保持原来的连续体积。

Tripo下载资源、任务ID、纹理和资源哈希未修改；这是运行时装配裁切，不宣称重新生成资产。原清单面数仍指源模型，实际裁切实例面数、变体内存和最大越界误差由`facilities.boundaryStitching`报告。

190项测试通过，包含接缝附近射线只命中一层、UV插值、旋转/平移后的共享网格缓存、全部边界邻接面一致。TypeScript和构建通过。先发布公开Mining测试版并核验资源哈希；正式版未覆盖。公开电脑检查脚本`tools/check-boundary-seams.cjs`，证据目录`artifacts/boundary-seams-v11/`。

公开检查与近景补充检查均退出0。检查直墙、转角及近景不同镜头角度，昼夜近景未见原先争夺深度的重叠条带；截图不作为持续帧率或真机视频验收。近景证据在`artifacts/boundary-seams-v11/close/`。

运行时共处理446个网格，共享12份裁切变体，几何缓冲159056字节（约155KiB），最大切面越界误差约1.34e-7米。公开报告无运行错误，着色器均链接成功，最大采样器数14；昼夜切换、返回地表及退出列表检查通过。
