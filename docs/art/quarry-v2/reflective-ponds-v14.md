# V14：有反光的像素水面

保留V13的方格草土岸、像素蓝色底纹及浅水通行。水面使用MeshPhysicalMaterial，IOR=1.333、roughness=0.13、metalness=0、envMapIntensity=0.8，恢复共享天空环境和真实场景灯光的反射。没有额外场景镜像渲染；不会声称倒映了建筑和角色。

反射法线使用约一毫米波高所对应的细微斜率（小于0.011），空间周期约一米，不抬动水面几何。远距离按像素足迹淡出法线细节。像素底色以原8Hz变化，反射纹理连续变化。保持统一透明度0.86，不加岸边亮圈、白色波峰、粗大法线波纹或透明度渐变。clearcoat、transmission、iridescence均为0。低粗糙度让真实灯光反射集中，避免大面积模糊的白色高光罩住整个塘。

模型、碰撞、种草范围、天空和灯光不变，资源仍为共享几何、4次绘制、0张新增纹理。Blender资产记录沿用V13，不宣称重新生成模型。
