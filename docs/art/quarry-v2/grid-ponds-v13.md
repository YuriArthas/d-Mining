# V13：方格草土岸与像素水面

用户否定V12的塑料薄膜水感和精致石材池边。本轮替换水材质与岸线，夜空月光和塘区位置不变。

- 水面改为Lambert漫反射，不使用环境镜面反射、高光、法线波纹、连续白色波峰或岸边亮圈。均匀透明度0.86；按两米16像素取样颜色纹理，以8Hz缓慢改变低对比蓝色像素图案。水面保持水平，不做几何运动。
- Blender重新制作一米网格岸线，非对称阶梯形轮廓，直角、直壁，无倒角。草顶共享现有128px草地纹理和相同的世界坐标着色，侧面为土块。两处使用同一模型，右塘转180度。
- 原石岸和八边形水面不再加载。草地排除、砂砾塘底、渲染与碰撞使用同一份水域格子描述。物理独立按岸边每行连续格合并为盒体，不用整片塘的包围盒阻挡角色。
- 浅水仍约13cm，岸高20cm，位于原有地面上，可直接走入走出；未增加游泳状态。各塘12×10米的预留范围不变，不侵占中央和两侧通道。

资产来源：`tools/blender/build-pond-bank.py` → `assets-source/quarry-v2/pond-bank-blender/source.blend`；面数和SHA256见该目录`result.json`。原创新版本`grid-pond-bank-blender-v2`，每份岸226三角面，水16三角面，两处共享几何，4次绘制。没有新增贴图或反射渲染目标。

192项测试通过，包含角色跨岸、走过水区与离开。公开检查脚本`tools/check-grid-ponds.cjs`，证据目录`artifacts/grid-ponds-v13/`；先发布测试版后进行电脑画面检查，正式版不覆盖。
