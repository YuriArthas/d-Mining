# V16：左上角性能栏与略深的浅水

普通游戏入口左上角常驻性能显示，无需debug参数：实际提交FPS、平均提交帧间隔、主线程CPU耗时、最近一次主画面的绘制次数和三角面数。每500ms汇总更新；FPS只计算RenderSubmission允许的外层画面，不把模拟tick或水面反射pass重复计入。绘制次数与三角面数包含反射和阴影工作；CPU不冒充GPU耗时。没有提交新画面时显示0 FPS及空帧间隔。

水面从Y=0.15提高至0.32，塘底维持0.022，实际水深由0.128增加至0.298米。草土岸从0.20提高至0.38米，仍低于角色0.45米自动跨步高度；岸边碰撞使用同一高度配置。浅水可走入走出，不引入游泳。反射平面随水位一起调整；吸收按水深计算（1-exp(-0.75*depth)），略增强水色，保留清晰底部和镜像。地面通路和岸线平面布局不变。

Blender脚本重建塘岸高度，源文件与资源哈希记录在`assets-source/quarry-v2/pond-bank-blender/result.json`，generationId为`grid-pond-bank-blender-v3`，面数和贴图资源量不增加。
