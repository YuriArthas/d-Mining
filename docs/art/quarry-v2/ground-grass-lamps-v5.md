# V5：像素地面、草簇与昼夜灯窗

保留已确认的V3功能布局与默认夜晚。本轮细化地表，新增草簇，并落实“白天灯不亮”。

- 地面使用一张128×128单通道图集，草地、沙地、施工泥土分别采样不同区域；采用世界坐标UV与mipmap。继续保持非金属、高粗糙度，保留功能区通路和矿坑开口。
- 草簇由Blender生成两种宽叶轮廓，每簇18或24三角面，使用顶点色，无草纹理和透明混合。780簇分成12个实例批次，合计16,380个实例三角面；几何、实例矩阵和实例颜色缓冲共63,816字节。草接收阴影、不投射阴影，无碰撞，不按距离卸载。风动只更新一个GPU时间参数，不逐棵更新矩阵。
- 草分布避开主路、广场、矿坑、宠物区、传送区和现有物体碰撞占地，采用固定种子的疏密簇群。
- 灯柱与箱灯各使用一张128×128发光遮罩，结合模型高度限制，仅让灯窗发暖光。夜晚发光强度2.5，白天为0；矿棚吊灯同步关闭发光，表层独立区域灯与补光白天也关闭。装饰灯不各自新增真实光源，原有照明仍单独管理。
- 新增三张R8纹理，包含mipmap的理论GPU纹理数据约64KiB；这不是整个游戏的内存。没有增加实时阴影灯或后处理。

## 资产来源

草簇生成脚本：`tools/blender/build-ground-details.py`。可编辑源：`assets-source/quarry-v2/ground-details-blender/source.blend`，运行时网格：`src/game/assets/ground-details/grass.json`。源文件、脚本、输出哈希及面数记录在同目录的`result.json`。

贴图脚本：`tools/blender/paint-ground-details.py`，小尺寸地面纹理自行绘制；灯窗遮罩从现有灯模型的UV颜色图提取。贴图尺寸与哈希记录在`assets-source/quarry-v2/ground-details-blender/textures.json`。这些为自制增量资产，不计入之前78个环境模型的Tripo数量，不存在Tripo任务ID。

## 验证

185项自动测试通过；最终诊断调整后，草簇与昼夜灯控制定向测试再次通过。TypeScript和生产构建通过。公开发布脚本核对测试入口全部产物哈希，并确认正式Mining未被覆盖。

电脑公开检查脚本：`tools/check-ground-grass-lamps.cjs`，证据：`artifacts/ground-grass-lamps-v5/`。实际检查出生广场、草地近景以及同机位灯柱昼夜截图：夜晚灯窗发光，白天灯窗熄灭，木架与底座没有一起发光。昼夜切换保持场景与角色位置；退出回列表，正式版和测试版均可见；页面、控制台和HTTP错误为空。真实链接着色器最多14个采样器。

软件GPU检查只证明这些公开运行行为与画面，不代表真实设备60FPS或用户美术验收。草的绘制统计按实际提交的绘制重置，GPU忙碌而跳过提交的模拟帧不会把上一帧统计清零。

最终公开复查退出码0。出生广场/草地近景/灯柱机位的草实际绘制分别为10/4/6次，对应13,536/5,388/9,204个三角面。这里的批次变化来自正常视锥剔除，场景资源始终驻留，并非角色距离卸载。
