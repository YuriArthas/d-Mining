# V29 — 半模块退台与初始开挖矿坑

围墙沿墙拼接间距仍为 8m，层间外退改成独立参数 `boundary.setback=4`，即围墙模块的半格；不是体素格长（2m）的一半。四层外退量改为 0 / 4 / 8 / 12m，保留原始首层内侧边界、层高和所有功能区。每层闭环仍落在 8m 拼接网格，沿用接缝裁切。

第三层的 22 支火把按新墙长重新分布，仍为前后各 5、左右各 6，距角部至少一个拼接间距；固定架与点光共同移动。树木和灌木落在缩窄后的第一层台阶，落地高度读取独立场景碰撞计划的实际台面，避免窄台阶把树根埋住或木阶下半段出现悬空植被。

表层矿坑维持 x/z=-4..3 共 8×8 格入口。新增 64 项固定柱深度表：36 列预挖，共 61 个空气格，深度 0..4 格（0..8m）。破口、残留土台与偏心深坑不对称。地下休整层入口不改变。

`SurfaceExcavation` 参与 `SparseWorld.baseXYZ` 的生产世界生成，generation.version 升为 7：

- 不创建密集体素数组，不往玩家修改记录写初始化挖掘，不计金币/背包/已挖数量。
- worker 渲染和碰撞、选格、开挖判断共用同一基础逻辑查询。
- 底部和侧面均是普通可挖矿物，口外表皮依然受保护。
- 显式 samples 验证地形保留原有平面测试样本。

32 项入口、地形、矿物、边界拼接与场地测试通过。原先“整块地表只生成一个顶面”的测试改到坑外平整区，继续检测边界内部不产生重复面；增加初始空气、零编辑开销及角色落到 -8m 坑底的物理测试。
