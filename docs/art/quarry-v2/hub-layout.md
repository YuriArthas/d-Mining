# 统一场地规划：阶梯蛋展台与外围退让（2026-10-04）

前一版的问题是把所有功能塞在原有围墙内，蛋排在地面上，传送区背后的低围栏、挡土墙和树冠又叠到一起。本次按原作参考图改为三层蛋展台，并同步扩大外围；不是只增加蛋的高度。

比例图：[hub-layout.svg](hub-layout.svg)，由 `node tools/plan-hub.mjs` 从当前代码生成。统一场地约束位于 `src/game/world/SurfaceSite.ts`。

外围仍用小型木挡土/草地组件组装四层梯田，不把一个模型无限放大成围墙。每个可见草坡保持原始高宽比例；下方用单个共享木方实体填充，移除原来被覆盖在地下的重复草坡叠层；没有按角色距离隐藏或卸载场景。地面覆盖尺寸同步扩大，覆盖完整外围。

## 三层蛋展台

- 三层，每层6个蛋，共18个展示位。沿用六款Blender蛋，在不同层排列展示；尚无孵化或宠物数值。
- 前、中、后层分别位于x=-28/-34/-40，台面高度0.4/2.2/4.0m。越往后越高，全部朝中央方向展示。
- 每层平台6×26m，蛋占2.7×2.7m、高3.02m；每层z=20/24/28/32/36/40，左右净距1.3m，展示行前有连续站立通道。
- 平台由已批准的木质方块与浅色收边组件拼装，不新增高分辨率贴图。渲染共享实例，碰撞独立使用平台壳体。
- 两侧楼梯位于z=15.5和44.5，宽3m。最大台阶高度0.3m，小于角色0.45m自动跨台阶阈值；上下不需要跳跃。
- PET标识移到展台后侧、高于顶层蛋的位置，照明重新对准整座展台。

## 传送、围栏和道路

站点顺时针排列于(15,24)/(24,24)/(33,24)、(42,24)/(42,33)/(42,42)、(33,42)/(24,42)/(15,42)。间距9m、触发半径3.3m保持不变。安全浏览区位于z=30/33/36、x≤35；走近独立站点才传送。

传送区低围栏重新定在z=19/47、x=47；与外层挡土墙之间留出草地缓冲。蛋区不再三面铺一圈平地展位和围栏，而是以阶梯展台本身作为空间边界。道路连接观看前场与两侧楼梯，不穿过蛋的台座。

灯的数量和阴影预算不增加，完整Tripo材质继续保持13个采样器。普通场景始终驻留。

## 资产与资源

77个独立模型、1394个实例、520010个实例三角面、约20.2MiB下载。没有新增模型或贴图下载；外围更大，但去掉被遮住的地下重复壳体后，实例三角面比前版650990更少。此统计不是帧率结论。

六款蛋仍由 `tools/blender/build-pet-eggs.py` 生成，每款1432三角面、一张128×128颜色纹理。规则、对称、精确尺寸/UV的模块适合Blender；复杂有机主题组件适合Tripo；记录各自来源与资源哈希。
