# 表层地图 V3：左传送、右宠物蛋

用户确认的观察方向：站在出生点面向矿坑，左手为传送带，右手为三层蛋台。售卖与升级建筑在身后，门朝向中央广场。默认黑夜，保留白天切换。

[实际配置比例图](hub-layout.svg) 由 `node tools/plan-hub.mjs` 从运行时坐标生成。游戏内不绘制规划红线。

功能区包络73×82m，建设范围x=-34..47、z=-24..66，即81×90m。外围采用现有8m拼接间距，第一圈中心线x=-39/57、z=-31/73；实际内沿x=-34.7..52.7、z=-26.7..68.7，在建设范围外留余量。四层梯田和树木一起迁移，普通场景不按距离卸载。

所有功能区域及主要通道从装饰摆放中排除。两侧低栏仅放在模型背后，不围住入口；原矿口附近的工具、矿车等按预留区重新布置。标识、功能碰撞和区域灯光跟随新位置，装饰灯与真实光源仍独立。

本轮没有新增模型或贴图，沿用用户已认可的这一代组件，仅重排、缩放。78个独立模型，1333个实例，496868个实例三角面，下载资源21195157字节。来源与哈希见 [assets.json](assets.json)。
