# V4：暖沙色地面与柔和夜景

本轮仅修改表层地面材质和照明，不改变V3确认的左右布局、功能坐标、体素、交互或相机。默认黑夜，保留白天切换。

- 广场和道路采用稳定的暖沙色，只保留3%的细颗粒变化，去掉大尺度云状斑驳；草地缩窄颜色波动范围，草地/道路边界更明确。
- 地面继续由现有地表模型和世界坐标shader绘制。去掉地表原模型的颜色、法线、凹凸、ORM与AO贴图引用，避免生成材质与新着色叠加；粗糙度1，金属度0，地面环境反射强度0。其余Tripo组件保留原贴图与材质。
- 夜景半球补光由0.85升至1.3，采用浅冷色天空与偏绿的地面反弹色，保留树木、木材和草地本色；天空依然是原夜景shader。
- 商店/售卖局部光从650降至170，并从7m提高至13m。蛋台从1250降至450，传送从600降至220，矿棚外立面从950降至320。广场补光从10m提高至28m，以更宽、更柔的范围覆盖中央区域。
- 灯和阴影灯数量不变，没有新增模型、纹理下载、后处理或距离卸载。矿坑内的下照灯保持原设置。
