# 方块矿棚试验

本页记录首次方块搭建试验；后续材质替换、徽标和照明见 [材质与吊灯迭代](mine-material-light.md)。

上一版整体生成的矿棚、商店、收购处及完整场景已提交为 `9703cde`。本轮只将矿棚替换为规则组件拼装，商店和收购处保留。

## 结构

- 网格单位与矿物方块一致：2 米；矿口 8×8 格、16×16 米。
- 四根柱子位于 `(±10, ±10)`；柱子和横梁由约 2 米立方块逐格组成。
- 柱高 8 米；上方闭合横梁圈、完整阶梯双坡屋顶、前后木质山墙。
- 整体宽深约 26 米。横向每进一格，屋顶升高半格，最高 17 米。
- 组件接缝留 0.12 米隐藏搭接，避免生成模型边缘的细小起伏造成透天缝；网格间距仍严格为 2 米。
- 木色结构、奶白收边、蓝色屋顶；左右、前后布局均对称。
- 挖矿口、正前方入口和矿棚下的行走空间保持开放。

## 生成方式

不再让 Tripo 生成整栋建筑。三种方块单独生成，保留原始拓扑；程序只负责重复摆放和批量绘制。

第一轮 text-to-model 木块（118 三角面）边缘起伏明显，不采用。第二轮使用 Image 2.5 Sunburst 的明确正方体参考图，再由全新 Tripo image-to-model 任务生成。

Imagegen 使用技能自带 CLI/API，提示词完整保存在 [grid-mine.jsonl](references/grid-mine.jsonl)。参考图：

- [木块](../../../../output/imagegen/grid-mine/grid-mine-timber-v2.png)
- [收边块](../../../../output/imagegen/grid-mine/grid-mine-trim-v2.png)
- [屋顶块](../../../../output/imagegen/grid-mine/grid-mine-roof-v2.png)

生成时每种组件面数上限 200。最终任务 ID、面数和 SHA-256 记录在 `assets.json` 及各运行时 manifest；原始任务与结果保存在 `assets-source/quarry-v2/`。

## 资源与碰撞

- 281 个重复组件使用 3 组 InstancedMesh，共享网格、材质与贴图。
- 单种组件颜色贴图 256²、法线 128²、ORM 64²，带完整 GPU 压缩 mip 链。
- 碰撞独立用 39 个粗略壳体描述立柱、梁、山墙和屋顶，不逐方块创建碰撞。
- 普通场景继续常驻；不按距离裁剪模型。
- 退出销毁实例缓冲；几何、材质、贴图仍按共享资源去重释放。

## 验证

- 167 项自动检查通过，包括双轴对称、矿口通畅、碰撞相机、批量绘制变换一致与释放。
- 原始 Tripo 几何组合后的 1,024 个屋顶覆盖采样全部命中；矿口向下检测遮挡为 0；360 组相机射线与实际模型穿插为 0。
- 正式 Mining 哈希不变；测试版公开文件逐个校验通过。
- 公开电脑版：64 格矿口、真实挖矿入包、自动售卖、棚内与陡角相机、普通场景常驻、地下/地面往返、退出回游戏列表均通过；无页面、网络或 WebGL 错误。
- 从公开截图发现部分木梁拼接处透天，增加隐藏搭接后重新检查模型、碰撞和批量变换，并重新发布。最终公开画面复查记录见 `artifacts/grid-mine/`。
- 运行时确认 281 个模块 / 3 个实例批次；全表层压缩纹理 mip 数据约 24.94 MiB、几何 CPU backing store 约 2.45 MiB。这不是浏览器总内存或真实硬件帧率结论。
- 布局已对称，但 Tripo 小方块仍有少量边缘起伏；本轮未将其描述为数学上严格平面的立方体。
