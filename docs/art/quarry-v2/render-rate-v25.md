# V25：60帧与跟随屏幕切换

用户确认少量烘焙阴影开关均已60FPS，要求突破60封顶。

- 右上角“帧率：屏幕 / 60”，默认屏幕模式。
- 屏幕模式每次浏览器RAF都提交画面，不再经过游戏60Hz截止时间筛选；不另起setTimeout或忙循环。
- 60模式沿用已有抗时间戳抖动调度；切回时重置旧deadline。
- 物理仍固定60Hz并插值，跑速、碰撞等不因绘制帧率增加而加速。
- 运行中切换不重建场景、渲染器或RAF循环。诊断报告携带模式，切换模式时取消已有诊断，避免混合样本。
- 没有保证iPhone浏览器提供120Hz RAF。软件GPU上的人为RAF限速只检查控制，不作为手机高刷证明。

9项相关测试通过，覆盖60/90/120/144/240Hz全部RAF绘制、60Hz模式恢复、最高240Hz下相同物理步数与移动距离，以及性能计数。构建与公开文件哈希核验通过，正式 Mining 不变。

公开检查：`tools/check-render-rate.cjs`，证据 `artifacts/render-rate-v25/`。

公开桌面检查通过：display→60→display切换成功，场景未重载，画布大小和烘焙阴影保持，实时阴影始终关闭，页面无错误。控件截图已查看；实际手机是否超过60FPS等待设备反馈。
