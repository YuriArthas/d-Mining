# V8：两处草地路灯试放

按用户截图，从蛋区方向朝传送区看，在主路两侧草岛放两盏路灯：(-11,40)与(11,40)。灯具落地高度0.02m，整体高4.6m、宽1.4m。离道路与功能触发点有净空；灯杆增加独立普通碰撞，草簇排除灯杆占地。

两盏灯各有一个真实Three.js PointLight，位置y=3.65m，暖色`#ffda9b`，强度70，距离16m，平方衰减。它们参与地表、路沿、角色及普通模型的照明，不只是灯窗自发光；本轮不增加这两个点光源的阴影贴图。灯具与光源用独立描述，共用摆放锚点。夜晚灯窗及光源开启，白天两者关闭，地下随表层照明组停用。

复用当前场景的Tripo `lantern-post`，不是新生成资产：任务`f23b7b64-c198-4c78-87fe-532fbdf7afb6`，单件1908三角面，增加2个实例、3816实例三角面；共享原网格、材质与纹理，不新增模型下载。完整资源哈希见`src/game/assets/camp/lantern-post.manifest.json`。原78件独立模型数量不变。

187项自动测试、TypeScript与生产构建通过。先发布到公开Mining测试版，产物哈希校验通过，正式版未覆盖。电脑公开检查：`tools/check-street-lamps.cjs`，证据目录`artifacts/street-lamps-v8/`；软件GPU结果不代表真实设备帧率。
