# V7：石砖光照响应与角色尺度

V6的路砖主要由底色和深色线条构成，路面法线仍是平面；角色高1.65m，相机距离10.5m，也放大了铺面与角色的尺度差异。本轮保留路网、低路沿、草及功能位置。

- 石砖从1.2×0.75m改为0.9×0.6m，缩窄并减弱接缝对比，压低整砖色差，加入少量磨损变化。
- shader以约9mm的浅倒角高度场扰动法线，让砖边响应实际灯光。该高度是着色用的微表面，不是新增几何或碰撞；小于像素时衰减法线细节，避免远处噪点。
- 夜晚环境补光1.3→0.95，方向主光1.15→1.5；广场暖色补光从正上方移到侧上方，强度400→180，以保留明暗方向。白天环境补光0.9→0.75。灯光和阴影数量不变，白天装饰灯仍熄灭。
- 角色高度1.65→1.85m，半径0.4→0.44m，碰撞与圆柱表现共享尺寸；相机距离10.5→8.5m，目标高度1.9→2.05m，保留原转镜头与避障逻辑。圆柱接收场景阴影，继续使用轻量脚底接触影。
- 修正脚底接触影偏移：原相对脚底-0.018m会低于约0.022m的可见地表；改为-0.002m，让阴影落在可见地表上方。

未增加图片下载、贴图、场景三角面或后处理；仅圆柱从20增加为32段。纹理继续使用既有128×128图集。
