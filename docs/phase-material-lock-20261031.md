# 矿物手动锁定（2026-10-31）

用户反馈：
- 出售时要能把某些矿留下；得能手动锁和解锁，不然前期挖到了不能卖，血亏。
- 第一版只能锁门票矿物，铜锁不了，不合理。应该都能锁，基础方块也能锁。

原来的材料仓（10-26，`f702021`）会自动收走下一个世界门票要的矿物（世界 2：紫水晶 20、蓝宝石 15、黑曜石 10）：挖到就进仓，不占背包，也卖不掉，直到存够数量。前期正缺钱，这些矿值钱却不能卖。

## 现在

- 任何矿都能锁，基础方块（泥土、石头）也能锁。锁定按种类：锁了铜，以后挖到的铜也是锁着的。一开始什么都不锁。
- 锁定的矿出售时留在背包里：走进售卖圈或点“全部出售”都只卖没锁的。“可卖”金额只算没锁的。背包里只剩锁定的矿时，HUD 上不显示“出售”；这时走进售卖圈，提示“锁定的矿物不会卖掉”。
- 背包“矿物”页：
  - 每个矿物格子就是锁定开关，整格都能点。没锁：角上一把淡色的开锁；锁定：金色的锁，格子变成淡金色。格子上方一行小字“点矿物锁定，出售时留下”。
  - 材料仓里，下一个世界门票要的每种矿物也是一个开关（整行），和下面格子是同一个锁。
- 门票矿物锁定后：
  - 不留在背包，进材料仓。背包里已有的马上收进仓，以后挖到的直接进仓，不占背包；
  - 仓里存够门票需要的数量时，这种矿自动解锁：门票已经够了，多挖的照常卖。原来存够后多的还锁在背包里，越积越多；想卖掉只能解锁，而解锁又会把仓里存好的放回背包一起卖掉。整局机器人接上锁定时发现了这个问题；
  - 存够后再手动锁上，多挖的就留在背包里不卖。
- 解锁（还没存够时）：材料仓里的这种矿放回背包，下次出售卖掉。存够了的仓一直留到交门票。
- 门票交矿时先扣材料仓的，不够再扣背包里的（锁没锁都算）。传送门上显示的“拥有”数量是两处加起来。
- 锁定随存档保存（背包数据的 `locked`，可省略）。
- 重生清空背包和材料仓，锁定也一起清掉，和新玩家一样从头开始。
- 旧存档材料仓里已有、还没存够的矿物视为已锁定，接着存。
- 文案：
  - 材料仓说明：“锁定的不会卖掉，挖到存进这里，不占背包”；
  - 传送门提示：“（在背包的材料仓里锁定，挖到就存起来）”。

## 代码

- `src/game/logic/Inventory.ts`：锁定集合 `locked`（快照和存档都有），`isLocked`、`setLocked`，`sellable()` 只给没锁的。
- `src/game/logic/MaterialStore.ts`：只管存放：`take` 按会话给的数量收；`release` 把一种矿全部还回；`pay` 扣仓里能扣的，返回还要从背包扣的部分。
- `src/game/application/GameSession.ts`：
  - `lockItem`、`unlockItem`，任何矿种都行；
  - `storeWants`：锁定且门票还缺的才进仓；
  - 出售和“可卖”报价用 `sellable()`；
  - `unlockWorld` 先扣仓再扣背包；
  - 重生清锁；载入时仓里有的矿种自动锁定。
- `src/game/ui/bag/BagSheet.tsx`、`bag.css`：矿物格子和材料仓行都是锁定开关（`aria-pressed`）；“传送出售”在没有可卖的矿时置灰。
- `src/game/ui/hud/Hud.tsx`：有可卖的矿才显示“出售”。
- `src/game/ui/kit/icons.tsx`：新增打开的锁 `unlock`（灰色锁身）。
- `src/game/ui/world/WorldSheet.tsx` 和英语、印尼语、越南语三张翻译表：新文案。

## 验证

- 单元测试：
  - `world-journey.test.mjs`：
    - 门票矿物一开始不锁、进背包；锁定后背包里的收进仓，以后挖的也进仓，锁定在重新载入后保留；存够的那一块让它自动解锁，多的照常卖，仓不动；存够后再锁上，多挖的留在背包；
    - 锁定时背包里的已经够数，仓一次存满并自动解锁，剩下的能卖；
    - 解锁后仓里的放回背包，挖到的也进背包，出售时一起卖掉；
    - 铜和泥土锁定后出售时留下，提示“锁定的矿物不会卖掉”，解锁后能卖；还没有的矿种也能先锁；坏的锁定数据报错；
    - 更后面世界的矿物，锁定后存进仓才出现在仓里；旧存档仓里有的视为锁定；
    - 交门票先扣仓再扣背包。
  - `rebirth.test.mjs`：重生清掉锁定。
  - 全量通过。
- 公开版手机检查 `tools/check-material-lock-mobile.cjs`（Android UA、触控、横屏 844×390、DPR 2、SwiftShader），存档里放 5 紫水晶、8 铜、6 泥土，全部触控操作：
  - 一开始材料仓三行和三个矿物格子都是开着的锁（行 215×36 像素，格子 76×88 像素）；
  - 在材料仓锁紫水晶：5 块进仓（5/20）。在格子上锁铜：铜留在背包，变成金色。“可卖”只剩泥土的 6。出售只卖了泥土，铜和紫水晶都在；
  - 背包只剩锁定的铜时，HUD 上没有“出售”；
  - 两个都解锁：紫水晶回到背包，再出售卖了 198；
  - 锁定后重新载入，仍是锁定。
- 这是服务器上的手机浏览器模拟，不是真机。
