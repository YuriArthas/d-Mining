# 手感与音效（2026-10-22）

游戏原来完全没有声音，敲方块只有裂纹和血量条。这一轮补上音效和挖矿反馈。工作区 `/root/.t3/worktrees/d-Mining/surface-roblox`，基于 `937404a`。

## 音效

全部音效在浏览器里用振荡器和一段固定噪声实时合成（`src/game/audio/sfx.ts`），游戏不带任何音频文件。

| 时机 | 声音 |
| --- | --- |
| 镐尖碰到方块 | 清脆的崩裂声 + 中频敲击 + 低频闷响；泥土更闷，矿石带金属余响，宝石/晶体带清亮的叮声 |
| 方块碎掉 | 碎石哗啦声 + 散落的小石粒；矿石和宝石另加一声奖励感的叮 |
| 捡到矿石 | “啵”一声；本层普通矿石多一个音，稀有宝石再加闪光音 |
| 出售 | “咔—叮”加一串金币声 |
| 起跳 / 落地 | 轻快的呼声 / 按落地速度变化的闷响 |
| 点按界面按钮 | 轻柔的点击 |
| 升级镐子或背包、领奖、扭蛋 | 上行和弦 |
| 孵蛋 | 跟着开蛋动画：蛋摇 0.8 秒时有几下咯噔、裂开时一声脆响、宠物弹出（1.0 秒）时一组和弦，稀有度越高越亮；自动孵蛋只轻轻一响 |
| 解锁新矿层 | 一段短号角 |
| 传送 / 返回地表 | 呼啸声 |
| 背包满、金币不足、镐子等级不够 | 两声低沉的“嘟嘟” |

- 浏览器规定首次触摸、点击或按键之后才能出声，游戏在那一刻启动声音；页面切到后台时暂停。
- 设置里新增“音效：开/关”，默认开，选择保存在设备上，刷新后保持。
- 同一种声音连续触发会合并（例如一次掉好几块矿只“啵”一声），手指按住满包的方块时拒绝声最多 1.2 秒一次。
- 手机扬声器几乎放不出 250 Hz 以下的声音，所以每个撞击声都有一层中频，低频闷响只是给耳机的。各音效按“去掉 300 Hz 以下后”的响度排了层次：奖励类最响（约 −22～−25 dB），碎块其次，敲击约 −30 dB，拾取、落地、拒绝更轻，界面点击最轻（约 −36 dB）；峰值都低于 −6 dB，总线上有一个温和的压缩器。

## 挖矿反馈

- **命中跟着镐子走**：普通命中的声音、碎屑和方块闪白，都在挥镐动画里镐尖碰到方块的那一帧触发，而不是按下的瞬间。接触点从挥击的 30% 提前到 24%（攻速 2 时按下后约 0.12 秒）。
- **碎屑从镐尖飞出**：碎屑从方块露在空气里、朝向玩家的那个面飞出，落点就是镐尖的位置（第三人称镜头在角色身后，原来从靠近角色的一侧飞出会被身体挡住）。碎屑分亮暗两种岩石色，矿石方块混入矿石色。
- **最后一击立刻炸开**：打碎方块的那一击在按下时就已经把方块交给地形移除，所以碎块爆开和碎石声立即触发，不等镐子落下；之后那一下挥击不再补命中声。
- **落地扬尘**：重落地时脚下扬起一圈尘土，颜色取脚下方块。
- 所有粒子共用一次实例化绘制，最多 192 个，半秒左右消失；不影响玩法、地形和物理。

## 代码结构

- `src/game/audio/sfx.ts`：音效配方（只在任意 `BaseAudioContext` 上排程节点，测试和离线渲染可复用）；`GameAudio.ts`：首次手势启动、开关与保存、同类合并、诊断计数。
- `GameSession.onFeedback`：出售、购买、领奖、孵蛋、解锁、拒绝这些时刻的事件。背包被装满的那一刻也会发出拒绝提示（原来提示文字已先设好，导致这一下没有声音）。
- `MinerAvatar.consumeEvents()`：镐尖接触（带镐尖位置）、起跳、落地；`MiningInteraction.strike` 带上方块种类和是否为最后一击。
- `src/game/runtime/MiningFeedback.ts` 把这些事件变成声音和效果；`src/game/presentation/HitEffects.ts` 负责碎屑、碎块、扬尘和闪白。
- 界面按钮统一走 `GameButton`，点按音效在那里加一次。
- 离线试听：`tools/sfx-preview/`（Vite 开发服务器 + `render.cjs`），把每个音效渲染成波形/频谱图、响度表和 WAV 文件，结果在 `artifacts/sfx/`。

## 验证

- TypeScript 与 Vite 构建通过。全量测试 503 项：499 通过，4 项失败与改动前相同（contact-bake、quarry 资源清单、quarry 庭院碰撞、旧道路）。
- 新增测试：`tools/tests/game-audio.test.mjs`（4 项：手势前不出声、关闭后保存并在刷新后保持、同类合并、每个音效在声明时长内结束且单声部不过载、噪声固定）；`tools/tests/mining-feedback.test.mjs`（8 项：命中在接触帧触发、最后一击立即炸开且不补命中声、方块已挖走或传送后不补声、起跳落地与扬尘、各会话事件的音效、未知物品不报错、碎屑从露出的面和镐尖位置飞出、粒子寿命与上限、会话的出售/购买/余额不足/满包事件及 1.2 秒限频）。
- 先发布到公开试玩入口（`artifacts/feel-sound-release.json`），再跑手机检查 `tools/check-feel-mobile.cjs`（Android UA、触控、横屏 844×390、DPR 2、SwiftShader），7 项通过、页面错误 0：首次触摸前声音不启动、之后运行；界面按钮有点击声、设置里有“音效：开”；触控跳跃有起跳和落地声；在广场矿坑按住泥土挖：镐尖接触时出命中声、最后一击碎石声、捡到矿石的“啵”；“返回地表”和“出售”有呼啸声，出售有“咔叮”；地下 400 米车站挖矿逐帧截取，碎屑从镐尖处飞出、方块闪白；关掉音效后命中照常但不再出声，刷新后仍是关闭。
- 同一公开版本上复跑动作与贴图检查 `tools/check-miner-motion-mobile.cjs`（接触点提前后）：5 项通过、错误 0。
- 声音的检查依据是游戏自己的音效计数和离线渲染的波形、频谱、响度，没有人耳试听，也没有在真机扬声器上听过；最终听感以在试玩入口实际听到的为准。
