# Mining 测试版：新手提示、装备购买和深度路线

本批按用户要求整合完成后统一检查、发布、公开验证；未提交 Git，未发布正式 Mining。

## 玩家行为

- 满包且有可卖矿物时，出售按钮放大、金色描边，常驻箭头气泡。按钮及气泡均可触控出售；完成出售后立即消失。不会被一次性新手提示的已读状态隐藏。全部矿物锁定时不误导出售。
- 首次出售后，达到购买条件时建议升级；已经升级或看过升级建议，且可以买到首颗开放的蛋时建议买蛋。首次解锁地下层并回地表后介绍层间传送；探索后介绍世界门票；下一世界的工具、对应货币、材料均满足时提示可以前往。点击只导航，不自动购买或扣门票。提示可关闭，满包优先，模态窗口期间暂停计时。
- 当前商店货架上的任意未拥有工具/背包，只要对应货币足够即可直接购买。跳过的装备仍未购买；回头购买它需付其价格。最高已购装备继续负责世界门槛、强化与推荐；买低级镐不会清掉高级镐强化。旧顺序购买存档保留原有权益，非连续购买记录持久保存。
- 挖掘门槛显示配置中所需镐子的实际名字，四种语言均走语言资源；不再显示 Lv.XXX。
- 所有普通基矿占 5 格，致密基矿占 10 格，矿石占 1 格。掉落数量和出售价格仍按块计算。尚未完成地形提交的掉落按体积预占容量；已经接受的最后整块允许超出剩余空间，绝不裁掉掉落。旧存档物品数量保留，若新体积导致超载仍能出售或购买更大的包。
- 顶部改为横向彩色深度路线、层/商店节点与当前深度指针。六个路段等宽，在各段内按米数插值以保障手机浅层节点间距；不是全程等比例尺。回地表指针归零，探索节点保持点亮；按当前世界切换终点 860 / 2400 / 2400 米。

## 数值影响与边界

占格从 1 改为 5/10 会增加出售频率，这正是本次背包压力的来源。未顺带调高背包容量或改动价格。已同步经济生成器和模拟的加权占格，避免重新生成后丢失配置或模拟继续把“格”当“块”。

原先 2/4/6 小时的世界完成目标不能继续声明达到：相同 seed 1、原有典型玩家购买策略，更新模型约为 216 / 351 / 449 分钟（各世界单独耗时）。这是模型估算，不是真机游玩测量；跳级购买的实际玩家策略可能不同。回归仍要求三世界全部到达、各世界耗时不超过原目标两倍。曾试算逐层增加占格，因后期出售负担过大已撤回，最终统一 5/10。
