# S1.8：平地草甸布局与完整远景

承接用户对 S1.7 的反馈：金属感地面、出生高台、旧布局、曲线折线和岩石硬面均需调整；普通场景不得按距离裁掉。此轮以场景质量为优先，不以性能预算限制造型。

## 实现

- 出生点改为西南侧平地，移除生产场景的高台和坡道，包括不可见碰撞。出生、回家与传送区域共享 `surfaceLayout.ts` 的坐标。
- 保留中心 16×16 米 / 8×8 格入口；售卖区移到东侧，矿车、轨道和卷扬机集中到西侧。移除跨越正前方的大门，改为西北角小木吊架，路牌在入口侧边。
- 曲线土路串联设施与侧面入口；真实弯曲草叶成片分布，避开通道、入口和功能圆圈。低矮圆石、树群、泉池与远山构成外围。
- 草地、土路与矿物地表去掉金属反射；木头、布顶、岩石使用各自的粗糙度和细节，金属响应只用于设备金属零件。
- 岩石以连续曲面生成，焊接顶点后计算平滑法线。视觉以 96×56 采样，物理凸包独立采样。管道提升横截面/路径分段，旋转体同时平滑轮廓拐角与圆周，避免只增加圆周分段而保留横向硬折痕。

## 可见性与模块边界

- 相机远平面从 80 米扩大到 10000 米；表层去除遮蔽远景的距离雾。
- 所有普通场景（表层和地下设施）在会话内保持加载；可见性不再由角色距离决定。仅退出会话时统一释放。
- 附近普通物体的碰撞仍独立开关（12 米加载 / 22 米卸载）。山体视觉不依赖碰撞是否存在。
- 体素渲染与碰撞继续使用已有的独立流式窗口，逻辑源仍然稀疏，不为远景创建实体矿块。
- 草甸地面补片属于普通场景，仅覆盖不可挖表层的视觉；严格留出中心矿口，不创建第二套地面碰撞，也不填平挖开的矿洞。
- 地下保留自身环境色和雾效；设施几何始终驻留。
