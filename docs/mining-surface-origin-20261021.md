## 结论

当前公开场景为 `surface-study/` 的「松风矿谷」。主要制作都发生在 T3 [Mining 教学与玩法系统改动](t3-thread://v1/6c769403-d3c0-4896-a27c-19e6b0b55c09) 内，场景阶段为第 13–20 轮。虽然该会话现在显示 Claude Sonnet，相关制作轮次的 durable run 记录均为 Codex / gpt-6-astra。不能用会话现在的模型标签倒推当时的作者。

它是独立 Three.js 0.186.1 / WebGPU 观景样板，没有角色、存档、采矿、经济与任务逻辑。当前可玩 Mining 使用 WebGLRenderer，迁移应落实新场景及其玩法接点，不能把独立样板的启动器或 renderer 整包替换进去。

当前版本来自用户最后一句「还行，再试试更偏 roblox 一点的」后的修改：宽连续屋顶、粗门窗框、饱满削角树冠、连续斜坡河岸，保留鲜明大色块和克制的小图集点缀。早期全屏像素后处理已明确被否定。

## 对话因果链

1. **10-19 22:15，第 13 轮：独立重做。** 用户对原游戏地表布局不满意，要求「新写个场景，不要接任何逻辑」「可以用 tripo3d，也可以自己堆」「单独注册」「threejs+webgpu」，同时强调画面和性能。形成前景溪桥、中景商店和宠物院、后景主矿架与山林的矿谷布局。最初主要用运行时代码生成几何。
2. **22:47–22:56，第 14/16/17 轮：灰暗与细线条。** 用户指出「不是雾，而是对比度」「线条太细」「要有 roblox 感觉，附带美漫一点」。此前讨论 Dream Loop；用户明确「按我们的来，不用它的」。随后加粗屋檐、门框、柱梁、桥栏和矿轮，拉开清绿草地、橙顶、青蓝顶、蓝色远山、深蓝结构边的关系。Neutral 色调映射在这一阶段确定。
3. **23:14–23:26，第 18 轮：像素后处理尝试。** 用户说「看起来好多了，能不能再像素化一点，或者后处理」。实现了原画、轻像素、强像素，通过低分辨率渲染再放大得到屏幕像素感。
4. **23:33–23:55，第 19 轮：明确否定，改原始资产。** 用户说「不行，感觉不是后处理能管用的，得原始模型和贴图就要改」，随后选择「两者融合一点」。移除全屏像素后处理；用 Blender 脚本重新制作建筑、树石、桥、矿架和蛋，两张 256×256 图集；地面使用世界 UV 和小纹理。之后修正方块墙式远山、同心台阶岩石和托盘式蛋轮廓。
5. **10-20 00:02–00:18，第 20 轮：当前最终版。** 用户说「还行，再试试更偏 roblox 一点的」。原三个资产子会话继续修改：建筑变成连续宽坡屋顶、粗切角门窗、十二边轮圈；树冠收成少量饱满削角体；河岸改连续坡面，道路嵌入地面，降低草和图集碎纹。00:13 发布，00:18 完成当时公开检查。这就是现在认可的方向。
6. **00:18 之后，第 21–24 轮：转向另一条光照样板线。** 用户提供 Petal Quay 视频，随后强调「最重要的是光，还有地面墙面材质适合这种光」，同意做一段地面、一面墙和墙角的小样。随后创建 `light-study/` 与 `/games/mining-light/`。后来继续到 [Continue Night Lighting Study](t3-thread://v1/eb1a436d-7846-414e-80c5-377416d556d9)。这是后续光材质研究，不是 mining-surface 当前画面的来源。

## 这个效果具体怎么做

- **构图：** 从南面的溪桥入场，弯曲主路通向后侧矿口。商店在左，宠物馆在右，次要工坊靠后；矿架最高，树群和山壁围合。留出道路与草地的空面，避免网格化等距摆放。
- **模型：** Blender 5.1.2 Python 脚本建模，保留 `.blend` 和生成脚本；宽坡顶、厚梁和明显切角提供实体轮廓。树为粗干和少量完整大块树冠，松树为三层整锥面。没有 Tripo 任务，也没有 Decimate。旧游戏模型没有作为这批资产来源。
- **纹理：** 两张 256² 图集，32px tile；清楚大色块上少量低对比木纹、瓦缝和石纹。使用 sRGB、近处最近邻、远处 mip 层，像素固定在 UV 上。正常屏幕分辨率，无全屏像素化。地形纹理由代码确定性生成。
- **灯光：** 主要哑光面为 Lambert 材质，暖方向日光配冷色半球补光；Neutral tone mapping；2048 阴影图，静态阴影缓存。天空环境只生成一次。AO 默认为关，保留诊断对照。这里的环境响应与当前游戏 PBR 材质不同，不能只复制灯强度便期待同样画面。
- **组织：** 静态空间合批，保留 UV、硬法线和颜色边界；全场景驻留，仅正常视锥裁剪。最终全场景 78,925 三角形，70 个静态批次，其中 63 个保留纹理 UV。静态样板按需绘制、最多一帧在途；可玩游戏有角色和昼夜更新，需要按实际动态更新条件接入。

关键源文件：`surface-study/tools/blender/build_architecture.py`、`build_nature.py`；`source-art/*.blend`；`src/assets.ts`、`landscape.ts`、`terrainTexture.ts`、`kit.ts`、`lighting.ts`、`main.ts`。`docs/direction.md` 描述最终设计；`docs/rendering-research.md` 同时含旧版历史，必须读最后的「进一步偏向 Roblox」章节，不能把前面 19 万面、52 draws 或像素模式当成当前值。
