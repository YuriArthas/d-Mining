# 按矿物来源分币种出售

用户确认跨世界不兑换货币：背包里的矿物卖回其所属世界的货币，与出售地点无关。

- 资源从经济层配置携带币种；普通岩石、致密岩石和矿石都走同一映射。
- 报价先按币种分组，对每组应用该币种的已装备宠物加成、重生倍率和双倍出售效果，再分别取整。
- 一次出售先检查全部金额和余额上限，再一次扣除可出售矿物、发放各币种金额、保存一次；任一币种溢出则整笔拒绝。锁定矿物和材料仓保持原规则。
- 背包显示分币种报价，每种矿物显示来源币种图标；卖出通知和头顶收益显示各笔金额。只有当前 HUD 显示的币种播放飞入该余额的动画，避免金币飞入科技币计数器。
- 四种语言的提示同步更新。没有调整价格、丰度或宠物合成规则。
