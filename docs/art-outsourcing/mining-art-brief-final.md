# Mining 挖矿游戏
# 美术设计与制作需求书

2026 年 10 月 21 日

## 一、委托内容

本项目为第三人称挖矿成长游戏，主要体验包括矿产采集、装备成长、宠物收集和世界探索。本次委托制作完整游戏所需的场景、角色、物品、界面及配套美术资源，全部内容统一设计、一次性交付。

画风、世界主题、物品命名、角色与宠物形象、场景布局及界面布局由美术承接方提出。现有游戏与参考截图仅用于了解游戏内容，不作为视觉设计的限制。

界面为本次委托的重点，需重新设计信息组织、功能入口、完整画面及操作过程中的视觉表现。

## 二、场景美术

### （一）世界与矿层

制作三个完整世界，每个世界包含一个表层和六个地下层。各世界及矿层应具有可识别的环境特征，使玩家能够辨认所在区域，并感受到探索内容的变化。

表层用于玩家到达、休整、补给及前往矿区；地下用于持续采矿、发现新区域及获取收集物。场景设计包括地形、矿区环境、功能设施、装饰物、地标与引导标识。空间组织、行进路线及设施组合由美术方案确定。

地下场景需包含可挖掘方块组成的矿区及配套环境，并在视觉上区分可采集资源、不可采集环境和通行区域。各层之间需有到达新区域的表现，第六地下层需体现该世界探索区域的终点关系。

### （二）功能设施

| 制作内容 | 用途与表现要求 |
| --- | --- |
| 到达与返回区域 | 用于初次进入和返回表层，配有世界或区域识别信息 |
| 矿区入口及引导 | 使玩家能够辨认采矿区域，找到进入和返回的方向 |
| 矿产售卖设施 | 表达出售矿产的用途，配有可识别的交互范围与售卖表现 |
| 装备购买设施 | 用于查看和购买工具、背包，包含相应展示与标识 |
| 宠物蛋展示设施 | 每区域配置对应蛋的展示，名称与价格常驻可见，接近后出现查看提示 |
| 旅行设施 | 用于选择和前往其他地点，包含设施形象、目的地识别及旅行表现 |
| 挑战记录展示 | 用于展示采矿深度成绩与个人记录，包含场景展示及相关标识 |
| 幸运扭蛋设施 | 用于免费抽取奖励，包含装置形象及抽取表现 |
| 重生入口标识 | 用于识别重生功能；是否采用独立场景设施由整体方案确定 |

三个世界的表层均需具备完整的主要功能设施。地下层配有对应矿区、宠物蛋及售卖、返回等服务的识别内容，装备补给方式由整体场景方案安排。设施可以按用途组合，具体位置与外形不作预设。

### （三）世界大门与矿区入口

制作两道可供玩家实际穿过的实体大门，分别用于进入第二、第三世界。大门需包含关闭、打开过程及开放后的表现，并配套目标世界、开放要求和进度的展示。

另制作两处后续世界的矿区入口。其用途为进入该世界的采矿区域，需具备尚未开放和已经开放的视觉区别，并与世界大门保持功能上的可辨识性。入口条件的界面内容见第四节。

### （四）环境表现

表层需提供昼间与夜间的环境表现。矿口、通路及重要设施在不同环境下均应便于辨认。场景物件、设施标识和界面中的对应图像应保持一致。

## 三、角色与物品美术

### （一）玩家角色

制作一名玩家角色，包含角色模型、外观贴图及配套动作。动作范围包括待机、移动、跳跃、下落、落地与持续采矿，采矿动作需适用于前方及向下的目标。

角色需能够持有本次制作的各类工具并携带背包。工具形态变化时，应配有相适应的持有与使用表现。角色、装备和宠物同时出现时，应保持角色动作与采矿目标的清晰度。

### （二）挖矿工具与背包

制作 30 款挖矿工具，用于角色采矿及装备购买展示。前期数款保留可辨认的镐子形态，后续工具可采用其他形态或抽象造型。各款需具有可辨认的形象差异，配齐持有、使用及展示所需内容。

制作 30 款背包装备，用于角色携带及装备购买展示。各款需具有可辨认的外观差异，体现装备成长。背包形态与成长表现方式由美术设计，不限定以体积递增表达。

### （三）可采集资源

制作 84 种可采集资源，每区域 4 种，包括常见基础资源、较难开采的基础变体及两种特色收集资源。资源形象与命名由美术设计。

资源用于矿区采集、背包展示、出售及部分入口条件展示。每种资源需具备场景中的采集形象及对应展示图，配套受损、破碎与获得表现。相同类型的通用效果可合理共用。

### （四）宠物蛋

制作 21 组宠物蛋及展示内容，每组与所在区域及对应宠物形成可识别的联系。制作范围包括场景中的蛋、界面展示形象、开蛋过程及结果揭示表现。

### （五）宠物

制作 105 种宠物，每组蛋对应 5 种。宠物用于收藏、跟随及展示成长收益，需包含模型、外观贴图、待机和跟随动作，以及详情、图鉴和获得结果所用的展示形象。

宠物设四个稀有层级，需设计配套的识别表现。稀有度、新发现与重复获得的展示应能区分。宠物不承担战斗表现。

## 四、游戏界面设计

界面需完成整体重新设计，包括信息层级、页面组织、交互引导、视觉样式及配套图像。以下按功能列出设计内容，不限定页面数量或布局，相关功能可由美术方案合理组合。

| 功能内容 | 需要设计的画面与展示内容 |
| --- | --- |
| 游戏入口与加载 | 开始、继续、加载过程及加载未完成时的提示 |
| 游戏主画面 | 所在世界与矿层、金币、背包容量、采集目标与进度、常用功能入口 |
| 新手引导与帮助 | 操作提示、目标引导、功能说明及回看入口 |
| 矿产背包 | 资源列表与详情、数量与容量信息、用于防止出售的材料保留标识及操作 |
| 出售矿产 | 售出内容、获得金币、留下材料及没有可售资源时的提示 |
| 工具与背包商店 | 商品列表、详情、当前与目标装备比较、购买及装备结果 |
| 宠物蛋查看与开蛋 | 蛋的展示、价格、宠物预览、各宠物概率、开蛋演出及获得结果；概率直接呈现 |
| 宠物管理 | 已有宠物、属性与稀有度、装备阵容、比较与替换、筛选及一键最佳操作 |
| 宠物图鉴 | 已发现与未发现的宠物、收集进度及获取地点提示 |
| 世界与矿层旅行 | 世界与区域选择、当前位置、目的地展示、可前往与尚未开放的区别 |
| 世界大门与矿区开放 | 开放要求与进度、所需材料及金币的展示、条件不足提示、缴纳确认和开放结果 |
| 重生 | 功能介绍、成长收益、保留与重新开始内容的说明、确认画面及完成表现 |
| 在线奖励与签到 | 奖励内容、等待与领取进度、可领取标识及领取结果 |
| 分享与邀请码 | 功能说明、填写与提交、领取结果及未完成提示 |
| 幸运扭蛋与能力 | 奖励预览及概率、抽取与结果、获得的能力、生效标识和剩余时间 |
| 挑战记录 | 各世界采矿深度成绩、个人记录与成长进度 |
| 设置 | 音乐、音效、操作说明、界面可读性及宠物显示相关选项 |

设计应包含空内容、已选中、已拥有、已装备、尚不可用及操作完成等必要画面与标识，并配齐按钮、窗口、标签、提示和通用控件。涉及购买、缴纳和重生的画面，应清楚呈现操作前的说明、确认及结果。

重点设计装备比较、宠物获得后装备或替换、材料保留与出售、世界开放及重生等过程，使相关画面能够连续衔接。返回、关闭及继续操作的入口应清楚，常用操作与重要信息应便于找到。

## 五、配套图像与动态表现

### （一）物品与地点展示图

制作 270 份物品展示图，分别对应 84 种资源、30 款工具、30 款背包、21 组蛋及 105 种宠物，用于列表、详情、比较、获取结果和条件展示。

制作 24 份地点展示图，分别对应 3 个世界及 21 个区域，用于旅行选择、区域识别及探索目标展示。构图与表现方式由美术方案确定。

### （二）功能与状态图标

制作游戏实际使用的完整图标，包括金币、幸运币、容量、采矿力量与速度、宠物加成、世界与矿层、旅行、材料保留、重生、收藏、奖励、设置及帮助等。

配齐稀有度、已装备、已获得、未发现、尚未开放、可领取等识别标记。图标、物品展示图和场景形象应相互对应。

### （三）动态表现

| 表现内容 | 制作范围 |
| --- | --- |
| 采矿与资源获得 | 工具作用、目标受损、资源破碎、资源获得及无法继续采集的提示 |
| 出售与装备成长 | 金币获得、装备购买、更换与提升表现 |
| 宠物获取与使用 | 开蛋、宠物揭示、新发现、稀有度展示及装备变化 |
| 探索与旅行 | 新区域到达、出发与抵达、实体大门打开及矿区入口开放 |
| 免费奖励与能力 | 幸运扭蛋、奖励领取、能力获得、生效及结束 |
| 重生 | 确认后的演出、完成及成长收益展示 |
| 界面操作 | 窗口与提示出现、按钮和选中反馈、确认及结果展示 |

动态表现可结合角色动作、场景变化、特效与界面动效制作。日常采矿与获得反馈应适于连续游玩，重要收集和阶段成长应具有明确的结果表现。

### （四）入口与宣传素材

制作游戏字标 1 份、游戏图标 1 张、加载图 1 张、宣传图 2 张，内容表现挖矿、装备成长、宠物收集及世界探索等实际游戏体验。正式名称与宣传构图由整体方案提出。

### 文件形式

三维美术资源统一以 Blender 工程（.blend）交付，包含完整模型、材质及动作，并附所用贴图。

UI 统一以可编辑的分层 PSD（.psd）文件交付，包含完整界面及各界面元素，附配套图片素材。其他平面与宣传素材提供可编辑源文件及成品图片。动态内容提供制作素材及效果演示，场景提供整体展示及资源对应说明。

无需制作或交付 Roblox Studio Place。

### 交付方式

全部成果整理为一个完整交付包，以 ZIP 格式打包，通过网盘或双方约定的共享盘提供下载链接。交付包以项目名称、交付日期及版本命名，制作源文件、配套素材、图像成品与预览资料须在同一次交付中提交。

文件按设计方案、场景、角色与物品、界面、动态素材及宣传素材分类整理，源文件、图像成品和预览资料分别存放。随包附资源清单，注明资源名称、类别、数量及对应文件位置；源工程使用的贴图等必要素材一并提供。

在线预览链接、截图和演示视频用于辅助查看，不能代替 Blender 工程及分层 PSD 文件。

### 完整性要求

各项成果应与制作范围逐项对应，数量齐全，场景与界面所需的配套内容完整。所有文件应与最终设计一致，能够明确识别其对应世界、区域、物品或功能。

本次委托交付完整制作成果，包含设计方案所使用的模型、贴图、动作、图像与界面素材。
