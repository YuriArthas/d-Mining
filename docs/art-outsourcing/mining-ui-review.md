# Mining 界面需求复审

2026-10-20 · 对照 V3.0，修订为 V3.1。

结论：上一版列全了功能，但还不足以指导一套好懂、好用的界面。玩家需要的是知道自己要做什么、这次选择有什么用、做完后怎么继续。只列“有背包、有宠物、有重生”不能保证这一点。

| 玩家会遇到的困惑 | V3.0 的缺口 | V3.1 的处理 |
| --- | --- | --- |
| 刚进游戏，到底先点哪个？ | 十五类功能并列，没有讲清出现时机与主次 | 主画面围绕挖矿、金币、容量与位置；教学随经历展开；奖励、设置和完整属性主动打开 |
| “背包”是装矿，还是买容量？ | 同一个词同时指矿产管理和装备 | 区分“矿物背包”与“装备里的背包”；宠物管理与图鉴也明确归属 |
| 80 块钻石只要留 30，另外 50 怎么卖？ | 按种类全部锁定，无法顺手保留所需数量 | 世界备料按需求保留，之后采到自动补足、多余可卖；手动全部保留仍可使用；显示总量、保留量和可售量 |
| 我已经带满三只，新宠物更好怎么办？ | 列了装备功能，没有把开蛋结果接到具体替换 | 结果直接比较，明确将替换谁；可直接装备或暂不装备；管理页定位新宠物 |
| 点“前往”会发生什么？ | 随时查看、现场购买、指路与传送的边界不清楚 | 明确各功能何时可用；区分“指引我过去”和实际传送；完成后有明确返回路径 |
| 我有 500 万，为什么还不能重生？ | 上版额外添加新矿收入条件，要求辨认矿产来源和两种金币进度 | 撤销我额外添加的收入条件；重生只看当前金币，确认前明示清空全部余额 |
| 重生后世界还开着，为什么不能挖、包还满？ | 规则分别写了，完成后的实际处境没有接通 | 区分世界开放与工具能力；落在售卖区外；保留材料超容时解释原因并接到售卖、管理或扩容 |

界面章节已按完整游玩过程重写。保留十五类功能覆盖用于查漏，但主要说明使用具体故事、选择和结果。没有规定美术风格和布局，原有模型、宠物、矿产及图标制作数量不变。

这次是对需求逻辑与说明清晰度的审查，尚未验证重新设计后的实际界面。后续看界面方案时，直接用第 7.11 节的六段玩家经历检查能否连贯完成。
