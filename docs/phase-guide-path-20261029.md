# 新手引导：沿路的箭头（2026-10-29）

用户反馈：第一次挖矿时的引导箭头不好看，而且会穿过出生点前面的桥。

## 原来的问题

旧箭头是一张平面的卡通箭头图片（`roblox-arrow-v1.webp`），从脚下拉一条直线到矿坑入口：
- 高度只比脚高 0.4 米，而拱桥最高处比路面高 1.15 米，直线的中段埋进了桥面里；
- 箭头头部远在矿坑那头，人身边只有一截细黄线；
- 走的是直线，不管实际路线。

## 选定的样式

先讨论了三种方向（沿路箭头带、脚下指向加终点标记、地上脚印），用户选沿路箭头带。然后用 Image 2.5 在出生点实景截图上画了 4 个版本：
- A：白色光带加青色箭头；
- B：青绿光带；
- C：白色立体箭头加深蓝描边、不画光带；
- D：粉紫光带。

用户选 C。效果图和提示词在 `output/imagegen/guide-path-20261029/`，`manifest.json` 记录了模型、输入截图和各张图的哈希。

## 做法

- **路线**（`src/game/world/guideRoute.ts`）：
  - 从小河南岸去矿坑时，先到桥南头，再到桥北头，然后去矿坑口；
  - 同在一岸时直线过去；
  - 人在桥上时先到桥的另一头。
- **箭头**（`src/game/presentation/guidePath.ts`，组件在 `GuidePath.tsx`）：
  - 一个个白色 V 形立体箭头，后面衬一圈深蓝描边，用一个实例化网格画；
  - 每 1.7 米一个，以 1.6 米/秒往前滚动；
  - 每个箭头放在它下方实际表面高度上方 0.26 米处，表面高度用物理射线往下取（`CharacterPhysics.surfaceBelow`，排除玩家自己的碰撞体），所以过桥时顺着桥拱起伏；
  - 再按坡度往镜头方向翘起约 34°；
  - 射线从脚上方 1.6 米往下打，命中点太高（比如打到灯柱顶上）就不用，沿用上一个箭头的高度；附近没有加载碰撞体的地方，同样沿用上一个高度。
  - 靠近人和终点的几个箭头逐渐缩小来代替淡出，全部不透明、不受光照，所以在沙地、草地、木桥上都同样清楚，也不需要半透明排序。
- **终点**：矿坑口上方 2.6 米处一个朝下的白色大箭头，同样白面深蓝边，上下弹跳，并始终转向镜头。
- **出现时机不变**：只在第一次挖矿的提示期间、人在地表还没到矿坑时出现，离终点 2 米内消失。屏幕上"去矿坑挖矿"的标签保留。
- 旧箭头组件、图片和它的预处理脚本 `tools/prepare-guide-arrow.py` 都已删除。

## 验证

- 单元测试 `tools/tests/guide-path.test.mjs`：
  - 路线会经过桥两头，同岸直走，人在桥上时走到另一头；
  - 箭头和终点标记都是白面在前、深蓝边在后，箭头尖朝 +Z；
  - 用世界 1 的真实场景碰撞体铺三帧，桥上每个箭头都高于桥面至少 0.1 米，终点标记在矿坑口上方。

  全量 515 项通过。
- 公开版检查 `tools/check-guide-path.cjs`，截图在 `output/guide-path/`：出生点、侧面看桥、站在桥上、走到矿坑附近。
