# P3F：各层 8×8 对齐入口与固定表皮

> 历史阶段记录。最新十层配置、场景、资源和落点见 [S1 实现记录](phase-scene-themes.md)。

状态：实现、本地与公网验证完成。难度 **40/100**。本次调整布局与开采边界，美术整理后续继续。

## 当前规则

- 地表入口为 8×8 格（16×16 米），水平格坐标 x、z 均为 -4～3。
- 400 米、800 米两处 20×20×10 格房间中心统一为 x=0、z=0，地板入口与地表使用同一组坐标。
- 表皮厚一格：地表在 y=-1，地下房间地板在 y=-201、-401。入口内保留正常矿物，入口外为不可开采的固定地面。
- 地表保护覆盖矿区表面；地下保护覆盖各房间的 20×20 地板，房间外的矿体不增加横贯整个世界的屏障。
- 向下穿过表皮后恢复普通矿体，可以向四周开采，不限制为 8×8 竖井；房间顶和墙仍可挖。
- 地下落点为 [0, -深度+0.1, 14]，售卖圈 [-12, -深度, 12]，800 米商店 [12, -深度, 12]，均位于固定地板上、入口以外。
- 地表坡道收至入口边缘，不覆盖 8×8 可挖区域。旧碰撞测试场和浅井仅保留在显式 `?debug=1&samples=1` 验证模式。

## 实现边界

- `world/entrance` 定义共享入口；`world/rooms` 定义对齐房间及服务点；`SparseWorld` 是保护属性的逻辑来源。
- 固定地面为第 7 个地形材质，不是背包物品，不参与矿物概率、HP、掉落和售价。六种矿物定义不变；共享图集由 24 KiB 增至 28 KiB。
- 选中、战斗读取、批量挖除入队、实际删除和待构建修改快照都遵守 `canMine`，固定地面不扣血、不消费攻击冷却、不产出奖励。
- 这不是新增可见性检查：可挖矿物仍只受原有 4 格攻击距离限制。
- 固定地面沿用体素渲染合并和独立碰撞合并，不额外叠加一层普通平台碰撞。房间招牌、圆圈与入口边框仍按距离加载、卸载。
- 地形生成版本升为 5，仍按坐标生成，不存储密集方块数组。
