# 地表光线色调（2026-10-23）

用户反馈地表“光影还是差了点，总觉得灰蒙蒙的”，判断是“色调问题，光线色调”。这一轮只调光线的颜色和强弱比例，加一层几乎不花性能的调色；不改模型、贴图、布局，也不加实时阴影（用户此前在“地表光照渐隐”阶段明确过不恢复实时阴影）。工作区 `/root/.t3/worktrees/d-Mining/surface-roblox`，基于 `35b72e9`。

## 原因

对照之前认可的样板（`/games/mining-surface/`，松风矿谷 `surface-study/src/lighting.ts`）和游戏实际生效的白天参数（`pinewindSurface.ts` 覆盖了基础配置）：

| | 样板（PBR 配置） | 游戏改前 |
| --- | --- | --- |
| 太阳 | `#fff5de` × 3.0 | `#fff2d9` × 2.15 |
| 天空/地面补光 | `#b5daff` / `#667b93` × 0.55 | 青色 `#c6e7ff` / 绿色 `#78954e` × **1.25** |
| 环境光（天空图） | × 0.35 | × 0.55 |
| 曝光 | 1.0 | 1.08 |

改前平地上补光和太阳差不多亮，绿、蓝两个通道里补光甚至更强：受光面和阴面几乎一样亮，阴面整体泛青，亮的沙地和草地又被曝光推向白色，于是发灰、发雾。另外天空里画出的太阳和天空环境光仍按基础配置放在西北，而真正的光从西南来。

## 改了什么

- **白天光**（`PINEWIND_DAY`）：太阳 `#ffeed2` × 3.18，从西南、进场玩家身后照来；补光改成几乎中性的 `#d9e4ea` / `#867f5c` × 0.38；环境光 × 0.163。强度按全局曝光 1.08 折算（等效于曝光 0.98），所以地下和夜晚的亮度不受影响。天空里的太阳和环境光改用同一个方向。
- **调色**：在色调映射里接一步轻调色（`src/game/presentation/toneGrade.ts`）：Neutral 色调映射之后，在显示空间加一点中间调反差，绿色饱和度 × 1.14，其余 × 1.03，接近白色时柔和收住。它在每个材质自己的着色器里完成，不额外渲染一遍、不复制画面，天空（不参与色调映射）不受影响。原有的“风格化”全屏调色仍只是调试选项。
- **调试工具**：`__miningValidation.lightingLook()` 可以实时换一组光线参数、曝光、调色开关和房子材质参数（不重载页面），用于同机位对比；`tools/check-lighting-tone.cjs` 在公开入口按固定白天、隐藏 HUD 拍四个机位的各个方案并输出颜色统计。

## 怎么选的

在公开入口上用同一机位对比了七组方案（样板原值、样板哑光值、偏暖、加强日光、加强日光 + 全屏调色、加强日光 + 偏绿调色等）。只改光线时饱和度从约 0.50～0.55 升到 0.61～0.64；全屏调色再加强会把广场沙地推成橙色；最终选“加强日光 + 只偏绿的调色”，草地接近样板的深绿，沙地保持暖棕。

## 第二轮：房子变暗（用户：“总的色调不错，但是房子变暗了太多；材质改改，本身也增加饱和度和明度”）

- **原因**：所有手工建模的资产（房子和地形）加载时都把环境光关掉了（`envMapIntensity = 0`），它们的阴面只靠天空/地面补光。补光从 1.25 降到 0.38 后，面朝广场、背对西南太阳的出售和商店正面只剩原来约三成的光。白墙本来就接近最亮，单靠提亮贴图提不上去（测得只从 0.26 到 0.29）。
- **改法**（`src/game/presentation/albedoLift.ts`，只作用于建筑资产这一个材质：房子、矿架、桥、蛋台、蛋、传送门）：
  - 贴图颜色在显示空间提饱和 × 1.25、做一次 gamma 提亮 × 1.2（黑白两端不动、中间调变亮）。
  - 白天墙面和底面多吃一份补光（× 3.6，带一点暖色），相当于被太阳晒着的沙地广场反射到房子正面的光；朝天的面（屋顶、台面）不加，免得发白；这份光随日光淡出，夜里房子不会发亮。
  - 地面、草地和其余画面保持上一轮认可的色调不变。
- **试过的方案**：只提亮贴图（不够）；加强全场补光并把地面反射色改成暖沙色（房子能亮回来，但地面跟着变浅、整体又发灰）；暗天空色配亮地面色（墙面最多只能拿到补光的一半，到 0.37 封顶）；最后用只给建筑加反射光的办法。
- **结果**（广场看出售和商店，房子区域）：亮度 改前 0.41 → 上一轮 0.26 → 现在 0.39，饱和度 0.66 → 0.78 → 0.72；整幅画面饱和度保持 0.65（上一轮 0.66，最初 0.53）。夜里与上一轮几乎相同。截图在 `artifacts/house-final/`。

## 验证

- TypeScript 与 Vite 构建通过。全量测试 514 项：510 通过，4 项失败与改动前相同（contact-bake、quarry 资源清单、quarry 庭院碰撞、旧道路）。新增 `tools/tests/lighting-tone.test.mjs`（4 项：太阳在西南且天空太阳同向；平地上直射光至少是补光的 2.5 倍、补光颜色接近中性；游戏使用带调色的色调映射；房子材质只打一次补丁、白天墙面暖色反射光、夜里收掉）。
- 先发布到公开试玩入口（`artifacts/lighting-tone-release.json`），再用 `tools/check-lighting-tone.cjs`（Android UA、触控、横屏 844×390、DPR 2、SwiftShader）拍同机位前后对比：“改前”由调试接口实时还原旧参数，统计与改前基线逐位一致。白天四个机位画面下 70% 的平均饱和度：出生点 0.55 → 0.70、出售商店 0.50 → 0.63、蛋台 0.53 → 0.66、反向 0.49 → 0.63；出售商店一侧的明暗反差 0.32 → 0.46。夜晚和老矿井只略增饱和与反差（0.54 → 0.59、0.40 → 0.42）。截图在 `artifacts/lighting-tone-final/`。
- 颜色判断以真实屏幕为准：这里是软件渲染的截图，没有在真机屏幕上看过。

## 尚未覆盖

- 夜晚和地下的灯光没有重新调。
