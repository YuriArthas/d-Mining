# S1：主题配置、三十种资源与场景首版

状态：实现、本地与公网回归完成。用户已授权从场景 Draft 开始制作；本阶段所有主题都有基础表现，画风与手感仍待用户实看，真实手机 60 FPS 未验收。

后续反馈：用户确认功能正确，要求逐场景精修；第二轮改动和静态缓存阴影见 [S1.1](phase-scene-polish.md)。下文保留首版交付记录。

## 本轮交付

- 十个主题和三十种资源已经进入游戏，详见 [场景 Draft](draft-scene-themes.md) 的名单。0～4000 米分十段，地表加九个地下营地；主题与深度分离。
- `content/themes.ts` 只定义表现主题；`content/resources.ts` 唯一维护资源身份、外观引用和物品属性；`content/layers.ts` 是深度、生成分布和设施安排的来源。
- 生成配置显式随任务送入 Worker。`roomsFor` 从同一楼层表派生房间、解锁和传送落点；楼层 ID 不再包含深度。生成版本为 6。
- 六种旧资源保留原物品 ID 和 HP/容量/售价，固定地面 kind=7 仍不是资源。其余资源用临时值；楼层预计售价/容量及平均 HP 随深度增加，但完整成长节奏仍未平衡。
- 每层入口仍为 8×8，保护表皮一格厚，下方自由扩挖。地下落点前移至 z=11，为第三人称镜头留出身后空间。
- 地表售卖圈移到 [-12,0,12] 的收购摊前。原家中平台变成木质出发平台，返回落点和家中传送范围保留。九处地下营地均可售卖，800/1600/2400/3200/3600 米有升级摊。

## 场景和表现

- 地表：草地、木构矿口、牌匾、收购摊、矿车轨道、木箱、树群、岩石和路径石。
- 老矿井：厚木支架、暖色灯笼、轨道、矿车和堆叠木箱。
- 其余主题：蘑菇群、晶簇、遗迹柱、冰晶、熔岩色岩柱、骨架与头骨、能源机械、地心晶体。统一设施结构，各主题替换颜色与标志物。
- 本轮以代码生成低多边形几何和纹理，未下载外部美术资产。矿纹使用较大形状、低对比岩底，保留按 HP 显示的既有裂痕。
- 一个场景的普通装饰合并为一个顶点色网格，发亮部分另合并一个网格，牌匾独立贴图；不为每块矿创建 Mesh，不使用大量实时点光或动态阴影。
- 地面远景去掉高频噪声，加入少量几何接触色块；灯笼和晶体的亮部主要使用材质表达。
- 默认镜头距离由 7.5 米调整至 10.5 米，初始俯角 0.35；碰撞就绪范围同步覆盖 12 米。原有自由转向、避障和贴墙角色淡出保留。开启抗锯齿，像素比上限仍 1.5。
- 环境色按所在主题渐变；基础岩体和矿物外观按方块逻辑来源决定。首版没有为每种矿制作十套主题变体。
- 背包只列已持有资源，列表限制高度；传送列表独立滚动，让九个目的地在手机中可用。未开展整套 UI 美术重做。

## 独立合并与驻留

- 渲染按最终图集槽位和面朝向合并，固定地面在各主题有独立外观；碰撞只读实体占用，忽略主题和矿物。
- 共享图集为 40 个 64×64 tile（30 资源加 10 固定地面外观），RGBA 原始数据 640 KiB。稳定 kind 与图集槽位显式映射。
- 地形仍采用原有程序化采样加稀疏编辑，渲染区域 16³、碰撞区域 8³，各自 Worker 与生命周期。
- `world/scenery.ts` 输出普通设施的纯几何/碰撞描述；`SceneryMesh` 负责批次合并与纹理释放；`RoomFacilities` 管理驻留。
- 普通场景表现进入 54 米、离开 78 米；每个普通碰撞体单独在 12 米内创建、22 米外卸载。普通碰撞不依赖视觉网格存在，体素地板没有叠加第二套碰撞。
- 场景切换释放旧几何、材质与牌匾纹理；装饰不参与开采、掉落、售卖或体素编辑。

## 查看方式

- 正常入口从草地矿场开始，按深度解锁地下营地。
- 验证入口 `?debug=1` 增加“选择主题场景”下拉框，直接定位十个场景，不必为看美术先挖几千米。
- 可以通过 `?debug=1&layer=old_mine` / `crystal` / `core` 直接查看某个地下场景；这是调试入口，正常游戏不自动解锁。
