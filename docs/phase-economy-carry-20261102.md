# 分层矿价、基岩体积与背包联合重算（2026-11-02）

本轮仅发布 mining-test。iPhone 14 Pro 兼容性按用户要求搁置。

## 落地规则

- 保留再次减半后的矿物丰度：每个世界依次 4.5%、4.9%、5.35%、5.75%、6.15%、6.6%、7%。
- 普通基岩、致密基岩的基础售价统一为 1。原有宠物、重生和出售增益继续应用；矿价不是占位单价。
- 基岩体积按 `HP / 20` 取两位有效数字、最低 1。HP 不变。起始普通基岩占 1；后期普通基岩达 150,000，致密基岩最高 1,500,000。矿物继续占 1。
- 相邻层普通矿基价：第一世界倍率 3 / 3 / 3.5 / 4 / 4.5 / 5；第二世界 3 / 3.5 / 4 / 4.5 / 5 / 6；第三世界 3.5 / 4 / 4.5 / 5 / 6 / 7；每次取整，稀有矿约为普通矿的两倍。
- 世界仍各自使用独立货币，新世界基础矿价从 3 重新起步，不把不同货币直接比较。宠物、工具伤害/速度、层级门槛、地形和矿物概率不变。
- 背包容量依据该档镐子的伤害、攻速、方块 HP、矿物概率和平均占位计算。参考 +100% 宠物挖掘加成，普通挖掘约 45 秒满包，档位之间至少增长约 25%。初始 25；第 2 档 130，价格 17；最终 14,000,000。
- 背包价按该档首次需要时约 30 秒的到手收入计算，同世界价格递增。工具、强化、蛋、宠物槽和世界票成本一起重新校准。

## 模拟口径与限制

`tools/economy/model.mts` 联合计入 HP 对应挥镐次数、宠物挖掘加成及攻速上限、对准/移动、矿物丰度、基岩占位、整块超容、出售往返、背包/工具/蛋购买、2×2 下挖、门票材料和奖励。

背包作为正常购买目标参与决策：参考装载时间不足 35 秒，或容不下两块致密基岩时，选择当前货架满足目标的背包，允许跳档。模型假设玩家锁住世界票需要的材料，满额后出售剩余；保留的材料不再重复计入出售收入。实际游戏仍由玩家手动锁定。

15 个种子随机化宠物和扭蛋奖励，矿物采用期望混合比例，并非 15 次完整随机地形通关。每个游戏日按 120 分钟活跃时间计；通关目标为每世界约 2/4/6 小时。

实际逻辑探针：`ONLY=0,1,2,3 node tools/economy/measure-headless.mts 3`，使用 GameSession、体素和角色物理、无渲染。四段各约 3 分钟，覆盖世界 1 层 1/4、世界 2 层 3、世界 3 层 5。均完成挖矿和出售，卖矿往返分别约 4.1/5.0/12.5/7.9 秒；模型改为表层和地下分别估计。短段实测收入与期望模型约 0.96～1.60 倍，矿物采样少且存在走位差异，不能当作整段通关时间的实测证明。

旧测量脚本假设每次出售回地表，并强行走向地表传送站；当前游戏出售落在上方最近大厅，已改为直接使用便携传送返回。旧失败记录保留于 `output/economy-carry/headless-old-route.*`；修正结果为 `headless.json`。主模型报告为 `model.json`。

## 存档与 UI

- 装备持久化改为版本 2，以稳定的背包档位记录最高已购、当前装备、跳档购买集合；容量从当前目录派生。
- 版本 1 按发布过的 25～500 容量表迁移，不猜测未知容量。保留低档装备选择、跳档缺口、矿物数量和锁定；存量超容仍可出售或升级。
- HUD 显示“容量”和已用/上限；挖矿标牌与矿物背包格显示每块占用。大数按各语言数字单位缩写。沿用既有美术图标，无新增美术资产。
