## 规则与临时配置

深度单位为米，1 格 = 2 米。矿块按其顶面深度归属矿层：顶面 398 米的格子仍属于浅层，顶面 400 米的格子开始属于金矿层，800 米同理。房间位置和解锁门槛不参与矿物生成。

| 深度 | 名称 | 基础岩层 | 煤 | 铜 | 金 | 水晶 |
| --- | --- | --- | --- | --- | --- | --- |
| 0 ≤ 深度 < 400 米 | 浅层矿区 | 岩石 80% | 12% | 8% | 0 | 0 |
| 400 ≤ 深度 < 800 米 | 金矿层 | 深层岩石 60% | 8% | 16% | 16% | 0 |
| 深度 ≥ 800 米 | 水晶矿层 | 深层岩石 45% | 0 | 10% | 25% | 20% |

- 分布仍按世界坐标和种子生成连续的 3×3×3 矿团，跨区块保持一致；矿层边界允许截断矿团。不逐格随机，不建立体素或矿团缓存。
- 同一种矿物在任何深度都使用相同的 HP、体积、单价；该表只返回矿物 ID。沿用六矿数值、力量/攻速成长、升级价格与背包档位。
- 视觉复用现有矿物材质：浅层灰色岩石，深处蓝色岩层，高价值金矿和水晶逐层增多。顶部状态显示当前矿层名称和米数。
- 正式世界及单独 `?debug=1` 都使用真实矿层。地表六矿条带只在显式 `?debug=1&samples=1` 验证入口开启；对应合并调试按钮只在该模式展示。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| terrain/strata | 深度区间、基础岩层、矿团权重、确定性 ID 查询；不依赖房间或经济模块 |
| application/items | 每种矿物固定的 HP、体积、售价；不接收深度参数 |
| world/rooms | 房间空洞、设施和解锁深度，保持独立 |
| SparseWorld | 逻辑生成源与稀疏修改；生成配置在创建会话时固定 |
| RegionPipeline / Worker | 将同一份生成配置传给两条独立合并管线，避免主线程、渲染和碰撞使用不同世界 |
| UI | 展示层名与现有矿物属性，不推算经济规则 |

生成版本升至 4。配置包含版本、种子和显式测试矿样开关；主线程和 Worker 使用同一配置。编辑快照仍只传稀疏修改，不存完整 16³ 方块数组。

## 粗略节奏校核

以下为按配置权重计算的**连续敲击期望**，不含寻矿、移动、售卖往返、加载、满包最后一格的溢出或升级决策；不是实测通关时间。相同矿团会让短程体验产生波动。

| 指标 | 浅层 | 金矿层 | 水晶矿层 |
| --- | --- | --- | --- |
| 平均单格占用 | 1.56 | 3.84 | 6.90 |
| 平均单格售价 | 3.04 | 12.00 | 29.40 |
| 平均单格 HP | 21.2 | 68.4 | 142.5 |
| 每容量平均售价 | 1.95 | 3.13 | 4.26 |
| Lv.1 挖 200 格的连续攻击时间 | 212 秒 | 684 秒 | 1425 秒 |
| Lv.6 挖 200 格的连续攻击时间 | 64 秒 | 110 秒 | 212.5 秒 |
| Lv.11 挖 200 格的连续攻击时间 | 27 秒 | 41 秒 | 71.25 秒 |

浅层 Lv.1 填满约 50 容量的纯攻击时间约 34 秒，期望售价约 97 金币。现有 Lv.1→6 的总价 45 金币、首档背包升级 20 金币，因此首轮出售可以带来明显成长；暂保留这些偏快的 MVP 价格。正式升级节奏、到达营地总时长在人工试玩后再调，不据此承诺真实分钟数。
