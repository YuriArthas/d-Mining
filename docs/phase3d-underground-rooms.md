# P3D：地下房间、深度解锁与家中传送

状态：实现、本地和公网验证完成。整体难度 **45/100**。

## 已确认的规则

- 首批两个局部房间，平台深度分别为 400 米、800 米（200 格、400 格）。房间水平 20×20 格，高 10 格，向平台上方留空；不横贯矿区，不保证玩家挖中房间。
- 解锁只取玩家实际到达的最大深度，不要求进入房间。地面为 0 米；为抵消物理接触间隙，站立时允许 0.04 米误差，空中使用实际深度。
- 回到地表家中可通过 HUD“传送”选择已解锁房间。落点在永久平台上、售卖圈外；先准备目的地附近碰撞，再放置角色，不在未加载地形中下落。
- 两个房间均有售卖圈，进入自动卖。800 米房间另有升级商店，踩入打开、离开关闭，关闭后重新进入可以再打开。商店界面不占用移动摇杆，仍可走出圆圈。
- 保留现有随时打开的升级 UI；商店暂时复用同样的镐子/背包升级 API 和数值。
- 只有小块服务平台为普通固定地形；其他房间地板、墙和顶仍可挖。背包、金币、损伤和挖掘改动不因传送清空。
- 解锁只保存本局内存，刷新重置。正式存档、宠物、新商品和深度数值平衡均后置。

## 模块边界

| 模块 | 职责 |
| --- | --- |
| world/rooms | 坐标、深度门槛、房间范围、平台和服务点配置 |
| SparseWorld / roomAir | 根据坐标查询空洞与平台预留空间，不创建体素数组、不添加挖除记录 |
| Exploration | 独立的最大深度与里程碑解锁，不知道房间形状、渲染或物理 |
| RoomFacilities | 普通平台、招牌和圆圈；渲染与碰撞分别按距离创建、释放 |
| ZoneDetector | 进入/离开区域，只给出区域状态 |
| GameSession | 接线多售卖点、商店状态、家中传送资格；售卖/升级复用原 API |
| ValidationScene | 地形加载准备、放置角色、重置输入和相机；准备期间不推进角色 |
| SessionUi / TravelPanel | 展示目的地与解锁状态，发送传送命令；商店展示与手动升级分开管理 |

房间尺寸与矿物网格共用 `CELL`；生成版本升至 3。矿物渲染合并继续按材质，碰撞合并继续只按占据，两条管线及驻留范围保持独立。普通平台渲染 54 米加载、78 米卸载；碰撞 16 米加载、24 米卸载，距离按平台范围计算，保留滞回。
