# S1.3：表层风格、光照与平台衔接

用户指出画风偏离 Roblox，并给出从矿口回望平台的截图。本轮优先修正实际结构错误，同时把表层推向明快、轮廓干净的模拟器式场景。

## 平台修正

- 原坡道从 z=8 升到 z=12，而平台从 z=10 开始；坡道后半段嵌入平台实体，正面形成一道高差。原坡道装饰条宽 9.85 米，坡道本身仅宽 6 米，装饰越界形成横线。
- 新增 `world/surfaceLayout.ts` 作为平台碰撞、坡道和外观尺寸的共同来源；平台前沿与坡道顶端统一为 z=12，顶高仍为 2 米，原出生和返回位置保持有效。
- 用 `surfaceDeck.ts` 组织底座、侧板、宽木板、包边和坡道侧边；删除重复旧装饰。平台碰撞保持一个盒体，坡道仍是连续三角网格；外观不创建第二套平台碰撞。
- 增加真正的双向行走回归：不跳跃上坡到台顶，再走回地面，要求高度连续且无阻挡。浏览器增加实际转镜头回望平台的截图。

## 表层风格与光影

- 表层场景启用独立的 `smooth` 表现配置：平滑树冠、带倒角的块状岩石和更圆整的圆柱，取消随机三角面色差。地下装饰继续使用原表现配置。
- 小花、钉头和小碎石继续使用低面数构件，细分仅用于较大的可见轮廓。
- 草地、树冠和天空提高明度与色彩区分。保留木构和设施布局，削减平台上的细碎横线。
- 表层使用更高的太阳角度、较中性的日光、偏冷的天空补光，阴影强度和柔化半径单独调整；远景雾起点延后。
- 仍只使用一张 1024² 缓存阴影图，静态场景变化时刷新。平台装饰和坡道参与投影，没有增加实时多光源或后处理。
- 增加一张 64² 的角色脚底柔和接触贴图，接地时显示；它不触发场景阴影重绘，额外一个绘制批次。相机淡出仍适用，贴图不写深度，退出时释放。
