# S1.1：十个场景精修

用户确认上一版功能正确，但场景仍粗糙。本轮落实十个场景的第二轮表现；美术效果仍以用户实看为准，真实手机 60 FPS 尚未验收。

## 具体调整

| 场景 | 本轮细节 |
| --- | --- |
| 草地矿场 | 成簇树冠、分层岩壁远景、灌木花草、矿口瓦顶与滑轮、木平台拼接、矿车轮毂和工作台 |
| 老矿井 | 木梁铁箍和铆钉、缆绳灯、工具架、木料堆、卷扬机、木桶 |
| 蘑菇洞穴 | 弧面伞盖与斑点、小型菌丛、蕨叶、荧光细节 |
| 水晶洞穴 | 连续六棱切面的晶体、大小晶簇、碎石基座、晶环 |
| 地下遗迹 | 逐块搭建的石门、菱形门楣纹样、柱身环带、角落植物 |
| 冰封矿洞 | 顶部冰锥、冰片与细小冰晶、冷色切面 |
| 熔岩矿洞 | 发亮嵌槽、金属栅条、火盆、黑色碎岩 |
| 巨型化石 | 弧形肋骨、独立椎骨、头骨牙齿与角 |
| 古代机械 | 管道、齿轮齿、能源罐、仪表与面板 |
| 地心秘境 | 轨道环、晶体基座、大小晶簇 |

共用设施增加柜台木板、斜撑、箱体钉头、秤具、招牌边框；营地落点增加低对比铺地。吊灯避开中央层名，化石与地心标牌避开主景。矿纹增加切面、线性采样与单格稳定镜像，减轻硬像素和完全重复的图案。

## 架构和成本

- `world/sceneryKit.ts` 提供纯描述构件；`surfaceArt.ts` / `undergroundArt.ts` 维护细节配方；深度位置仍来自楼层配置。表现代码没有新增深度常量。
- `presentation/SceneryMesh.ts` 创建和合并几何；普通颜色仍合并一个网格，发亮部分一个，牌匾独立。大木构件增加轻微倒角，岩石和树叶带少量面色变化。
- 新增一张 1024² 静态阴影图，只在装饰驻留或所在矿层改变时更新；体素地形只接收阴影，不投影。正常移动、挖格子不会触发每帧阴影生成，角色不参与阴影缓存。
- 阴影接收仍有 GPU 采样成本。场景进入时生成/合并装饰与首次阴影有一次性成本，计入现有 `sceneResidencyMs` 等诊断。不能因使用缓存就推断目标手机达标。
- 普通碰撞依然独立近处开启、远处卸载；细小花草、钉头、纹样不创建逐个碰撞体。入口、售卖圈和通路保留。
- 未引入外部美术资源。本轮不改主角、动作、镐子、背包模型或经济规则。
