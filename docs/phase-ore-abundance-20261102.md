# 矿石丰度再次减半

用户要求在当前基础上再减半。三个世界全部 21 层的 `oreChance` 从 9%～14% 减至 4.5%～7%，逐项精确除以二；每个世界各层依次为 4.5%、4.9%、5.35%、5.75%、6.15%、6.6%、7%。未改动两类矿石的相对权重、岩盖、容量、售价或商店价格。

已同步 `tools/economy/model.mts`，未运行价格重生成或校准。地形生成版本和已挖空记录保持不变，剩余矿块按新的概率生成。

验证：地层生成、概率抽样、渲染/碰撞一致性及经济模拟共 10 项测试通过，生产构建通过。原世界 1 的 240 分钟检查因用户明确降低丰度而不再适用；测试改为与紧邻上一版的双倍丰度比较，并要求三个世界完整可达、单世界耗时小于上一版两倍。相同 seed 1 模型结果为 216→261 / 351→396 / 449→522 分钟，分别对应三个世界；这是模拟估算，非实际游玩时长。

只发布 mining-test。发布器验证公开文件哈希及正式 Mining 未改动。公开手机横屏 Chromium 模拟的 21 层运行时矿块抽样和截图记录位于 `output/ore-abundance-half/report.json`。本轮不处理或验证 iPhone 14 Pro 原始系统兼容性。
