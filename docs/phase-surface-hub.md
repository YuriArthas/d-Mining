# S1.4：重新调整表层造型语言

S1.3 的平台结构修正保留，但用户明确指出画风仍然不符合 Roblox。原先的木屋、水塔、瓦片、花丛与细木构件方向停止沿用。本轮重做表层场景构图，而不是继续增加营地细节。

## 本轮变化

- 矿口：蓝白色厚框架、黄色压顶、放大的镐子徽章和描边大字标牌；边缘采用黄黑标识。完整保留 8×8 格入口，前方坡道直接通向入口。
- 售卖：独立红色柜台、金币标识和大号出售招牌；激活圆环仍使用原位置和半径，没有添加新的商店或交互。
- 平台：蓝白色基座与顶面，青色侧边和传送圈；共用原有平台/坡道尺寸，平台前沿与坡道顶端仍在 z=12、y=2。
- 环境：成组块状树冠、阶梯式灰岩与绿色草顶、宽铺路，以及蓝色矿车与大颗矿石。移除旧表层装饰叠加器，避免两套风格混杂。
- 材质：表层采用独立 `plastic` 描述，纯色块面与适度高光；地下场景保持原来的材质和招牌。设施招牌使用单独样式，不修改地下木牌。
- 光照：重新平衡表层日光与补光。沿用一张 1024² 静态缓存阴影图和角色接触阴影，没有增加实时灯或后处理。

## 边界

- 表层构图归 `world/surfaceArt.ts`，平台皮肤归 `surfaceDeck.ts`，几何/材质转换归 `presentation/SceneryMesh.ts`；场景描述仍不依赖 Three.js/Rapier。
- 装饰依旧合并成普通材质/发光材质批次，招牌各自绘制；物理仍按独立距离窗口加载。
- 主角、镐子、背包和 UI 美术本轮不展开。玩法、背包、采矿和主题/深度配置关系不改变。
- 官方缩略图仅作色彩/标识参考，它们是宣传图，不能当作游戏实景证据。本轮是否符合用户期望，以实际画面反馈为准。
