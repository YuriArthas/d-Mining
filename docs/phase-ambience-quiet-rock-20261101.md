# 石头里不再有嗡嗡声，小溪边才有水声（2026-11-01）

用户反馈：游戏里一直有嗡嗡声，以为是小溪的水声；离得近听到可以，可挖进几十格石头还能听见，不合理。

## 原因

游戏里原来没有小溪的声音。一直响的是两层持续的噪声底声：
- 地表的风：粉红噪声过 650 Hz 带通，强弱只在 0.4～1.6 倍之间起伏，从不停，听起来像流水；
- 矿井里的「洞穴低鸣」：170 Hz 以下的低频加 520 Hz 一带的噪声。往下挖约 10 格换成它，音色和风差不多。

所以从地表到石头深处，一路都是同一种「流水」声。老矿井、蘑菇洞也用同样的底声，其他各层底下也都垫着它。

## 改动

- **小溪有了自己的水声**：明亮的流水声，上面有一串细碎的气泡声，按离水面的距离变化：
  - 离水边 3 米内全响，26 米外听不见；
  - 桥上 1.0，出生点约 0.68，广场中间约 0.09，矿坑口为 0；
  - 往下挖，离水面越来越远，自然就没了。
- **风一阵一阵**：每次各一半机会起风或停歇。起风 2.5～5.5 秒，强度是原来的 0.55～1.15；停歇 4～11 秒，只剩 0.04～0.12。地下遗迹、冰洞、化石层的风也一样。
- **普通的土和石头里没有持续底声**：所有地方都去掉了「洞穴低鸣」。地表矿井、老矿井、蘑菇洞只剩滴水、远处闷响、别的矿工敲镐、木头吱呀这类偶发声音。
- **有东西在响的地方才有底声，而且只在开阔处**：熔岩、机器、晶体、地心、各层的风。这些底声属于本层的大厅（第一层是山谷）：
  - 在大厅里全响；
  - 挖下第一格仍全响，挖进 3 格约剩一半，挖进 7 格（14 米）就听不见。
- 背景音乐不变，第一层矿井里仍是闷住的山谷曲子。

## 代码

- `src/game/audio/ambience.ts`：
  - 风改为阵风加停歇；新增 `brook`（小溪）和 `bubble`；删掉 `caveAir`。
  - 每个地方的底声接到 `open` 音量下，小溪接到 `creekLevel` 音量下，由 `Ambience.setLevels(open, creek)` 平滑调节。
  - 小溪听不见时不排气泡声。
- `src/game/audio/soundscape.ts`：
  - `PlaceSound` 增加 `dug`（挖进本层开阔处以下多少米）和 `creek`（离小溪水面多少米）；
  - 按 `BEDS_THROUGH_ROCK`、`CREEK_REACH` 换算成音量。
- `src/game/audio/GameAudio.ts`：`AudioScene` 增加 `beds`、`creek`。只有这两个变化时，只调环境声的音量，不动音乐。
- `src/game/content/pinewindSurface.ts`：`creekDistance(x, y, z)`，用和溪床同一条曲线计算离水面的距离。
- `src/game/runtime/updateGame.ts`：每帧把 `dug`（所在深度减去本层起点：大厅地板就在层顶）和 `creekDistance` 交给声音。
