# 宠物的挖矿加成和镐子差不多；特殊矿减半（2026-11-02）

用户反馈：
- 宠物的提升有点小，按说三只宠物就该和镐子提升的战斗力差不多，甚至略强一些；
- 特殊矿的丰度有点高，降到一半。

## 原因

每只宠物除了本世界货币的收入加成，还有一项全世界通用的挖矿加成：先加挥镐速度，到 4 倍上限后折成伤害。10-25 定这一项时，有意让它"小、长得慢"，保证镐子是主力：
- 原野蛋（第一颗蛋）五只宠物只有 +4% / +5% / +6% / +9% / +14%；
- 每往下一层只涨 12%。

按模型的典型玩家（会抽到几只金色宠物）算，到达各层时装备的宠物合计：
- 世界 1：只有 +25%～+80%，镐子的作用比宠物大得多；
- 到了世界 3，因为层数多、栏位多、金色宠物多，宠物却有 +200%～+800%。

前期太弱，后期又太强。

## 改动

挖矿加成改成起点高、涨得慢。每只宠物 = 15% × 1.03^层序号 × 稀有度系数（1 / 1.2 / 1.6 / 2.3 / 3.5），高价蛋再 ×1.5，金色宠物 ×2.5。稀有度系数、高价蛋、金色宠物的倍数都没变。

| 蛋 | 原来 | 现在 |
|---|---|---|
| 原野蛋（世界 1 第 1 层） | 4 / 5 / 6 / 9 / 14 | 15 / 18 / 24 / 35 / 53 |
| 火花蛋（世界 1 第 7 层） | 8 / 9 / 13 / 18 / 28 | 18 / 21 / 29 / 41 / 63 |
| 铜矿蛋（世界 2 第 1 层） | 9 / 11 / 14 / 20 / 31 | 18 / 22 / 30 / 42 / 65 |
| 熔岩蛋（世界 2 第 7 层） | 17 / 21 / 28 / 40 / 61 | 22 / 26 / 35 / 51 / 77 |
| 地心蛋（世界 3 第 7 层） | 39 / 46 / 62 / 89 / 140 | 27 / 33 / 43 / 62 / 95 |
| 黑洞蛋（世界 3 第 7 层高价蛋） | 58 / 69 / 93 / 130 / 200 | 41 / 49 / 65 / 93 / 140 |

（单位：%，从普通到传说）

模型的典型玩家到达各层时，装备的宠物合计（15 个种子的中位数，矿减半并重新校准后）：

| | 原来 | 现在 |
|---|---|---|
| 世界 1 | +25%～+80% | +100%～+200% |
| 世界 2 | +31%～+330% | +70%～+470% |
| 世界 3 | +190%～+840% | +240%～+580% |

- **世界 1**：三只宠物合计和镐子差不多或略强（镐子算 1 倍，宠物再加 1～2 倍）。三只普通的原野宠物也有 +45%。
- **世界 2**：刚进世界 2 时，"装备最佳"先换上本世界货币的新宠物，挖矿加成会掉到约 +70%。这一点和原来一样（原来掉到 +31%），抽几次新蛋就回来了。
- **世界 3**：比原来低一些。栏位从 3 个加到 5 个，金色宠物也多了，宠物仍比镐子强不少。

**矿的等级门槛不变，仍然只看镐子**：宠物挖得再快，也挖不了等级不够的矿。

## 特殊矿减半

每层两种值钱的矿（3 倍、6 倍石头价），占格子的比例从 18%～28% 减半为 9%～14%（每个世界第 1 层到第 7 层）。这是唯一的来源：数值表的 `oreChance`，地形生成和模型都读它。

- 每格石头的收入少了，矿也更难碰到。
- 门票要的矿物数量不变，所以世界 1、2 的最后一层要多挖一会儿来凑门票矿物（模型已计入）。

## 重新校准

两项改动后重新校准（`model.mts calibrate`），保持原来的目标时长，由价格吸收。和今天改动前相比：

| | 改动前 | 现在 |
|---|---|---|
| 世界 1 镐子 L3～L9 | 450 / 1300 / 1600 / 3.1 万 / 9 万 / 11 万 / 170 万 | 640 / 1900 / 2400 / 3.8 万 / 10 万 / 13 万 / 220 万 |
| 世界 1 镐子 L10 | 1400 万 | 1200 万 |
| 世界 2、3 镐子 | | 多数约 0.75～0.9 倍；L11 不变，L12 1.5 倍，L13 1.1 倍 |
| 蛋 | | 都便宜约 15%，例如原野蛋 12 → 10、火花蛋 43 万 → 36 万 |
| 门票 | 630 万 / 3900 万 | 520 万 / 3100 万 |
| 宠物栏位 | 13 万 / 73 万 | 12 万 / 59 万 |

世界 1 宠物变强得多，所以镐子贵了；后两个世界宠物比原来略弱、矿又少了，所以便宜了。蛋价按到达这一层时的收入定，矿少了收入低，蛋就便宜了。

岩石、矿和岩盖的血量都没改。有了宠物，岩盖挖得更快：原来带着下一把镐子挖穿约 200 秒，现在按典型队伍大约是一半到三分之一。

## 代码

- `tools/economy/model.mts`：
  - `miningPct` 改为 `15 × 1.03^层`（原来 `4 × 1.12^层`）；
  - `ORE_CHANCE` 减半：`.09 + .05 × 层/6`（原来 `.18 + .1 × 层/6`）；
  - `simulate` 记录到达各层时装备的宠物合计加成 `petMining`，`report` 打印这一行。
- 重新校准 `k3.json`、`plan.json`、`economy.json`（宠物挖矿加成、各层矿的比例、各项价格、各蛋计划抽数）。

## 验证

- 全量测试 539 项通过，类型检查通过（和出售修正一起，见 `docs/phase-sell-floor-20261102.md`）。
- 已发布到测试入口 `mining-surface-play`；线上包里原野蛋苔团的挖矿加成为 15%，第一层矿的比例为 0.09。
- 宠物和矿只改数值，界面没变，没另外开浏览器。

## 整局机器人

两局（种子 1、2）都从新存档一路玩到世界 3 通关，没有卡住，每局约 47 分钟（服务器无渲染）。机器人用的是这次的全部改动，包括就近出售；但它卖完后仍回地表、坐传送站下到大厅，往返时间和模型的假设一样。单位：分钟。

| | 种子 1 | 种子 2 | 目标 | 10-31（改动前） |
|---|---|---|---|---|
| 到第二层 | 6.9 | 7.0 | 约 7 | 5.7 / 6.0 |
| 到第三层 | 16.9 | 16.2 | 约 15 | 13.5 / 14.4 |
| 世界 1 | 132.5 | 126.0 | 120 | 113.5 / 113.8 |
| 世界 2 | 252.5 | 237.6 | 240 | 234.3 / 247.2 |
| 世界 3 | 299.1 | 326.0 | 360 | 345.7 / 342.2 |
| 总计 | 11.4 小时 | 11.5 小时 | 12 小时 | 11.6 / 11.7 小时 |

和同一种子的模型比较：
- **世界 1**：模型 119.4 / 116.8，机器人慢 8%～11%，主要多在挖矿时间（47 / 43 对 38 / 35 分钟）。10-31 时机器人也慢，挖矿多 12%～23%。
- **世界 2**：模型 244.4 / 252.1，相差 3%～6%。
- **世界 3**：模型 361 / 349.8，机器人快 7%～17%：
  - 每一层都更快，挖矿时间少 210～230 对 245～250 分钟；
  - 下挖本来就比模型快（25 对 43 分钟，10-31 时也是这样）；
  - 10-31 时种子 2 也快了 9%，两局之间的差别主要来自抽蛋结果。

真人卖完可以直接从大厅走回矿坑，比机器人和模型都快一些，所以实际节奏会略短于上表。
