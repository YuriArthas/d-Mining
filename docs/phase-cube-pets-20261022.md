# 方块宠物（2026-10-22）

原来跟在角色身后的宠物是纯色圆球加一行名字，界面里是矢量头像；抽到传说宠物，场景里看到的还是一个球。这一轮换成方块宠物。工作区 `/root/.t3/worktrees/d-Mining/surface-roblox`，基于 `96e84bb`。

## 用户定下的方向

- 方块 + 脸，两块分开；脸用萌系画法。
- 要有一跳一跳的感觉；做成一块还是两块视情况决定（最终是身体和脸两块，脸单独一块便于眨眼）。
- 粒子：前期的蛋只有传说宠物带，后期的蛋从稀有开始带，中间由我决定。

## 现在的样子

- **身体**：一个圆角方块，颜色是物种颜色，表面花纹按所在的蛋区分（原野苔藓、卵石、蘑菇斑点、水晶切面、铜脉、遗迹符文、潮汐波纹、霜冻、火星、熔岩裂纹、化石骨纹、蜂巢、铆钉、白银光泽、星点、地心光环，共 16 种），同一颗蛋的宠物一眼就是一家。
- **脸**：贴在正面的另一块，萌系大眼睛、腮红、小嘴；用脸上的特征表明是什么动物：狐狸和猫的耳朵、兔耳、熊耳、猫头鹰的眼圈和喙、鹿角、牛角、狮子的鬃毛、龙角和尖牙、蜜蜂的触角和条纹等，共 24 种（团子类就是一张简单的脸）。每隔几秒眨一次眼。
- **稀有度**：普通、稀有、史诗、传说体型依次为 0.7 / 0.76 / 0.84 / 0.95 米（传说不超过 1 米，免得挡住视线），越高越有光泽；传说还带一圈淡淡的光晕。
- **粒子**：按蛋的进度下放——前五档进度的蛋（原野、卵石、蘑菇、水晶、铜、遗迹）只有传说带粒子；中期（潮汐、霜冻、火焰、熔岩、化石、琥珀）从史诗开始；最后四颗（齿轮、白银、星辉、地心）从稀有开始。粒子跟着蛋的主题：原野飘叶子，潮汐冒泡泡，火焰和熔岩是火星，霜冻是雪花，白银、星辉、地心是星星，其余是闪光。普通宠物永远不带粒子。
- **动作**：跟随时一跳一跳，起跳拉长、落地压扁；离得远就跳得更远更快，不会被跑步的角色甩掉；角色停下后宠物转过来面朝镜头，看得到脸（跟着走时朝前走，镜头在后面只能看到背）；偶尔原地小跳；角色跳起来时宠物留在地面；传送途中先隐藏，到达后落在角色身边。去掉了宠物头顶的名字。
- **界面**：背包、蛋台概率列表、开蛋揭晓里的宠物头像，用同一套画法画出 3/4 视角的方块、花纹、脸和粒子，和场景里是同一只。

## 制作与记录

- 身体网格：Blender 自制，脚本 `tools/build-pet-cube.py`，源文件 `assets-source/pets/pet-cube.blend`（按仓库规则不入 Git），游戏资产 `src/game/assets/pets/pet-cube.glb` 与 `pet-cube.manifest.json`：300 个三角面、152 个顶点、9,368 字节，SHA-256 `d421b3c2a281ce1161418f24298073c8162516fc2d1bbff19656c4a9061fd576`。底面中心为原点，6 个平面各铺满一块花纹 UV。没有 Tripo 任务。
- 贴图：全部在运行时由代码画出（`src/game/presentation/pets/petArt.ts`），不带图片文件。脸 128×128（睁眼、闭眼各一张），花纹 32×32（像素风，最近邻采样），粒子 64×64，光晕 128×128；同一张贴图被所有用到它的宠物共用。界面头像 288×288，每个物种只画一次，界面里的画布直接拷贝。
- 外观规则（脸、花纹、粒子、体型）集中在 `src/game/content/petLooks.ts`；模型在 `src/game/presentation/pets/PetModel.ts`；跟随在 `PetFollowers.ts`。
- 制作用的离线预览：`tools/pet-preview/`（全部 80 只宠物的模型图和界面头像图，按蛋的进度排列），只用于制作，验收以公开入口为准。

## 顺带修掉的问题

- 第一次打开背包时，头像在点按的同一刻同步生成，SwiftShader 下拖慢了浏览器补发的点击，这个点击超过了原来 700 毫秒的防穿透窗口，落在刚弹出的关闭按钮上，把背包又关了。现在头像在面板显示后才画（且不再编码 PNG）；防穿透窗口改为 2 秒，任何新的按下都会清掉它，所以真正的连续点按不受影响。

## 验证

- TypeScript 与 Vite 构建通过。全量测试 493 项：489 通过，4 项失败与改动前相同（contact-bake、quarry 资源清单、quarry 庭院碰撞、旧道路）。新增 `tools/tests/pet-looks.test.mjs`（3 项：每只宠物都有外观且体型随稀有度递增、粒子按蛋的进度下放且普通永不带、模型是身体加独立的脸并会眨眼且只释放自己的资源）；`tools/tests/pet-followers.test.mjs` 的跟随测试按新实现重写（共享身体网格、传送途中隐藏、跳跃跟随与落地压扁、角色跳起时留在地面、停下后面朝镜头）。
- 先发布到公开试玩入口（`artifacts/cube-pets-release.json`），再跑手机检查 `tools/check-cube-pets-mobile.cjs`（Android UA、触控、横屏 844×390、DPR 2、SwiftShader），4 项通过、错误 0：装备的原野传说龙带粒子和光晕、地心蛋的稀有宠物带粒子、原野蛋的稀有狐狸不带；站着不动时宠物面朝镜头；用摇杆走动时宠物一跳一跳跟上（逐帧截取）；背包、蛋台和开蛋揭晓显示同样的方块宠物。统一面板手机检查 `tools/check-ui-panels-mobile.cjs` 复跑 8 项通过、错误 0（覆盖防穿透窗口的改动）。
- 这是手机浏览器模拟和软件渲染，不是真机；粒子在真机上的观感和开销没有测过。

## 尚未覆盖

- 物种之间的区别主要靠脸和颜色，没有额外的耳朵、角等立体部件；如果同一颗蛋里的宠物看起来太像，再考虑给稀有以上加小部件。
- 宠物在窄矿道里仍可能穿进墙里（和原来的圆球一样）。
