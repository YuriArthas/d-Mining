# S1.2：表层林间矿场

用户认为上一轮比之前好，但仍可继续美化，要求先集中表层。本轮只推进地表营地表现。

## 构图和细节

- 矿口保持中心；屋脊增加矿场徽记，木平台增加罗盘刻度、侧板接缝、支撑和两侧灯柱。
- 后方左侧是暖色瓦顶矿务小屋：烟囱、窗框、窗台植物、墙板、门和灯；右侧是青绿色水塔：木支架、交叉撑、管道和检修梯。
- 两侧土路连接售卖圈、矿车工作区与后方建筑。保留中间 8×8 开采口、售卖圈和原来的返回/传送落点。
- 近处花草改成成簇种植，矿口外增加低矮石边。外围混合阔叶树、分层松树与原有岩壁，形成前中后景。
- 按实际截图将挡住建筑和步道的树移到外围，压低松树轮廓，避免默认镜头只剩高尖顶。

## 代码与成本

- 新的 `world/surfaceCamp.ts` 只输出表层布景描述；`surfaceArt.ts` 组织矿口、平台与营地配方。
- 路面和小装饰不叠加地面碰撞；房屋、水塔支架等大构件保留独立普通碰撞，按既有距离加载/卸载。
- 仍合并普通/发光装饰网格，沿用静态缓存阴影；增加两张建筑标牌。不增加每帧动画、粒子、点光或外部资源。
- 新增三棱柱山墙构件，封闭屋顶并制作矿口徽记底板。小花从高面数扁球/石头改成六边柱和小锥体，避免把几何预算耗在很小的花心上。
- 地下主题、矿物分布、经济和角色操作没有调整。
