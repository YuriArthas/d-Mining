# S1.7：翡翠山谷场景重塑

用户确认本轮以场景质量和鲜明的风格化为优先，不用性能预算限制美术。继续保留占位主角、已有操作与玩法。本轮重点为表层，地下主题沿用已有内容。

## 场景方向与资产制作

表层统一为青绿设备、奶油色饰边、暖铜色售卖站与翡翠晶簇。使用项目内专门设计的旋转轮廓、曲线扫掠、异形挤出和连续外壳生成模型，没有调用 Tripo 或引入外部模型。

- 矿口：弯曲铸造支架、金属卷曲托架、齿轮、异形招牌和晶簇徽章；整体降高，使默认相机能看到完整标识。低矮护边始终在 8×8 格外。
- 售卖站：旋转成型的柜台、连续弧面屋顶、包边、硬币顶饰、矿石展品与独立称重盘。售卖触发仍由原区域 API 负责。
- 矿车：连续敞口、内外壁和收腹车斗，车轮、矿石负载、货物徽记；轨道弯入装卸区，并加挡车器。
- 卷扬机：横置罐体、抱箍、飞轮、弯管、喇叭形排气口与压力表，管道接向矿口支架。
- 环境：分层岩台、厚草沿、远景岩峰、弯曲树干和宽树冠、垂挂藤蔓、成组植物与矿物露头。出生点背面也有山谷、树群、营地标识和灯具。
- 地面：弯曲道路、售卖区圆形铺装和出生台嵌线；主通路、坡道和矿格保持清楚。
- 山泉：侧壁瀑布、浅水池、落水泡沫与岸石；水材质使用随时间变化的流纹。

## 材质与光影

- 石体顶底颜色变化和草沿平滑法线，维持清楚的大色面。
- 重画矿物图集中的块状夹杂，降低细长尖锐纹样；仍共享图集和地形材质，不改变合并规则。
- 表层增加天空渐变和太阳方向的暖色光晕；雾的远端扩到 135 米，以显示山谷远景。
- 阴影图提升到 2048²；水使用独立材质，不投射不合适的实心阴影。
- 地下恢复原有天空、反射与雾参数。天空网格、材质和反射资源随会话释放。

## 模块边界

- `world/surfaceArt.ts`：场景布局和设施配方。
- `world/surfaceSculptures.ts`：纯数据的旋转体、曲线、异形牌匾、树木、植物、晶簇等造型描述。
- `presentation/surfaceGeometry.ts`：Three.js 网格构造；所有曲线、剖面与摆放参数来自描述层。
- `world/rockProfile.ts`：岩石/草沿的纯几何轮廓；渲染与普通地形凸包分别使用。
- `SurfaceMaterial.ts` / `SurfaceEnvironment.ts`：材质、流动水面和天空。
- 不把美术数据写入稀疏体素、挖矿、背包、售卖或成长模块。
