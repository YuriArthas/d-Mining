# UI 深度改造：统一面板与入口收拢（2026-10-22）

用户要求：入口收拢、没有的功能去掉、难用的地方直接改、不受现有代码约束，按常识当 Roblox 游戏来设计，目标是好玩。画风（场景美术）保持不变。工作区 `/root/.t3/worktrees/d-Mining/surface-roblox`，基于提交 `b75ec9f`。

## 设计决定

- **一个容器**：所有窗口改用 `Sheet`（`src/game/ui/kit/panel.tsx`）：亮青面板、标题压上边框、红色关闭键在角上、左侧页签、可滚动格子区、底部固定操作栏。示意图见 `docs/ui-mockups/`，按真实组件样式渲染。
- **入口收拢**：8 个独立弹窗合成 3 个带页签的容器——背包（宠物 / 矿物 / 装备）、世界（传送 / 进度）、奖励（在线 / 签到 / 邀请）；蛋台、扭蛋机、商店仍在场景里走到跟前打开。HUD 右侧固定 4 个入口：宠物、商店、奖励、世界，去掉「更多」。
- **去掉不存在的功能**：商店「重生商店·未开放」柜台；宠物等级显示（宠物固定 Lv.1，没有升级玩法），包括场景跟随宠物头顶的「Lv.1」。
- **改掉难用的流程**（对齐 Roblox 挖矿模拟器常见做法）：
  - HUD 新增「出售」：背包有矿时出现，一点传送到售卖圈自动卖出；背包满时按钮跳动。
  - HUD「商店」和背包条「+」直接传送进商店圈并打开商店，不再只画箭头。
  - 各处「前往」（商店、售卖圈、扭蛋机、已解锁蛋台）都是即时传送，到达后镜头转向目标。
  - 传送菜单在地表任意位置可用（原来必须站在出生点一圈内）；地下仍需「便携传送」。
  - 奖励红点显示可领取数量；宠物红点表示「一键最佳」能让队伍更强。
- **宠物头像**：场景宠物目前是彩色球、界面是单字圆章。本轮用矢量方块宠物头像（`src/game/ui/pets/PetArt.tsx`，24 种动物模板 × 物种颜色，传说带皇冠），作为 Blender 3D 宠物出来前的过渡；模板也作为 3D 宠物的造型说明。
- **开蛋**：全屏揭晓，蛋摇晃 → 闪光 → 宠物弹出，按稀有度换色，点一下可跳过；新物种显示「新宠物」。
- **其余统一**：帮助改成六张图标卡；保存 / 退出对话框、存档警告、读档页、加载页换成同一套组件和配色；商店展厅的钱包、按钮、属性换成组件；新手引导文案改为提示「出售」「商店」按钮。

## 代码结构

新增 `ui/kit/panel.*`、`ui/bag/`、`ui/eggs/`、`ui/world/`、`ui/rewards/`、`ui/HelpSheet.tsx`、`ui/pets/PetArt.tsx`、`ui/pets/EggArt.tsx`。删除 `PetPanel`、`PetDialog`、`EggPanel`、`PetPortrait`、`JourneyPanel`、`TravelPanel`、`RewardsPanel`、`OnboardingHelp` 及 `pets.css`、`journey.css`、旧 `rewards.css`、`feedback.css`；`styles.css` 删除失效的旧 HUD/升级面板规则，`legacy.css` 只剩引导文字、调试工具和矿石图标。

逻辑层改动：`GameSession.goTo()`（商店 / 售卖圈 / 扭蛋机 / 蛋台的即时传送，带朝向）、`canTravelNow()`（地表即可传送）、快照 `location`；`WorldCommands.travelTo` 增加可选 `lookAt`，运行时据此转镜头。

- 先发布到公开试玩入口，发布记录 `artifacts/ui-panels-release.json`，其他游戏文件未变；正式 Mining、mining-test 未覆盖。
- 手机检查 `tools/check-ui-panels-mobile.cjs`（Android UA、触控、横屏、DPR 2、Chromium/SwiftShader）：在独立验收数据库里写入 2500 金币、8 只宠物、矿石和 812 米深度后，用触控走完全部窗口。8 组全部通过，页面错误 0，截图 24 张，报告 `artifacts/ui-panels-mobile/report.json`：背包三页、一键最佳、世界两页（离开出生圈也能传送）、领取在线奖励、帮助、获取宠物 → 传送到蛋台 → 开蛋动画、传送到扭蛋机抽奖、HUD 商店传送开店、出售传送自动卖出、地下 HUD、640×320 小屏；每个窗口都在视口内、按钮 ≥ 44px、内容区无横向溢出。
