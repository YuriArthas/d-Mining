## 本次规则

攻击距离约 4 格（8 米），按角色手部到命中表面的距离判定，不检查普通地形或矿物遮挡，也不依赖渲染驻留。每次敲击只攻击一个格子。第一次立即出手，后续由玩家的冷却控制，不补发卡顿期间错过的攻击。每次攻击前由挖矿查询背包是否满；满则不扣血。已经销毁的矿物完整加入背包，Inventory.add 仍不限制容量。

HP 按格子坐标保存，仅受损格子有记录，完整格子从矿物配置读取最大 HP。切换目标、返回地面和渲染/碰撞卸载都不重置 HP。真正销毁后删除该格子的 HP 记录，刷新仍重置整个会话。

| 矿物 | HP | 初始力量 10 的敲击次数 |
| --- | --- | --- |
| 岩石 | 10 | 1 |
| 深层岩石 | 40 | 4 |
| 煤 | 20 | 2 |
| 铜 | 30 | 3 |
| 金 | 60 | 6 |
| 水晶 | 100 | 10 |

- 力量：`10 + (level − 1) × 5`。
- 攻速：`min(16, 2 × 2^floor((level − 1) / 5))` 次/秒；Lv.1/6/11/16 分别为 2/4/8/16 次/秒，Lv.16 达到临时上限，之后力量继续增长。
- 临时升级价格：`5 + (当前等级 − 1) × 2` 金币；Lv.1→6 总计 45 金币。
- 松手、切换目标、打开界面、移动/返回和升级都不清除已有冷却。升级后下一次攻击用新力量，并以新攻速计算随后的冷却。
- HUD“升级”打开镐子/背包两页。仅当前选中格子显示 HP 和受击闪动，未损坏矿物不创建单独 UI/网格。

## 模块边界

| 模块 | 自己负责的事 | 不负责的事 |
| --- | --- | --- |
| BlockHealth | 泛型键的稀疏剩余血量、扣血和清除 | 地形、矿物种类、掉落和 UI |
| AttackCooldown | 绝对时间就绪判断、计算下一次出手时间 | 输入、目标、背包和升级 |
| Pickaxe | 等级推导力量和攻速 | 费用、钱包、UI 和开采 |
| MiningCombat | 查询满包/目标/属性、单格伤害、冷却、请求销毁 | 渲染碰撞构建和奖励 |
| TerrainStream | 占据数据、两个独立合并管线、真正删除和删除结果 | 血量、攻击属性和背包 |
| Mining.collected | 把已完成开采结果映射为物品并完整加入背包 | 再查容量、扣血和网格 |
| PickaxeUpgrade | 独立报价、校验展示等级、扣币升级 | 地形、冷却、输入和表现 |
| GameSession / UI | 端口接线与一致快照 / 展示和发送命令 | UI 不直接改规则数据 |

地形现有 mineMany 与通用采集批次 API 继续保留；当前玩家镐子入口只接收单格，未来其他工具可独立采用不同的攻击规则。

致命一击遇到地形队列拒绝时，不扣血、不消费冷却；接受后记录 0 HP，等待地形现有流程完成。处理中不重复打击。如果返回/售卖等取消尚未完成的删除，0 HP 保留；冷却结束且允许挖矿后可重新请求删除，不再次消费攻击、不重复发奖励。不新增业务异步协调层。
