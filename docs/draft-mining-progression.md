| 项目 | 决定 |

| 到层奖励 | 不送金币。新场景、新蛋、新矿和更高的收入本身就是奖励 |

| 岩石分段 | 每层岩石分浅层和深层两段。休息区四周是上一层的岩石，脚下是本层的浅层岩石；深层岩石在靠近下一层休息区的地方，很厚，是软门槛 |

| 镐子规则 | 保留每 5 级攻速翻倍。攻速到上限后，超出部分折算成力量。到上限之后每 5 级是力量跃升，不能再承诺挥得更快 |
| 方案表述 | 先讲清楚玩家的感受和选择；数值模型只用来检验这些感受，不能代替试玩 |

## 3. 核心心流

一句话：**新层先压住你 → 你慢慢变强，换去挖更值钱的矿 → 这层挖得轻松了，也快够得着下一层了 → 往下挖，被新层压住。**

- 当前区域开始挖得轻松时，往下走需要的那档镐子也应该快买得起了。买到之后，往下挖要立刻变得明显顺畅。
- 最要避免的感受：“我已经很强，升级和宠物都不再让我更快，却还要攒很久才能走。”

### 3.1 节奏层级 [建议]

| 节奏 | 体验目标 |
| --- | --- |
| 挖碎一块 | 0.3～1.5 秒，碎得有手感 |
| 装满一包 | 全程 1.5～3 分钟，背包跟着矿石体积一起变大 |
| 一次能感觉到的变强 | 来自升级镐子、宠物或背包。前期 1～3 分钟一次，后期 5～8 分钟一次，任何时候不超过 10 分钟 |
| 大节点 | 解锁新的高级矿，或镐子每 5 级的跃升，两者错开。后期大约每 15～20 分钟一次 |
| 到达新层 | 新场景、新蛋、新矿，卖矿收入明显变高 |

### 3.2 每一段 [建议]

| 段 | 时长 | 玩家应该感受到 |
| --- | --- | --- |
| 地表 → 老矿井 | 20 分钟 | 学会挖、卖、升级。约 1 分钟第一次卖，约 2 分钟第一次升级，3～5 分钟拿到第一只宠物，5～8 分钟第一次攻速翻倍。煤和铜经常能挖到 |
| 老矿井 → 蘑菇 | 15 分钟 | 很快又到下一层的胜利感 |
| 蘑菇 → 水晶 | 25 分钟 | 第一次清楚感觉到换一整队宠物的好处 |
| 水晶 → 遗迹 | 60 分钟 | 第一次长段，学会“先变强再往下挖”。这里是最早的风险点 |
| 后三段 | 各 2 小时 | 分三幕，见下 |

### 3.3 两小时段的三幕 [建议]

三幕是体验章节，不是强制停留的时间。

1. **到达，约 20 分钟。** 进入休息区，卖掉一路带下来的新岩石和矿，钱刚好够买入门蛋。回地表买蛋，再传送回来。浅层岩石稍有点吃力，但很快就挖顺了，同时感到这次下来值得。
2. **变强，约 60 分钟。** 升级镐子让手里的矿越挖越轻松，高级矿一档一档解锁，玩家换去挖更值钱的矿。高价蛋是中途值得期待的一笔投资，但不是全段唯一的目标。
3. **收尾，约 40 分钟。** 去挖深层岩石，确认“还差多少”，做完最后几笔投资。镐子到位后，几分钟就能挖穿深层，进入下一层的休息区，这是全段的高潮。

## 4. 开采门槛与岩石

### 4.1 两类门槛 [已定]

- **高级矿**：镐子等级不够就挖不动，提示要几级镐子。这是层内“新矿解锁”的时刻。
- **普通矿和岩石**：只有血量，越往下越厚。玩家看敲几下、血条掉多少，自己判断划不划算。

### 4.2 每层的结构 [已定 + 建议]

```
上一层深层岩石  ← 挖穿它到达本层
┌──────────────┐
│  第 N 层休息区  │  四周是上一层的岩石；售卖点在这里
└──────────────┘
第 N 层浅层岩石   ← 本层主要的刷矿区域：普通矿血量逐步变厚，高级矿逐档解锁
第 N 层深层岩石   ← 软门槛：很厚、不值钱
┌──────────────┐
│ 第 N+1 层休息区 │
```

### 4.3 深层岩石的手感 [建议/待验]

- **太早去挖**：一块要几十秒，血条几乎不动，敲几下就明白“现在还不行”。
- **镐子到位**：几分钟挖穿深层。
- **不值钱**：深层岩石每敲一下换来的钱，要明显少于浅层岩石和矿。这一条最关键。如果深层岩石和普通矿一样赚钱，一路硬挖下去就是最优解：边挖边赚，还在往下走，到达时间会被压缩。
- **提早硬挖**：只差一档时可以接受，差两档明显不划算，差三档基本挖不动。
- **提早硬挖是正当技巧**：精算玩家会自己判断“现在硬挖”还是“再刷一档”，这是 4 小时和 12 小时差距的主要来源之一。
- **宠物的作用**：宠物让人更早挖穿深层，运气好的人自然快一点。不需要专门追传说宠物。

### 4.4 矿的档次 [建议]

前几层段短、矿少，后几层段长、矿多：

| 段 | 层内解锁次数 | 例子（用现有矿表） |
| --- | --- | --- |
| 地表 | 1 次 | 泥土、煤 → 铜 |
| 老矿井 | 1 次 | 旧矿 → 银 |
| 蘑菇 | 1～2 次 | 银 → 翡翠 |
| 水晶 | 2 次 | 水晶 → 紫水晶 → 蓝宝石、钻石 |
| 后三层 | 3 次 | 每层约 30、70 分钟各解锁一种新的高级矿，收尾去挖深层 |

- 同一种矿在各层的等级要求相同，玩家一看就懂，不做同名不同级的矿。
- 因此每种高级矿全程只解锁一次。现有矿表里，蓝宝石、钻石等矿在好几层都会出现，表中的例子只用来说明节奏，不能原样照搬；实施前要重新安排各层的矿物分布，让每层的解锁对象都是这一层第一次出现的矿。
- 每档高级矿刚解锁时应该要敲好几下，而且赚钱效率明显更高，玩家才会愿意转去挖它。只把血量和售价一起抬高，不算有吸引力。

## 5. 宠物与蛋 [已定 + 建议]

- 每层的新蛋就是这一层的“升级”。验收时看整队的实际提升：换上一只新宠、换上几只新宠后，整队分别强了多少。不要求一只新的普通宠物就压过三只旧宠物。[建议]
- 上一层抽到的好宠物，能多带一层，但带不了两层。[建议]
- 代差按整队的总倍率来算，不按单只宠物的加成算。三只宠物的加成是相加的，只换一只的提升会被稀释。[建议]
- 蛋都在地表。到层后回地表买蛋，是每层固定的一个短仪式。[现状 + 建议]

## 6. 三种玩家 [建议]

| 类型 | 典型做法 | 到第 8 层 |
| --- | --- | --- |
| 精算 | 算好钱分给镐子、宠物、背包的比例；挑效率高的矿；就近卖；只抽最新的蛋；判断好时机，必要时提早硬挖深层 | 约 4 小时 |
| 普通 | 大致跟着“这层轻松了就往下”走，偶尔绕路 | 约 8 小时 |
| 随性 | 什么都挖，常回地表，会抽旧蛋，挖轻松了还继续留着 | 约 12 小时以上 |

镐子每级价格固定，能升就早升，早升早提速，没有必要攒到 5 级的节点再买。随性玩家要更慢，但不能无聊：任何时候 10 分钟内都应该有下一笔能感觉到的变强。

## 8. 主要风险

1. **2 小时段单调。** 主要靠高级矿解锁、5 级跃升和高价蛋穿插来撑，只有到达和下挖不够。首版先保住 2 小时，再用公开试玩确认；出现空窗时，在 2 小时之内重新安排升级密度、收益和深层厚度，不缩短时长。
2. **提早硬挖的收益过大。** 镐子每 5 级只翻一倍，提早一两档硬挖往往很划算，可能把各层的到达时间整体提前。要靠深层岩石“不值钱”和厚度来压。
3. **4→5 层（第一次 60 分钟）和 5→6 层（第一次 2 小时）** 是最容易劝退的两段。
4. **后期回去卖矿越走越远。** 后半段可能被走路吃掉不少时间；玩家能不能直接爬回休息区，还没核实。
5. **旧存档。** 新数值下，旧存档的镐子等级和金币会失衡，测试入口的存档怎么处理还没定。
