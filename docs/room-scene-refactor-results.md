# 第二层场景配置拆分结果

本轮将第二层作为后续独立场景的样板，保持现有美术和玩法。其他八个地下层保留旧生成器，随之后的美术重做逐层迁移。

- `oldMine.scene.json`：参考尺寸、出生/售卖/商店位置、招牌、交互圈、材质参数、图集采样和局部照明。
- `oldMine.layout.json`：九个布景组的实例、独立碰撞和灯位；售卖组显式绑定售卖位置。
- `sceneDefinitions.ts` / `sceneAssets.ts`：轻量元数据与重资源注册分开，Worker 不导入布景网格或实例。
- `authoredRoomPlan.ts` / `AuthoredRoomView.ts`：公共展开与渲染代码不再包含第二层编号、灯光暖色、固定图集规格或专属招牌布局。
- Blender 脚本读取同一组 JSON，负责网格/图集生成和源场景导出，不再包含该层摆放列表。

验证：

- 构建通过，全套 289 项自动检查通过。
- 配置变化测试覆盖：售卖位置同时驱动模型、独立碰撞、灯位、标识与实际触发区；另一个楼层使用不同出生/商店位置；冷色照明与 4×1 图集；不同场景材质参数隔离；资源去重释放；错误配置显式失败；Worker 依赖图不含重资产。
- 与拆分前对照：974 个实例、14 个批次的矩阵完全一致，网格和贴图相同，静态光照场字节差异为零。证据：`artifacts/scene-config-refactor/baseline-result.json`。
- 实际运行 Blender 重导出，网格与像素仍一致；源文件、布局、元数据和脚本分别记录 SHA256。
- 先发布公开测试版，再进行桌面检查：地表踩踏进入第二层、400m 落地、售卖区触发、返回地表、再次踩踏传送均通过；无浏览器或 shader 错误。证据：`artifacts/scene-config-refactor/preview.json`、`arrival.png`。
- 发布脚本校验公开产物哈希，并确认正式版文件未改变。

边界：没有新增在线编辑器、任意洞穴轮廓或通用 shader 编辑器；配置改动通过构建和测试发布生效。新增水、粒子等表现仍需对应实现。具体编辑说明见 `level-content-guide.md`。
