# 背景音乐、环境声与脚步声（2026-10-22）

上一轮有了音效，但游戏里没有音乐，走路没有声音，地表和地下听起来一样安静。这一轮补上三样：每个矿层主题一首背景曲、每个地方的环境声、按脚下材质区分的脚步声。工作区 `/root/.t3/worktrees/d-Mining/surface-roblox`，基于 `27a2284`。全部在浏览器里实时合成，游戏仍然不带任何音频文件。

## 音乐

十个主题各一首原创曲子，旋律逐音写成，伴奏（琶音、低音、和弦铺底、鼓点）按和弦生成：

| 主题 | 曲名 | 调性 / 速度 | 主奏（两遍轮换） | 风格 |
| --- | --- | --- | --- | --- |
| 翡翠山谷（地表） | 松风晨光 | F 大调 100 | 木琴 / 陶笛 | 轻快明亮，吉他分解和弦 |
| 老矿井 | 矿灯小调 | D 多利亚 92，摇摆 | 口哨 / 木琴 | 乡村民谣，班卓滚奏、木鱼 |
| 蘑菇洞穴 | 孢子微光 | A 小调 96，摇摆 | 拇指琴 / 木琴 | 俏皮，拨弦、气泡声 |
| 水晶洞穴 | 棱镜深穴 | E 利底亚 76 | 钟琴 / 八音盒 | 空灵，钢片琴琶音 |
| 地下遗迹 | 砂岩回声 | E 弗里几亚属 84 | 长笛 / 木琴 | 异域，竖琴、手鼓、持续低音 |
| 冰封矿洞 | 霜光 | B 小调 66 | 八音盒 / 钢片琴 | 清冷稀疏，无鼓 |
| 熔岩矿洞 | 熔岩脉动 | C 小调 108 | 木琴 / 柔和合成主奏 | 有推进感，八分低音、通鼓 |
| 巨型化石 | 远古骨语 | G 多利亚 80，摇摆 | 长笛 / 拇指琴 | 原始，木琴节奏、低鸣 |
| 古代机械 | 齿轮深处 | A 小调 104 | 钟琴 / 柔和合成主奏 | 机械感，十六分琶音、齿轮滴答 |
| 地心秘境 | 世界之心 | C 小调 → C 大调结尾 72 | 钟琴 / 长笛 | 庄严神秘，人声铺底、定音鼓 |

- **结构**：每遍是前奏、A 段、B 段、A 段、尾声，一到两分钟；放完安静 9～18 秒（只剩环境声），再用另一种主奏乐器放下一遍，免得循环听腻。
- **跟着地方变**：传送或走进另一层时，旧曲两秒内淡出，稍停后新曲从前奏开始。
- **地表的昼夜**：白天鼓点齐全，入夜鼓组渐渐停下，只留旋律和伴奏。
- **下到第一层矿井**（0～400 米，仍属山谷主题）：继续放山谷的曲子，但像从井口传下来的一样，声音变闷、变轻，没有鼓。
- **大时刻让路**：解锁新矿层、开蛋揭晓、领奖、购买时，音乐被压低一下，过后恢复。
- **音量层次**：所有曲子响度对齐到相差约 2 dB 以内；音乐的平均响度比镐子敲击低约 10 dB，与脚步声相当，不抢挖矿的声音。低频收着放（手机扬声器放不出 150 Hz 以下，堆在那里只会让耳机里发闷），旋律在中频最突出。
- **调度**：音符由一个每 0.1 秒运行的计时器提前 0.6 秒排进音频时钟，与画面帧率无关；卡一帧或打开面板都不会让音乐断拍。页面切到后台时暂停。

## 环境声

| 地方 | 持续底声 | 偶发声音 |
| --- | --- | --- |
| 地表 | 一阵阵的风 | 白天鸟叫（三种叫法），夜里虫鸣，偶尔树叶沙沙 |
| 矿井浅层、老矿井 | 洞穴低鸣 | 滴水、远处闷响、远处别的矿工敲镐；老矿井还有木头吱呀 |
| 蘑菇洞穴 | 洞穴低鸣 | 更密的滴水、咕嘟冒泡 |
| 水晶洞穴 | 洞穴低鸣 + 很轻的晶体共鸣 | 滴水、晶体叮当 |
| 地下遗迹 | 洞穴低鸣 + 穿堂风 | 滴水、远处风铃、石块摩擦 |
| 冰封矿洞 | 冷风 | 冰晶叮当、冰层开裂、滴水 |
| 熔岩矿洞 | 低沉的熔岩翻涌 + 热气嘶声 | 岩浆冒泡、火星噼啪、闷响 |
| 巨型化石 | 干燥的风 | 沙粒滑落、滴水 |
| 古代机械 | 机器嗡鸣 | 蒸汽嘶声、金属碰撞、滴水 |
| 地心秘境 | 脉动的低鸣 + 晶体共鸣 | 能量涌动、风铃 |

- 偶发声音随机出现在左、中、右三个方向，带一点混响；换地方时底声交叉淡入淡出。
- 地下时，挖矿、脚步等音效也会带上洞穴回声，越空旷的层回声越多（水晶、地心最多）。
- 环境声属于「音效」开关。

## 脚步声

- 落脚时刻取自角色的走路和跑步动画：读取动画中每只脚向前伸到最远的位置，在稍后一点出声，所以声音和画面里的落脚对得上；跑得越快步子越密越重，站着、在空中不出声。
- 八种材质：草地、沙地、泥土、石头、木头、金属、冰、晶体。地表按广场的地面布局区分（中央广场和出生点是沙地、小路是泥土、铺砖和传送门底座是石板、小溪上的木桥是木头、蛋台台阶是石头，其余是草地）；地下按脚下方块的种类（泥土、岩石、冰岩、合金岩、晶体类矿石）；各层休整站的地板按主题（老矿井木头、古代机械金属、冰封矿洞冰面等）。
- 每一步的音高、明暗、力度都略有变化；各材质的响度对齐，比镐子敲击低约 10 dB。

## 设置

设置里新增「音乐：开/关」，与「音效：开/关」分开，默认都开，选择保存在设备上。两个都关掉时声音整体暂停。

## 顺带修掉的问题

- 上一轮的音效里，每个噪声成分在开始的那一个采样会以满音量漏出（音量包络在开始前默认是 1），可能听到细小的“咔”声；渲染里一处脚步声的峰值因此达到 −2.8 dB。现在所有包络从静音开始，同一处峰值降到 −15.6 dB。

## 代码结构

- `src/game/audio/synth.ts`：音效、乐器、环境声共用的振荡器/噪声声部与包络，以及无缝循环的粉红噪声。
- `src/game/audio/mixer.ts`：整套混音链（音效、环境声、音乐、共用混响、压缩器），游戏和离线渲染共用；两个开关各控一组门限。
- `src/game/audio/music/`：`instruments.ts`（22 种乐器、15 种打击乐）、`score.ts`（类似 tracker 的记谱和编译）、`songs.ts`（十首曲子）、`MusicPlayer.ts`（提前排程、换曲淡入淡出、轮换编配）。
- `src/game/audio/ambience.ts`：各地方的底声和偶发声音；`soundscape.ts`：根据所在主题、离地表的光照和昼夜决定曲子与环境声。
- `src/game/presentation/minerSteps.ts` 与 `MinerAvatar.consumeEvents().step`：脚步时刻；`src/game/runtime/footSurface.ts`：脚下材质；`MiningFeedback.place()` 每帧把所在位置交给声音，脚步声也在这里出声。
- 离线工具 `tools/music-preview/`：用游戏自己的混音链把曲子、环境声、脚步声渲染出来，输出频谱图、响度表、WAV 片段和试听用的 Opus 片段；只用于制作，验收以公开入口为准。

## 验证

- TypeScript 与 Vite 构建通过。全量测试 510 项：506 通过，4 项失败与改动前相同（contact-bake、quarry 资源清单、quarry 庭院碰撞、旧道路）。新增 `music.test.mjs`（6 项：记谱解析；十首曲子格数、音域、强拍旋律落在和弦音上的比例不低于 80%、每遍时长、两遍换主奏；十个主题各有不同曲子；播放器只提前排程一小段；换曲淡出后从前奏开始、夜里不排鼓点；放完休息后换主奏、关掉再开从头放）、`ambience.test.mjs`（4 项：地表/矿井/深层的场景选择与洞口防抖；白天鸟叫夜里虫鸣；每个地方都有底声和偶发声音；换地方时底声淡出并释放）、`footsteps.test.mjs`（3 项：从动画找出两只脚的落地时刻；走、跑、站、跳时的步数与力度；地表布局、地下方块、休整站地板的材质）；`game-audio.test.mjs` 增加两个开关分开保存、场景驱动曲目和环境声、大时刻压低音乐；`mining-feedback.test.mjs` 增加脚步声材质和每帧场景。UI 字体子集按新文字重新生成。
- 离线响度（tools/music-preview，均为游戏混音链输出）：十首曲子平均响度 −33.1～−35.4 dB，去掉 300 Hz 以下后 −36.9～−38.8 dB；环境声 −39.8～−44.3 dB；镐子敲石头最响的 0.1 秒约 −23 dB，脚步声约 −30～−37 dB。
- 先发布到公开试玩入口（`artifacts/audio-release.json`），再跑手机检查 `tools/check-audio-mobile.cjs`（Android UA、触控、横屏 844×390、DPR 2、SwiftShader），5 项通过、错误 0：首次触摸前不出声，之后山谷曲子和环境声开始，实测输出约 −36 dBFS；从出生点跑上木桥，脚步声随地面变化（石板 → 沙地 → 木头）；入夜鼓组停下、虫鸣代替鸟叫；到老矿井（400 米）换成矿灯小调和洞穴声，音效带回声；设置里音乐、音效分开开关，都关掉时声音暂停，刷新后保持。检查同时录下 12 秒游戏实际输出（`artifacts/audio-mobile/surface-walk.webm`），频谱里能看到音乐、脚步和鸟叫。
- 这些都是计数、电平和频谱上的检查，没有人耳试听，也没有在真机扬声器上听过；最终听感以在试玩入口实际听到的为准。
