## 分阶段

每个阶段：改完 → 全量测试 → 发布到公开试玩入口 → 电脑端截图验证 → 提交，再进入下一阶段。

### P1 矿石配色（问题 1）

所有矿现在只有两种颜色：三个世界 21 层的 42 种矿，每层第一种都是 `#d9bc82`（土黄），第二种都是 `#b8a3ee`（淡紫）（`journeyResources.ts`），所以煤是黄的、铜是紫的、红宝石是紫的。
- 每种矿按名字给自己的颜色（煤深灰、铜橙、翡翠绿、红宝石红、钻石冰白……），越深的矿越亮越饱和；同一层两种矿、矿和本层岩石都要拉开。
- 影响方块贴图、背包图标、拾取提示、第二世界材料清单，全部来自同一个颜色字段，不用分别改。
- 验收：42 种矿颜色两两可分（色差下限写进测试），每种矿和本层岩石可分；方块贴图每种仍唯一。

### P2 传送与商店（问题 2、3）

- 矿层传送和“前往第二世界”在哪都能用，和出售、商店、蛋台的一键传送一致。
- 扭蛋机的“便携传送”（解除上面那条限制）换成 **“出售金币 ×2（5 分钟）”**，和现有的移速、稀有率加成同一套；HUD 加成提示、出售报价跟着生效。旧存档里的 `permanent.travel` 照常读取、不再起作用。
- 右侧“商店”按钮和背包条上的“+”原地打开商店（不再传送），直接进工具页（“+”进背包页），页内切换；去掉“工具 / 背包”二选一的小窗。商店在哪都能买；走进地表商店圈照旧自动打开。
- 验收：会话测试覆盖地下传送、新奖励的抽取/计时/出售加成/旧存档读取、地下买东西；公开版截图。

### P3 蛋台（问题 4、7、12）

- 所有“按 E”统一成屏幕底部的按钮（蛋台、扭蛋机、矿区要求），站进范围就能按，不管镜头朝哪；仍是靠近才出现。去掉挂在蛋上方 4.85 米的那个。
- 蛋上方的名字和价格保留常驻，但缩小、贴近蛋顶、加深色底板；还没解锁的蛋整块调暗（价格照常显示）。
- 开蛋界面里的蛋图用这颗蛋在场景里的颜色。
- 验收：站在蛋台前背对蛋也能按 E；从广场和蛋台前截图对比。

### P4 HUD（问题 8、9）

- 开局引导只留一个：地上的箭头变细变淡；“去矿坑挖矿”只在矿井在画面里时显示，去掉画面外的“朝这个方向”。
- 左上“下一层”卡片改成和资源条同风格的细条（游戏自己的进度条组件，不用浏览器自带的）。
- 帮助、设置两个小按钮移到左上资源条上方；去掉金币条里像空位的两颗菱形。
- 验收：开局、矿下、出售前后截图。

### P5 面板（问题 5、6、10）

- 奖励：打开时跳到有可领奖励的那页；幸运币统一用一个专用图标（签到格不再画金币）；在线奖励 1/1/2/3。
- 背包面板标题跟页签走（宠物 / 矿物 / 装备）。
- 没有宠物时不显示“全部卸下 / 一键最佳”，提示只说一遍；装备页卡片排紧；扭蛋机、开蛋界面按内容收高；世界页放不下的卡可横向滚动并露出半张，未解锁的进度条写“0 / 400 米”。
- 验收：每个面板截图。

### P6 文字与单位（问题 11）

- `formatNumber` 改成万 / 亿；深度写完整米数（HUD、世界页、进度条、房间牌、传送门牌）；传送门地上的 `LOCKED` 改“未解锁”，`m` / `M` 改“米”。
- 验收：数字格式单元测试；HUD、世界页、蛋价、深层房间截图。
