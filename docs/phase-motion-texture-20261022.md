# 贴图闪点、跳跃与挥镐动作（2026-10-22）

用户反馈：地下选中的矿块侧面满是闪烁的小点；跳跃和挖矿的动作都不好看。工作区 `/root/.t3/worktrees/d-Mining/surface-roblox`，基于 `e2e6734`。

## 贴图闪点

斜着看矿块侧面时出现两层闪点：

- **矿物贴图**：矿物图集只用一级贴图（没有 mipmap），远处或斜面上一个屏幕像素跨过好几个贴图像素，矿脉和母岩每帧随机取到一个，于是变成雪花点；矿脉边缘又是 `step()` 硬切，加重闪烁。现在图集生成 mipmap；着色器用连续的格子 UV 算贴图级别（原来的 `fract()` 会让硬件导数在格子边上失效），每一级按级别向内收边，不会采到相邻图块。矿物颜色改为按矿脉覆盖率预乘存储、母岩在着色器里按 `(1 - 覆盖率)` 补上，远处的矿脉按覆盖率平滑过渡。近处仍是原来的清晰像素，第 0 级的画面与之前一致。
- **裂纹贴图**：被敲过的方块叠一层裂纹，裂纹是一像素宽的深色线和浅色高光，同样没有 mipmap，斜看时碎成浅色斑点（用户截图里集中在被选中方块上的浅色点就是它）。裂纹图集改为同样的做法：生成 mipmap、按格子 UV 选级别、逐级收边，不会采到下一阶段的裂纹图块。

代码：`src/game/terrain/minerals.ts`、`src/game/terrain/mineralMaterial.ts`、`src/game/presentation/BlockCracks.ts`。

## 跳跃与挥镐

RAB 动作库没有镐子挥击，只有约 2 秒的持斧下劈和带落地的长跳跃；原来把持斧下劈压进攻击周期，跳跃则只是把走路姿势冻结在空中。现在这几段动作都在代码里手调（`src/game/presentation/minerMotions.ts`），待机、行走、跑步仍用 RAB。

- **挥镐**：镐子竖在胸前 → 举到头后上方 → 加速砸下（接触点在 30%，镐尖朝前下方砸进胸口高度的方块面）→ 短暂停顿 → 回到胸前。上身按目标高度俯身或后仰，挖脚下的矿时整个人压下去。挥击时长等于攻击间隔，限制在 0.22–0.6 秒：高攻速时每次命中照常结算，手臂按 0.22 秒一次连贯挥动，最多排一次，停手不补播（原来每秒 16 次时手臂会抽搐）。
- **跳跃**：上升时收膝、一手上扬；过最高点换成双臂张开的下落姿势；落地蹲一下再站起，下落越快蹲得越深，双脚按腿长解算留在原地。走下矮台阶或短暂离地不算下落。
- 腿和上身分层：边跑边挖腿照常跑，空中挖矿腿保持空中姿势。
- 模型 GLB 里原来的 RAB `Mine` 片段（约 20 KB）没有删除，运行时不再使用。

代码：`MinerAvatar.ts`（分层混合、空中状态）、`MinerMiningLayer.ts`（挥击节奏）、`minerMotions.ts`（姿势数据、关键帧、落地两节腿解算）。制作用的离线预览在 `tools/motion-preview/`（侧面 / 背后 / 游戏视角逐帧拼图）。

## 挖矿目标卡挪到顶部

检查挥镐时发现：挖矿目标卡（矿名、血量、体积售价）放在底部中间“返回地表”上方，正好是第三人称镜头下角色站的位置，挖矿时把角色整个挡住。目标卡和新获得矿石提示一起挪到顶部深度下方。

顶部中间能用的宽度取决于左侧资源栏：中间这一列按左栏（以及右侧同样的边距、刘海安全区）留下的空间居中，最宽 280 px，窄屏上矿名过长时省略。卡片只保留矿名、血量条、体积和售价；原来的“力量 · 攻速”一行是镐子属性，商店里能看，只在镐子等级不够或方块已击碎时显示一行提示。
