# PICKAXE 招牌抬高（2026-10-31）

用户反馈：镐子店上方的 PICKAXE 文字和房子挤在一起。

原来招牌离地 6.9 米，在店门前 3.2 米（`hubLayout.ts` 的 `BUILDING.shop`），正好压在屋顶尖上，文字下沿碰到后面的烟囱。改为离地 8.6 米、门前 3.6 米。其他招牌高度不同：BACKPACK 7.1 米，SELL 5.6 米，从出生点一起看到时不会叠在一起。

验证，在公开版用手机横屏模拟（SwiftShader），同样机位截图对比：修改前用正式入口，修改后用测试入口。
- 广场中间：
  - 修改前：文字压在屋顶尖和烟囱上；
  - 第一次抬到 8.1 米：P、I 的下沿还碰到烟囱顶；
  - 8.6 米：文字和烟囱、屋顶之间都留出了空隙。
- 店门右前方近处：文字整个浮在屋顶上方，仍在画面内。
