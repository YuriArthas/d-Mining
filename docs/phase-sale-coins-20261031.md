# 出售时金币飞进金币栏（2026-10-31）

用户要求：出售时要有金币弹出的效果。

## 效果

一次出售（走进售卖圈，或站在圈里点背包的“全部出售”）：

1. 角色头顶弹出金色的“+120”，前面是本世界的货币图标（世界 2、3 分别是科技币、星币）。
2. 金币从角色胸口向上呈扇形散开，边飞边翻转，在角色周围停一下。
3. 金币一枚接一枚沿弧线加速飞进左上角金币栏的图标，每落进一枚图标跳一下，最后一枚落下时数字也跳一下。
4. 金币栏的数字先保持原来的值，第一枚落下才开始往上滚，最后一枚落下时正好滚到新值。
5. 声音：原来的收银声后面，每枚金币落下各有一声轻响，音高逐渐升高。

时间表放在 `src/game/presentation/saleFlight.ts`，金币、数字滚动、声音三处共用：散开 0.3 秒；第一枚 0.88 秒落下，最后一枚再晚 0.62 秒，整套效果约 1.5 秒。金币数随卖出的金额增加：几十个币出 6 枚，约一百万出 14 枚（对数增长）。

## 细节

- 出售发生在游戏这一帧的逻辑里，传送到售卖圈的那一帧镜头还没跟上，所以金币等到下一帧画面更新后再从角色身上出发（`MiningOverlay.sold` 先记下，`update` 里开始）。
- 在背包里点“全部出售”时面板盖着画面，叠加层和 HUD 都隐藏，这时不放金币，钱照常到账。原来这条路径不发出售事件，连收银声都没有，这次一起补上：两条路径改走同一个 `executeSale`，存档、事件、提示文字一致。
- 角色不在画面里时，金币从屏幕中间出发。
- 系统设置了“减少动态效果”时，不放金币，只淡入淡出“+120”，数字直接跳到新值。
- 动画全部用 Web Animations，每枚金币一个元素，落下即删除；每帧不新建元素，也不重新排版。
- `CountUp` 加了 `delay`：数值变化那一刻用的是什么时间，就按那个时间滚完，之后的重绘不会打断。HUD 收到出售事件后 250 毫秒内的那次数值变化，按金币的时间表滚动。
- 数字的计时从下一帧开始，和金币动画一样。金币的 Web Animations 要到下一帧画出来才开始计时；数字原来从出售那一刻起算，传送后第一帧很慢时两者会错开。服务器上有一轮第一帧卡了约 3 秒：数字 11.7 秒就滚完了，最后一枚金币 15.5 秒才落下。改成都从下一帧起算之后，两者对齐。

## 代码

- `src/game/presentation/saleFlight.ts`：时间表、金币数、第 i 枚的落下时间。
- `src/game/presentation/MiningOverlay.ts`：`sold`、`coinBurst`（“+N”、扇形散开、弧线飞入、图标和数字跳动）；把角色上方某点投到屏幕的计算提成 `overFeet`，`figure` 也改用它。
- `src/game/ui/hud/miningOverlay.ts`：出售事件交给叠加层。
- `src/game/ui/hud/mining.css`：`.sale-gain`、`.sale-coin`（翻转动画），大屏尺寸，减少动态效果。
- `src/game/ui/hud/Hud.tsx`、`src/game/ui/kit/controls.tsx`：金币栏数字等金币落下再滚，计时从下一帧开始。
- `src/game/audio/sfx.ts`：出售声后面加 8 声落币声，`CUE_LENGTH.sell` 改为 1.6 秒。
- `src/game/application/GameSession.ts`：两条出售路径合并，都发 `sold` 事件。

## 验证

- 单元测试：`feedback-session.test.mjs` 新增一项，走进售卖圈和点“全部出售”都发出一次带金额的出售事件，空背包不发。音效时长测试覆盖新的出售声。全量测试通过。
- 公开版手机检查 `tools/check-sale-coins-mobile.cjs`（Android UA、触控、横屏 844×390、DPR 2、SwiftShader）：存档里放 30 块矿，点 HUD 的“出售”传送去卖。
  - 放慢 8 倍、不截图的一轮，由页面自己记录时间（计划第一枚 7.0 秒、最后一枚 12.0 秒落下，SwiftShader 大约一秒一帧）：
    - 第一枚 8.23 秒落下，金币栏数字 8.24 秒开始变；
    - 最后一枚 12.69 秒落下，数字 12.72 秒到新值。
  - 放慢 8 倍、截图的一轮：散开；停在角色周围，数字还是原值；飞向金币栏，数字滚到一半（120 → 165 → 240）；全部落下。截图本身要几秒，会卡住页面，所以计时和截图分两轮。
  - 正常速度一轮：钱和金币栏都对，画面上不留金币和“+N”。
    - 这一轮从金币出现到全部落下记了 3.3 秒（计划 1.5 秒）。记录显示 6 枚是同一时刻落下的：传送后第一帧在 SwiftShader 上卡了几秒，动画的结束事件攒到一起才发出。
    - 数字和金币仍然同时到。真机上的节奏需要实际看一下。
- 这是服务器上的手机浏览器模拟，不是真机。
