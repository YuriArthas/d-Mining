# r3 验证范围

本轮验证范围：Linux / Node.js 24 的类型检查、共享源码哈希、语言资源校验、大小写路径检查和针对性 CPU 测试；从实际交付源码包解压后重新安装与构建。具体数量与结果见随包 VALIDATION_RESULT.json。

新增语言资源测试使用临时第五语言，覆盖自动发现、启动文案、数字小数格式与缺少键/参数时的失败。保留三个世界的 Sell 向上最近售矿点回归。

本轮未运行 GPU、浏览器、手机模拟或真机测试；没有执行 Windows 构建。路径静态检查不代表 Windows 实机通过，也不代表整份技术要求验收通过。公开测试入口仅使用 HTTP 文件核对。
