后续更新：用户收紧为整个发布包 ≤5 MB，当前已压缩到 **4.47 MB**，详见 [compact-release.md](compact-release.md)。下文保留 L23 当时的体积与验证记录。

## 运行方式与计时

用户暂缓动态光源工作。默认关闭移动提灯，隐藏其控制条，只保留固定灯、现有环境和静态阴影；窗口可见时连续逐帧绘制，最多两帧在途。切到后台停止提交，返回后恢复。每帧实际执行 8 个通道，包括几何法线、AO、照明、光晕和最终合成，不是重复显示缓存截图；移动灯的六面阴影与两道重建通道不执行。

性能栏新增 Render FPS 和帧间隔 P95，按实际渲染提交时间计算，不用 1000/GPU 时间冒充帧率，也不宣称测到了显示器的最终呈现次数。普通上报仍保存最近 1800 帧。默认自动按钮现在是“静态测帧率并上报”：先准备两帧，再固定当前日夜、视角和分辨率测 30 秒，一次上报包含独立 FPS、帧间隔、CPU/GPU 分布和原始数据。窗口变化、后台或新建管线会明确拒绝不完整结果。

`?loop=demand` 保留按需绘制诊断；`?experiment=dynamic&motion=moving` 才显示原动态实验操作。动态诊断及原 PCSS 仍在代码中，本轮没有继续优化它们。

公开功能验证报告 `689f6962-7afa-472f-8e69-d0f8cb3eb36c` 来自 Chromium/SwiftShader：960×640，30 秒只完成 9 个正常帧，提交 FPS 0.281，CPU 中位数 4.3 ms；唯一 GPU 样本 3532.378 ms。这是 CPU 模拟 GPU 的结果，只证明逐帧测量和上报链路运行，**不能代表 iPhone 或笔记本 GPU 帧率**。真实设备当前静态版本的 FPS 尚待上报。

## 磁盘与下载

以下 MB 均为十进制，浏览器数据来自新建无缓存上下文的响应体，未计 HTTP 头。

| 项目 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 公开 mining-light 目录 | 51.50 MB | 22.16 MB |
| 街景首访响应体总量 | 7.46 MB | 5.13 MB |
| 街景 GLB 的实际传输 | gzip 2.71 MB | Brotli 1.33 MB |
| 街景加载的材质贴图 | 33 张 | 21 张 |

原始 GLB 仍为 10.72 MB、117156 个三角面，没有改变任何顶点、UV、模型造型或材质画质。Brotli/gzip/identity 三种公开 HTTP 响应均独立解码并核对到相同 SHA-256。服务端按 Accept-Encoding 质量值协商，明确拒绝 br 的浏览器继续得到 gzip。压缩发生在构建时，不占渲染帧 CPU。

街景原来同时加载 baseline/crafted 两套贴图，现在只加载当前使用的 crafted；小院对照仍可切换两套材质。夜景公开截图前后逐像素一致。独立的当前发布包为 21.17 MB，其中包含小院、模型原文件以及 gzip/br 传输表示，并非首访都要下载的资源。

公开目录中的 128 个旧散列 JS/CSS 共 31.66 MB，已逐文件哈希核验后压缩归档为 8.61 MB；公开目录保留当前版与上一版依赖文件。归档可恢复，路径和各文件校验值在 `artifacts/static-continuous/bundle-archive.json`。若计算整台服务器硬盘，应把这 8.61 MB 归档也算上，不能把公开目录的全部减少当成物理磁盘释放。

工作区 `artifacts/` 另有约 357 MB，主要是历史截图、烘焙中间文件和验证证据，未随页面下载；Blender 源文件约 3.61 MB。这些开发记录没有被当作场景资产大小，也没有擅自清除。

## 后续压缩空间与验证边界

34 张 PNG 的无损 WebP 试压逐像素往返一致，全部文件合计 3.72 → 2.86 MB；这是包含小院/备用材质的总量，不是街景当前下载可额外省掉的同等大小。尚未替换运行时图片。无损 meshopt 试压在当前浮点布局上反而令 gzip 结果增大，没有采用；未使用有损量化或减面来凑体积。

验证文件在 `artifacts/static-continuous/`：前后截图/网络清单、真实 30 秒按钮上报、默认入口、390×655/DPR1.5 日夜截图、后台停止/恢复、Brotli 协商及资源归档。19 项帧间隔/历史/计时/动画/投影测试与传输协商检查通过。帧率结论仍必须使用对应真实硬件；本轮资源传输变小不等于 GPU 着色成本下降。
